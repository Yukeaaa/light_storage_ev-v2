# 背景与问题证据台账

> 每一条汇报或专利表述都必须在 `data_registry/claim_evidence_registry.csv` 登记，并在报告中
> 引用 `claim_id`。本台账说明背景与问题证据的分级依据、允许/禁止措辞与升级路径，
> 防止汇报文本在不同版本中不断扩大（审查结论7 §4.2）。
> 外部来源可回查编号见 `docs/evidence/sources.md`（S-xxx，审查结论8 P1-5）。

## 1. 四级证据定义

| 等级 | 含义 | 示例 |
|---|---|---|
| **A** | 协议、标准或受控实验 | IEC 61851 pilot 语义、厂标受控测试 |
| **B** | 公开真实系统、官方数据论文 | 公开 EVSE/车辆实测研究、官方数据集文档 |
| **C** | 本项目冻结实验结果 | E1-Lite/E3-Lite/K1 冻结数值（冻结阈值+负对照） |
| **D** | 待验证研究假设 | 未在任何门通过前禁止对外断言的主张 |

等级升级路径：D →（E0-Full 复现 / E1-Full 阶跃验证）→ C →（跨站扩展/受控实验）→ A/B。

## 2. 台账字段

| 字段 | 含义 |
|---|---|
| `claim_id` | 表述编号（汇报引用依据） |
| `claim` | 准备使用的结论 |
| `evidence_level` | A/B/C/D |
| `source` | 标准、论文、官方数据、本项目结果 |
| `source_ref` | 可回查来源编号（S-xxx，登记在 `docs/evidence/sources.md`；D 级假设为 `—`） |
| `scope` | 适用条件和数据范围 |
| `limitation` | 当前不能证明什么 |
| `allowed_wording` | 允许措辞（对外/对内报告） |
| `forbidden_wording` | 禁止扩大措辞 |
| `next_gate` | 哪个实验可升级该证据 |

## 3. 关键背景事实（A/B 级，可作为问题依据）

1. **pilot 是最大允许电流，不等于实际执行功率**（C-001，A 级）：充电协议中 pilot 定义的是
   桩侧允许电流上限，车辆实际吸收功率由其内部 BMS/充电机决定；两者之间的差异属于系统
   正常现象，不构成车辆"故障"。
2. **不同车辆响应存在精度、延迟和分辨率差异**（C-002，B 级）：车型/充电机型号差异导致
   对同一 pilot 的实际功率响应不同，且 pilot 阶梯分辨率有限。
3. **ACN 核心运行阶段存在持续响应差异**（C-003，C 级）：本项目 E1-Lite 冻结样本下的结论，
   尚未在 E0-Full 全量/硬切分样本上复现。

## 4. 当前主张边界（C/D 级，审查结论7 §2）

以下内容**已冻结为禁止对外断言**，除非对应门通过：

| 主张 | 等级 | 解除条件 |
|---|---|---|
| 差值可被其他车辆吸收（可回收能力）（C-004） | D | E1-Full 自然 pilot 正阶跃验证增量响应 + E2 区间有效性 → 且不得表述为"可回收能力"（同时满足，缺一不可） |
| 短时可执行功率区间可生成（C-008） | D | E2/K2 门 |
| 可减少储能补偿（C-005） | D | E4 闭环 + E7 站级嵌入 |
| 可提高光伏消纳（C-006） | D | E4 闭环 + E7 站级嵌入 |
| 全车型/全站点普遍适用（C-007/C-012 边界） | D | 跨站扩展审计（R1 全量扩展） |

## 5. 升级路线（与实验顺序一致）

```text
E0-Full 复现（C-003/C-011 升为全量口径 C）
→ E1-Full 自然 pilot 阶跃（C-002 细化、C-007 成立 → C）
→ E2 可执行区间（C-008/009/010 成立 → C；K2 信息价值门）
→ E4 闭环回放（E4.1 仿真器验证硬前置；C-004/005/006 才可谈收益）
→ E7 UCSD 站级嵌入（跨站方向一致 → B）
```

## 6. 使用规则

- 报告引用 `claim_id`，措辞不得超过 `allowed_wording`；
- 任何新增表述必须先登记台账，再进入报告；
- C 级结论必须附冻结范围（站点/月份/阈值/负对照）；
- D 级结论只允许在研究记录中出现，禁止进入对外汇报与权利要求初稿；
- A/B/C 级主张必须带 `source_ref`（S-xxx）可回查，禁止只写来源类别。
