# A. 工程架构（架构师视角）

## A.1 设计原则

1. **配置即预注册**：实验 = 代码版本 + 数据版本 + 配置（含阈值网格）。阈值网格、禁止特征、基线、主指标全部写在 YAML 配置里，作为预注册载体；代码不硬编码任何阈值。
2. **数据契约优先**：E0 冻结的 `datasets/` 表（1 分钟会话表、控制池表）是全项目唯一数据入口。下游实验（E1–E8）禁止直接读原始静态文件，保证口径唯一。
3. **泄漏防护内建**：`forbidden_features` 在配置层声明，运行器与测试层双重强制校验（模型输入 schema 中不允许出现该列表任何列）。
4. **可复算优先**：每个结果文件头部记录 `data_version / config_version / code_version / seed`；随机模型 ≥3 种子；确定性方法重跑必须逐位一致。
5. **结果分层**：`results/raw`（逐会话/逐日）→ `results/summary`（聚合）→ `reports/`（门评审）。raw 永不被 summary 覆盖，审计可回溯。
6. **重型构建可断点续跑**：E0.2（1 分钟表）按 site×month 分片、逐文件幂等、失败可续跑、完成后再校验哈希。

## A.4 数据契约

### A.4.1 `datasets/session_response_1min.parquet`（E0.2，全项目核心表）

| 字段 | 定义 | 质量标记 |
| --- | --- | --- |
| session_id / station_id / site / cluster | 会话、桩点、站点、车库 | mapping_status（matched/static_only/api_only） |
| timestamp_utc / timestamp_local | UTC 主时间、站点本地派生时间 | timezone_valid |
| actual_power_kw | 能量守恒的 1 分钟平均功率 | power_source=measured/computed/estimated |
| pilot_a / pilot_power_kw | pilot 存在时按电压换算 | pilot_available |
| state_raw / state_norm | 原始状态与统一状态 | state_available / state_valid |
| energy_cum_kwh | 累计能量（或重建累计） | energy_source |
| connected_elapsed_min | 仅由当前连接时刻累计 | online_safe=true |
| done / disconnect / kWhDelivered | API 离线标签 | online_safe=false（禁止进在线特征） |
| sample_count / gap_flag | 桶内样本数、缺口标记 | quality_flag |

功率口径（沿用 acn_project）：实测 Power → Voltage×Current（computed）→ 额定电压×Current（estimated）。额定电压 jpl=192.7V（已校准）、caltech=240V、office001=240V。积分用前向保持；超过允许最大间隔的缺口不跨越填充。

### A.4.2 `datasets/pool_state_1min|5min.parquet`（E0.3）

| 字段 | 定义 |
| --- | --- |
| site / cluster / pool_id / time_bucket | 池标识与时间桶（对齐到周期边界） |
| n_active / n_matched | 活跃会话数与其中 matched 数 |
| actual_power_kw_total / pilot_upper_kw_total | 池实际总功率与 pilot 总上限 |
| measured_kwh / estimated_kwh | 各来源能量 |
| pilot_coverage / state_coverage / measured_ratio | 每桶字段覆盖率 |

控制池优先 siteID+clusterID（或 README 可识别车库），禁止跨地理车库合并；static_only 仅用于响应审计，不用于严格池回放。

## A.5 配置体系（预注册载体）

每个实验一个 YAML（示例 `configs/e1_gap_audit.yaml`）：

```yaml

threshold_grid:                           # V2.0 §4.3，训练/验证集定参
  active_power_kw: [0.3, 0.5, 1.0]
  relative_gap: [0.15, 0.25, 0.35]
  absolute_gap_kw: [0.5, 1.0, 2.0]
  min_duration_min: [3, 5, 10]
  startup_exclusion_min: [2, 5, 10]
  tail_exclusion_min: [5, 10, 15]
  pilot_step_a: [2.0]
  pilot_step_relative: [0.15, 0.25]
forbidden_features:                       # 运行器强制校验
  - future_disconnect_time
  - final_kwh_delivered
  - future_done_charging_time
  - true_soc
primary_metrics: [event_session_rate, event_minute_rate, gap_energy_kwh, cross_site_replication]

  - results/raw/E1/gap_events.parquet
  - results/summary/E1/problem_strength_summary.csv
  - reports/E1_gate.md
```

运行器约定：主阈值 = 网格中在验证集按"事件保留率 × 稳定性"选出的组合；测试集冻结后只跑一次，禁止逐图调参。新增方案 = 新 experiment_id + 新测试协议。

## A.7 复现、版本与审计

- **版本三元组**：`data_version`（dataset_registry.json 哈希）、`config_version`（配置哈希）、`code_version`（git rev）。实验运行器在写入每个结果时同时落这三个版本 + 全部预注册参数 + seed。
- **幂等性**：E0 构建脚本重跑必须哈希/计数一致或可解释；确定性基线重跑逐位一致；随机模型固定 3 个种子并报告种子方差。
- **审计路径**：`results/raw` → `results/summary` → `reports` 层层可追溯；每个门评审报告引用其 raw/summary 路径与版本。

## A.8 测试与防泄漏

| 测试层 | 内容 | 关键断言 |
| --- | --- | --- |
| unit（E0.5 基线） | EV 能量守恒、活跃边界、功率边界、BESS 互斥、终端条件、重复运行 | 分配不凭空增加能量；连接前后命令为 0；同周期不同时充放电；无末端拖延 |

| regression | 每门通过后冻结该实验的主汇总结果 | 重跑一致 |

## A.9 性能与资源

- 原始静态 85,877 个文件、约 4.49 亿行：E0.2 只解析所需字段（time/pilot/current/voltage/power/state/energy），按 site×month 分片并行（ProcessPool），逐文件落盘中间结果 + 断点续跑。
- `datasets/` 表按 (site, month) 分区存 parquet；单会话 1 分钟表预估数百万行，pandas/pyarrow 可承载。
- 计算密集型步骤（E2 模型、E4 回放）限定在 `configs/control_params.yaml` 的控制周期与池规模内，避免全站小时级循环。
- 所有中间临时文件写入仓库外临时目录（如 `%TEMP%`），不污染结果目录。

## B.4 E1：问题强度（E1.1–E1.6）

**要证明的命题**（非"EMS 命令失败"）：在实际可观测充电过程中，导引/允许电流与实际吸收之间存在状态相关、持续、可重复的差异，且简单尾段解释不足。

| 子实验 | 设计 | 输出 |
| --- | --- | --- |
| E1.1 状态分段 | 层级规则：先排除无效/异常 → 初始爬升与离线尾段 → 稳定/约束/降流候选/间歇。每个判断分量单独输出一列 | state_segments.parquet |
| E1.2 pilot-actual 差异 | 响应比 r=I/max(I_pilot,ε)，差 g=max(P_pilot−P_actual,0)；事件需同时满足激活功率、比例差、绝对差、T_event（阈值网格预注册） | gap_events.parquet + 汇总指标 |
| E1.3 无 pilot 降流 | JPL current-only：会话历史 P90/P95、最近稳定平台、同桩历史分布；只标"降流候选"，不声称可吸收余量 | 降流候选表 |
| E1.4 自然 pilot 阶跃 | 正/负阶跃分开；前置稳定≥2/5 分钟；后置观察≥5/10 分钟；排除初始/尾段/短文件；响应方向一致率、增益、延迟、饱和比例、状态依赖 | pilot_steps.parquet |
| E1.5 排伪 | 随机时间置换、done 附近排除、pilot 恒定子集、实测功率子集、短文件剔除、station 固定效应 | 排伪报告 |
| E1.6 跨站稳定 | 站点/cluster/month 分层；L2 核心 vs L3 敏感性方向一致性 | problem_strength_summary.csv |

**E1 门（V2.0 §7.6）**：Go = 至少两站、多个合格月份、多个桩点重复；尾段/异常排除后仍有稳定事件率与差值量级；自然 pilot 阶跃显示状态相关响应或饱和可预测。条件Go-A = 仅 pilot-rich 车库成立（收缩交流充电群）；条件Go-B = 正阶跃不足但高估上界成立（收缩为上界/预算修正，不主张增量吸收）。No-Go = 主要由尾段/估算误差/少数桩点造成，或简单当前值/状态规则完全解释。

## B.5 E2：可执行响应区间（E2.1–E2.7）

**两类目标必须分别训练与评价**（V2.0 §8.1）：
- A 类（延续当前/导引条件下未来吸收功率）：A1 点值（h=1/5/15）、A2 条件分位区间 Q10/Q50/Q90、A3 高估风险。
- B 类（pilot 变化时的增量响应）：B1 正阶跃增量 Δactual/Δpilot、B2 饱和概率。B 类只有经自然阶跃样本验证后才能用于"额外分配"。

| 项目 | 设计 |
| --- | --- |
| 特征组 | F0 实际功率（current-only 基线）、F1 pilot、F2 state、F3 能量阶段（不用最终 kWh）、F4 场站历史、F5 质量 |
| 基线顺序 | B0 当前功率持久性 → B1 窗口均值/分位数 → B2 当前 pilot/历史 P95 上界 → B3 规则状态机 |
| 模型 | M1 线性/分位数回归 → M2 LightGBM/随机森林分位数 → M3 共形/分组校准 → M4 轻量时序（仅 M2 显著不足时） |
| 协议 | 特征严格截断在 t；目标 (t,t+h]；断开后功率记 0 但 disconnect 不作特征；按会话/日分组防泄漏；时间顺序切分；超参只在验证集；随机模型 ≥3 种子；pilot-rich/current-only 分训 + 统一模型+缺失标记对照；校准在独立校准集 |
| 指标 | 点值 MAE/RMSE/sMAPE（辅助）；区间 PICP/MPIW/Winkler；控制高估 ∫max(P_upper−P_actual,0)dt + 事件率（D1 核心）；低估量；最差 5% 会话/日尾部风险；跨站/字段模式/异常月份泛化；单会话与池级 P50/P95 计算时间 |
| 消融 | E2-A 站内时间外推（B0–B3 vs M1–M3）、E2-B 跨站迁移、E2-C pilot-rich→current-only、E2-D L2 vs L3、E2-E 1/5/15 分钟、E2-F 自然阶跃上验证 B1/B2 |

**E2 门**：Go = 相对 B0–B3 中最强者，在测试集且至少两站稳定降低高估功率/区间损失，覆盖合理且宽度不过度，增量模型在自然阶跃中可复现区分。条件Go = 仅 pilot-rich 或仅 current-only 有效（场景分支）；模块保留 = 预测同效但状态识别可用于规则分配；No-Go = 仅改善平均 MAE 或滚动分位数同效。

## B.6 E3：重分配机会（E3.1–E3.5）

三个必要条件同时成立才有闭环价值（V2.0 §9.1）：①某会话分配上界 > 可执行响应；②同池存在仍连接、可响应、有增加空间的会话；③站级预算/PCC 约束使功率再利用有价值。

| 项目 | 设计 |
| --- | --- |
| 控制池 | Pool-1 同 site+cluster、1 分钟状态/5 分钟控制（主）；Pool-2 同 site 可控桩（扩展）；Pool-3 单桩（上界保护对照）；15 分钟池（UCSD 兼容敏感性） |
| 反事实预算 | C0 观察参考、C1 90%/滚动P90、C2 75%/80%、C3 60%/70%（压力）、C4 日内需量/PV 余量。全部预注册、所有方法共享，不得按结果调整 |
| 量定义 | Recoverable=Σmax(P_cmd−P_exec_upper,0)（只用观察值则称"预算差值"）；Headroom 只来自自然正阶跃验证的增量模型；Redistributable=min(Recoverable, Headroom, 剩余预算)；Opportunity=超过阈值的周期 |
| 输出 | 机会周期比例、可重分配功率/能量（kW/kWh/占预算%）、并发会话数与集中度、机会持续时间、最强简单上界（上一周期 actual）后剩余机会、跨站与字段模式边界 |
| 统计 | 按池/日/站点/预算强度分层；报中位与分位数；配对比较同一预算场景 |

**E3 门**：Go = 机会在多个车库和月份重复，且在最强简单上界后仍有非忽略量级，不只在强合成预算下出现。条件Go = 仅特定高并发车库/预算强度成立（收缩场景）。No-Go = 偏差时通常无其他可吸收会话，或上一周期 actual 已消除绝大部分，或头部样本过少。

## B.7 E4：闭环回放（E4.1–E4.8）

| 项目 | 设计 |
| --- | --- |
| E4.1 响应仿真器 | R0 轨迹上限（最保守）、R1 一阶响应+延迟、R2 状态转移、R3 数据驱动。先用未参与训练的自然阶跃事件验证（方向/增益/延迟）。主结论只用 R0 + 经验证 R1；R2/R3 仅在明显提高阶跃复现且不引入未来信息时使用 |
| 分配器 | A0 平均/比例、A1 当前 pilot、A2 上一周期 actual（最强简单闭环）、A3 滚动分位数、A4 简单状态机、D1-P 区间分配、D1-C 闭环回收重分配 |
| 统一协议 | 所有分配器共享：站级预算、活跃会话、控制周期 5min（1/15 敏感性）、动作上限、同一仿真器；最小保持、最大爬坡、每周期最大重分配轮数、动作死区；优先级只用可观察规则（连接时长/累计能量分位/公平债务），不用真实剩余需求 |
| 指标 | 执行性（站级预算跟踪 MAE、未执行功率电量、超上界次数、响应延迟）；服务（交付电量 vs A2、低交付分位会话、最差 5%）；公平（Gini/Jain）；稳定（动作次数、总变差、抖动）；站级（峰值/爬坡/BESS 补偿残差）；计算（P50/P95/P99） |
| 压力矩阵 | 预算强度 C1–C4；pilot 缺失 10/30/50%、state 缺失、功率转 estimated；通信延迟 0/30/60/300s；训练站→测试站、早→晚月份漂移；池规模小/中/大；自然饱和、间歇充电、短文件；仿真器 R0/R1/R2 |

**E4 门**：Go = D1-C 相对 A2/A3 在配对测试中稳定减少未执行功率与预算跟踪残差，交付无显著恶化，动作与运行时间可接受，至少两站/多月重复。条件Go = 仅高并发/pilot-rich/动态预算成立（限定场景，D1-P 可独立保留为上界保护）。模块保留 = D1-P 有效但重分配无增益。No-Go = 简单 A2/A3 同效，或收益依赖未验证仿真器，或以牺牲交付/大量动作换取。

## B.8 E5/E6：条件实验

- **启动条件（E5）**：E1–E4 证明字段缺失、用户申报偏差或模型失配显著损害 D1 控制，而统一保守规则又造成明显损失时才启动。
  - E5.1 信息源可靠性标签（功率/pilot/state/申报/预测模型）→ E5.2 用户申报审计（缺失率、修改动态、离场/电量申报差异，仅离线）→ E5.3 可信度→约束映射（T0–T3）。
  - 基线：统一缺失填补 / 缺失标记模型 / 统一保守裕量 / 字段分支规则。Go = 相对统一保守与字段分支，减少过度保守或控制损失且不增高估风险，跨字段模式与至少两站稳定；No-Go = 只是缺失值处理或阈值包装。
- **启动条件（E6）**：先做负迁移先验（X1 时间漂移、X2/X3 跨站、X5 Office001、X6 字段模式）；不存在明显负迁移则 D3 无独立必要性。
  - 适用度特征（分布距离/字段模式/近期性能/数据质量/环境状态）→ 模式切换 M-local/M-global/M-interval/M-rule/M-protect。Go = 适用度在控制前可识别负迁移风险，切换改善最差站点/月份的高估与残差，优于按站固定与简单集成。

## B.10 E8：专利决策（E8.1–E8.4）

- **一票否决**：问题依赖合成异常或不可得变量；最强简单基线同效；效果只在预测误差未进执行/跟踪/交付/PCC/BESS；只在单月单桩/离群/未验证仿真器出现；关键步骤无法接入现有接口或计算不可接受。
- **100 分评分**：问题真实性与必要性 20 / 必要输入可观测与实施性 15 / 相对强基线独立效果 20 / 控制技术效果 15 / 跨场景重复性 10 / 步骤完整与闭环关系 10 / 专利组合空间 5 / 工程与实验成本 5。
- **输出**：seven_gate_matrix、direction_scorecard.csv、patent_evidence_map.md（问题→步骤→效果→实施例→权利要求骨架）、No-Go 知识库。

## B.11 统计与报告规范（V2.0 §14）

- **配对比较**：同会话/池/日/预算下比较方法，报差值而非只报独立均值。
- **置信区间**：会话/日级 cluster bootstrap 95%CI；禁止把分钟点当独立样本。
- **效应量**：绝对 kW/kWh 与相对百分比同报；显著性不能替代工程量级。
- **最差场景**：报 p95 损失、最差站点/月份/会话，不只总体平均。
- **失败案例**：每实验抽取 ≥20 个代表性失败会话，保留原始轨迹、状态、模型输出与控制动作。
- **稳定性**：确定性方法重跑一致；随机方法 ≥3 种子并报告种子方差。
- **多重比较**：主指标预注册；其他指标标为探索性，必要时控制 FDR。
- **D1-R 主指标顺序**：高估/未执行功率电量 → 站级预算跟踪残差 → 交付影响 → 动作与运行时间；MAE/RMSE 为辅助。
