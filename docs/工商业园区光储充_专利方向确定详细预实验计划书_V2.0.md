# ***\*1. 项目背景、前因后果与本轮纠偏\****

## ***\*1.1 光储充系统的工程链条\****

园区光储充系统由基础负荷、光伏、储能、电动汽车充电设施、电网接口和EMS组成。站级调度器通常先决定光伏消纳、储能充放电和EV聚合功率，再把EV功率预算分配到具体充电会话。真正影响PCC和储能的是车辆最终吸收的实际功率，而不是理论额定功率、用户申报或优化器中的抽象变量。

园区负荷/PV/电价/需量约束
    ↓
站级滚动优化：得到EV总功率预算与BESS计划
    ↓
会话级分配：把EV预算分配给各充电会话
    ↓
充电桩导引/允许电流与车辆实际响应
    ↓
PCC实际功率、BESS补偿、车辆交付电量
    ↓
下一周期状态反馈与重新优化

如果会话级分配忽略车辆当前响应状态，可能把功率分给短时无法吸收的车辆；如果系统又不能及时回收差值，就会形成EV预算跟踪偏差或让储能被动补偿。但是，ACN数据没有真实EMS命令，因此本轮必须先审计“pilot/允许电流—实际响应”差异及自然pilot变化下的响应规律，不能直接声称现场指令执行失败。

## ***\*1.2 前期路线及已确认的教训\****

| **前期探索** | **结果/风险**                                                | **本轮约束**                                        |
| ------------ | ------------------------------------------------------------ | --------------------------------------------------- |
| 行为预测A1   | 局部预测误差可改善，但控制收益不稳定；时间分辨率改变时结论可能反转 | 预测只能作为控制上游，必须验证下游执行收益          |
| 行为自适应A2 | 相对普通行为MPC未形成稳定增益                                | 先证明信息价值，再做自适应                          |

**本轮转向：**从“假设用户准确需求与离场已知”转向“利用真实可观测响应生成短时控制边界”；从“复杂模型优先”转向“问题强度—简单基线—控制后果优先”。

## ***\*2.4 数据不能证明的事项\****

· ACN不提供真实EMS优化器命令，因此pilot与实际电流差异只能称为“导引/允许电流与实际响应差异”，不能直接称为“命令拒绝”。

· ACN不提供车辆真实SOC、BMS限功率原因、温度降额和PCS拒绝码，因此独立方案不得依赖这些隐藏变量。

· kWhRequested和requestedDeparture是用户申报，存在缺失和修改；不能等同于真实需求或准确离场。

· ACN与UCSD不是同一现场，组合回放只能证明机制及站级潜在后果，不能证明真实联合现场频率。

· 自然历史时序只反映当时pilot和环境下的响应；推断提高pilot后的额外吸收能力必须依赖自然pilot阶跃样本或明确的响应仿真。

## ***\*4.3 阈值预注册原则\****

所有事件阈值在训练/验证集上以有限网格确定，不得在测试集上逐图调整。主报告同时给出一个预注册主阈值和完整敏感性网格。阈值不是行业事实，而是实验参数；专利方案应表述为可配置阈值或根据历史分布自适应确定。

| **参数**            | **建议网格**                                    | **说明**                 |
| ------------------- | ----------------------------------------------- | ------------------------ |
| 统一状态粒度        | 1分钟为主；原始粒度和5分钟为敏感性              | 避免不同文件采样不一致   |
| 激活功率阈值P_on    | max(0.3/0.5/1.0 kW，站点或会话P95的5%/10%)      | 排除接近零功率噪声       |
| 响应差比例δ_r       | 0.15 / 0.25 / 0.35                              | pilot-rich中识别显著差异 |
| 绝对差δ_p           | 0.5 / 1 / 2 kW                                  | 防止低功率比例放大       |
| 最短持续时间T_event | 3 / 5 / 10 min                                  | 避免单点跳变             |
| 连接初始排除        | 2 / 5 / 10 min                                  | 排除正常握手与爬升       |
| 离线尾段排除        | doneCharging前后5 / 10 / 15 min；或state=done后 | E1排伪，不作为在线规则   |
| pilot阶跃阈值       | ≥2 A且≥15% / 25%相对变化                        | 自然干预识别             |

# ***\*7. E1：充电响应问题强度与自然响应识别\****

**E1要证明的不是：**“EMS命令经常失败”；而是“在实际可观测充电过程中，导引/允许电流与实际吸收之间存在状态相关、持续、可重复的差异，并且简单尾段解释不足”。

 

## ***\*7.1 E1.1 会话状态分段\****

| **状态**               | **离线识别条件（示意，阈值由预注册网格确定）**               | **在线可实现版本**                            |
| ---------------------- | ------------------------------------------------------------ | --------------------------------------------- |
| S0 未连接/无效         | 会话外或字段无效                                             | 连接状态/数据质量                             |
| S1 初始爬升            | 连接后前2/5/10分钟；功率单调上升或快速波动                   | 连接以来时长+斜率                             |
| S2 稳定充电            | 窗口功率变异系数低、实际功率高于P_on                         | 窗口统计                                      |
| S3 pilot约束           | actual/pilot接近1且pilot变化后actual同向响应                 | 响应比+阶跃响应                               |
| S4 车辆侧降流/限制候选 | pilot稳定较高，actual持续低于pilot或下降；不在离线尾段排除区 | pilot+actual趋势；无pilot时只能标记“降流候选” |
| S5 完成尾段            | state=done或接近doneChargingTime；actual接近0                | 在线不能用未来done；仅以低功率持续和状态回退  |
| S6 间歇/异常           | 频繁启停、短文件、非物理跳变、能量离群                       | 质量标记和异常检测                            |

 

状态分段需采用层级规则：先排除无效/异常，再标记初始与离线尾段，然后在剩余有效充电区分稳定、pilot约束和降流候选。所有状态规则需输出每个判断分量，避免黑盒标签。

## ***\*7.2 E1.2 pilot—actual持续差异审计\****

在pilot-rich会话中计算响应比r=I_actual/max(I_pilot, ε)和功率差g=max(P_pilot-P_actual,0)。事件必须同时满足：有效充电状态、pilot/功率高于激活阈值、比例差与绝对差均超阈值、连续时间达到T_event。

| **输出指标**         | **计算层级**       | **必须报告**                           |
| -------------------- | ------------------ | -------------------------------------- |
| 事件会话率           | 会话               | 至少一次持续事件的会话比例             |
| 事件分钟率           | 有效充电分钟       | 事件分钟/有效充电分钟                  |
| 事件持续时间         | 事件               | 中位、p75、p95、最长                   |
| pilot-actual差值能量 | 事件/会话/日       | ∫(P_pilot-P_actual)+dt，仅称“差值能量” |
| 站点/车库分布        | site/cluster/month | 均值、中位、样本数和置信区间           |
| 尾段敏感性           | 不同尾段排除规则   | 问题保留率                             |
| 质量敏感性           | L2核心 vs L3敏感性 | 结果方向是否一致                       |

 

## ***\*7.3 E1.3 无pilot的实际功率降流事件\****

JPL大量current-only文件无法计算响应比。该子实验只识别“实际功率下降/受限状态”，不声称存在未利用上限。采用会话内稳态平台作为历史参考，检测平台后持续下降、间歇或低功率段；用于训练current-only状态模型和D2回退，不直接用于证明可重分配余量。

| **参考上界**      | **定义**                       | **风险**                |
| ----------------- | ------------------------------ | ----------------------- |
| 会话历史P90/P95   | 仅使用当前时刻以前窗口         | 早期窗口不足            |
| 最近稳定平台      | 状态S2期间最近稳定均值         | 平台可能本身受pilot限制 |
| 同桩历史分布      | 训练期同station与时段分位数    | 跨车辆差异              |
| 站点额定/典型上界 | 仅作压力测试，不作真实能力标签 | 过度高估                |

 

## ***\*7.4 E1.4 自然pilot阶跃响应实验（决定性补充）\****

为避免把“观察到的实际功率”误当成“可提高到的能力”，必须利用数据中自然发生的pilot变化作为准实验。分别识别正阶跃和负阶跃，比较阶跃前稳定实际电流与阶跃后1/3/5分钟响应。

| **筛选条件** | **建议**                                        |
| ------------ | ----------------------------------------------- |
| 阶跃大小     | 绝对变化≥2A且相对变化≥15%/25%；正负阶跃分开     |
| 前置稳定     | 阶跃前至少2/5分钟pilot与actual稳定，无其他阶跃  |
| 后置观察     | 阶跃后至少5/10分钟仍连接且数据完整              |
| 排除         | 初始爬升、离线尾段、state异常、短文件、能量离群 |
| 匹配对照     | 同会话无阶跃窗口或相近状态/功率的对照窗口       |

 

| **指标**       | **定义**                               |
| -------------- | -------------------------------------- |
| 响应方向一致率 | pilot增加/减少后actual同方向变化的比例 |
| 响应增益       | ΔI_actual / ΔI_pilot；报告中位和分位数 |
| 响应延迟       | actual达到最终变化10%/50%/90%的时间    |
| 饱和比例       | pilot提高但actual几乎不增加的事件比例  |
| 状态依赖       | S2/S3/S4、站点、时段、会话阶段分层     |
| 可预测性       | 仅用阶跃前在线特征预测增量响应/饱和    |

 

**E1.4阶段门：**只有自然正阶跃中存在足量样本，并且阶跃前状态能区分“会响应”和“不会响应”，D1-R才可以继续讨论“其他车辆可吸收余量”。若正阶跃样本不足，D1-R只能收缩为功率上界保护/预算修正，不能声称主动增配能力。

 

## ***\*7.5 E1.5 排伪与负对照\****

| **排伪/负对照** | **目的**                     | **预期**                     |
| --------------- | ---------------------------- | ---------------------------- |
| 随机时间置换    | 检验事件是否只是功率分布结果 | 真实连续事件显著强于置换     |
| done附近排除    | 排除正常充电结束             | 去除后仍保留非零问题强度     |
| pilot恒定子集   | 排除频繁导引改变             | 持续差异仍存在或明确限定场景 |
| 实测功率子集    | 排除电压估算偏差             | Caltech/Office结果方向一致   |
| 短文件/异常剔除 | 排除数据损坏                 | 主结论不依赖异常样本         |
| station固定效应 | 排除单桩故障支配             | 问题跨多个桩点               |

 

## ***\*7.6 E1 Go/No-Go标准\****

| **结论** | **最低条件**                                                 |
| -------- | ------------------------------------------------------------ |
| Go       | 有效充电状态下持续差异在至少两个站点、多个合格月份和多个桩点重复；尾段/异常排除后仍有稳定事件率和差值量级；自然pilot阶跃显示状态相关响应或饱和可预测。 |
| 条件Go-A | 问题仅在pilot-rich车库成立：专利场景收缩到支持导引采集的交流充电群。 |
| 条件Go-B | 自然正阶跃不足，但高估上界问题成立：收缩为“短时可执行上界生成与预算修正”，不主张增量吸收。 |
| No-Go    | 问题主要由正常尾段、估算误差或极少数桩点造成；或简单当前值/状态规则已完全解释，无独立问题。 |

 

# ***\*8. E2：短时可执行响应点值、区间与增量模型\****

## ***\*8.1 目标定义与术语边界\****

E2分成两个不同目标，必须分别训练和评价：A类是“在当前/延续导引条件下未来实际吸收功率区间”；B类是“pilot发生指定变化时的增量响应/饱和概率”。A类不能直接等同于物理最大能力，B类只有在自然阶跃样本中验证后才能用于额外分配。

| **目标**            | **标签**                           | **应用**                  |
| ------------------- | ---------------------------------- | ------------------------- |
| A1未来平均功率      | 未来h分钟实际功率平均，h=1/5/15    | 预算跟踪预测              |
| A2未来下/上分位区间 | 条件分位数Q10/Q50/Q90或校准区间    | 保守上界与稳定下界        |
| A3高估风险          | 未来实际低于候选上界超过阈值的事件 | 控制保护                  |
| B1正阶跃增量        | Δpilot>0后的Δactual与响应延迟      | 估计可增加吸收功率        |
| B2饱和概率          | pilot提高后actual增量不足的概率    | 决定是否回收/禁止继续增配 |

 

## ***\*8.2 特征组与消融\****

| **特征组** | **在线特征**                                                 | **消融目的**         |
| ---------- | ------------------------------------------------------------ | -------------------- |
| F0实际功率 | 当前值、1/3/5/10分钟滞后、斜率、波动、最近平台、连接时长、时刻 | 全量current-only基线 |
| F1 pilot   | 当前pilot、变化率、稳定时长、actual/pilot、最近阶跃大小      | pilot增量价值        |
| F2 state   | 统一状态、状态持续时间、切换次数                             | 状态字段价值         |
| F3能量阶段 | 截至当前累计能量、当前功率积分、会话内相对阶段代理           | 不使用最终kWh        |
| F4场站历史 | station/site训练期历史分位数、时段分布                       | 本地规律价值         |
| F5质量     | measured/estimated、缺失率、采样密度、短文件标记             | 可信度与回退         |

 

## ***\*8.3 基线与模型顺序\****

## ***\*8.4 训练与调参\****

\11. 所有输入严格截断在预测时刻t；目标窗口为(t,t+h]。若车辆在窗口内断开，断开后实际功率按0计入目标，但disconnectTime不作为特征。

# ***\*9. E3：同控制池可重分配机会审计\****

## ***\*9.1 目的与必要条件\****

闭环重分配只有在三个条件同时成立时才有意义：①某会话的当前分配上界高于实际可执行响应；②同一控制池内存在其他仍连接、可响应且有增加空间的会话；③站级EV预算或PCC约束使功率重新利用有价值。

## ***\*9.2 控制池与时间粒度\****

| **方案** | **定义**                                             | **主/敏感性**                       |
| -------- | ---------------------------------------------------- | ----------------------------------- |
| Pool-1   | 同siteID+clusterID或同车库；1分钟状态，5分钟控制周期 | 主方案                              |
| Pool-2   | 同site内所有可控桩                                   | 扩展场景，需明确通信/配电可控性假设 |
| Pool-3   | 单station                                            | 无重分配，仅用于上界保护对照        |
| 15分钟池 | Gold 15min聚合                                       | 与UCSD时间尺度兼容的敏感性          |

 

## ***\*9.3 反事实站级预算生成\****

ACN没有真实站级预算。E3/E4必须预注册透明预算，不得根据候选方法结果调整。预算来自观察负荷的受控缩放或站级容量约束，全部方法共享。

| **预算场景** | **定义**                       | **目的**                     |
| ------------ | ------------------------------ | ---------------------------- |
| C0观察参考   | 预算=观察到的池总实际功率      | 不控制参考                   |
| C1轻度约束   | 预算=观察池功率的90%或滚动P90  | 常规削峰                     |
| C2中度约束   | 预算=75%/80%观察上界           | 产生分配竞争                 |
| C3强约束     | 预算=60%/70%                   | 压力测试，不作为现实频率证据 |
| C4动态预算   | 按日内需量阈值或合成PV余量生成 | 接近站级控制                 |

 

## ***\*9.4 可回收与可吸收定义\****

对每个控制周期，在统一分配方法产生初始命令后，利用E2模型或自然响应仿真计算实际可执行。可回收量是命令超出可执行响应的部分；可吸收余量必须由自然正阶跃验证的增量模型或保守上界估计，不能用额定功率直接替代。

| **量**          | **定义**                                 | **限制**                                         |
| --------------- | ---------------------------------------- | ------------------------------------------------ |
| Recoverable     | Σ max(P_cmd - P_exec_upper, 0)           | 若只用观察actual，称“预算差值”而非真实可回收能力 |
| Headroom        | Σ max(ΔP_absorb_upper,0) over其他会话    | 主结果仅用pilot阶跃支持的模型                    |
| Redistributable | min(Recoverable, Headroom, 站级剩余预算) | 同控制池、同周期                                 |
| Opportunity     | Redistributable超过绝对/相对阈值的周期   | 报告阈值网格                                     |

 

## ***\*9.5 输出与Go门\****

| **指标**           | **统计**                                        |
| ------------------ | ----------------------------------------------- |
| 机会周期比例       | 按池、日、站点和预算强度                        |
| 可重分配功率/能量  | kW、kWh、占预算比例                             |
| 并发会话数与集中度 | 是否被少数大池支配                              |
| 机会持续时间       | 中位、p95                                       |
| 简单闭环剩余机会   | 使用“上一周期actual上界”后仍剩多少              |
| 跨站稳定性         | JPL/Caltech/Office及pilot-rich/current-only边界 |

 

| **结论** | **条件**                                                     |
| -------- | ------------------------------------------------------------ |
| Go       | 机会在多个车库和月份重复，且在最强简单上界后仍有非忽略量级；不是只在强合成预算下出现。 |
| 条件Go   | 仅特定高并发车库/预算强度成立：收缩为高并发慢充群或需量受限场景。 |
| No-Go    | 偏差发生时通常无其他可吸收会话；或上一周期actual已消除绝大部分；或头部样本过少无法支持增量能力。 |

 

# ***\*10. E4：响应仿真器、功率分配与闭环修正回放\****

## ***\*10.1 为什么需要响应仿真器\****

历史ACN轨迹只记录实际pilot下的响应。为了比较不同分配命令，必须建立受约束响应仿真器，并先用未参与训练的自然pilot阶跃事件验证。若仿真器不能复现响应方向、增益和延迟，E4只能做“预算上界离线分析”，不能做闭环控制效果结论。

## ***\*10.2 E4.1 响应仿真器验证\****

| **模型层级** | **形式**                                                | **验证**             |
| ------------ | ------------------------------------------------------- | -------------------- |
| R0轨迹上限   | actual=min(command, 观察/预测上界)                      | 最保守，不模拟提功率 |
| R1一阶响应   | actual_{t+1}=actual_t+α(state)(target-actual_t)，带延迟 | 自然正/负阶跃        |
| R2状态转移   | 状态S2/S3/S4决定增益、饱和和结束概率                    | 阶跃与自由轨迹       |
| R3数据驱动   | 轻量树/状态空间模型预测下一周期actual                   | 独立测试事件         |

 

主控制结论优先使用R0和经验证的R1；R2/R3仅在明显提高阶跃复现且不引入未来信息时使用。所有控制方法必须在同一响应仿真器下比较。

## ***\*10.3 E4.2 分配器基线\****

| **编号** | **分配方法**   | **在线上界/权重**                            |
| -------- | -------------- | -------------------------------------------- |
| A0       | 平均/比例分配  | 额定或当前可用固定上限                       |
| A1       | 当前pilot分配  | pilot-rich中的当前pilot                      |
| A2       | 上一周期actual | 最强简单闭环                                 |
| A3       | 滚动分位数     | 最近窗口P50/P75/P90或保守上界                |
| A4       | 简单状态机     | S1-S6规则上界                                |
| D1-P     | D1区间分配     | E2上界+置信度                                |
| D1-C     | D1闭环修正     | D1-P后检测差值，回收并向经验证headroom重分配 |

 

## ***\*10.4 E4.3 统一优化目标与约束\****

· 所有分配器使用相同站级EV预算、活跃会话、控制周期、动作上限和响应仿真器。

· 不使用真实未来disconnect或最终kWh作为在线优先级。服务评价只在实际断开时离线统计。

· 每会话命令非负，且不超过分配器在线上界；池命令和不超过站级预算。

· 设置最小保持时间、最大功率变化率和每周期最大重分配轮数，避免无限瞬时修正。

· 控制优先级采用可观察规则，如已连接时长、当前累计能量分位、历史公平债务；不得用真实剩余需求。

| **工程参数**   | **主值**                     | **敏感性**   |
| -------------- | ---------------------------- | ------------ |
| 控制周期       | 5 min                        | 1 / 15 min   |
| 测量-决策延迟  | 1个控制周期内0/30/60 s       | 网络压力测试 |
| 最小保持       | 5 min                        | 0 / 10 min   |
| 最大重分配轮数 | 1次/周期                     | 0 / 2次      |
| 动作死区       | 预算或会话功率的2%/5%        | 1%/10%       |
| 命令斜率限制   | 由观察pilot阶跃分布的p95确定 | 无/更严格    |

 

## ***\*10.5 E4.4 评价指标\****

| **层级** | **指标**                                                     |
| -------- | ------------------------------------------------------------ |
| 执行性   | 站级预算跟踪MAE、未执行功率电量、超上界次数、响应延迟        |
| 服务     | 断开前实际/仿真交付电量、相对A2下降、低交付分位会话、最差5%会话 |
| 公平     | 会话交付比例分布、Jain指数或Gini、连续被削减周期             |
| 稳定     | 动作次数、总变差、功率抖动、重分配轮数、频繁启停             |
| 站级     | 池峰值、爬坡、预算欠跟踪、需要BESS补偿的残差                 |
| 计算     | 每周期P50/P95/P99运行时间、内存、失败率                      |

 

## ***\*10.6 E4.5 压力测试矩阵\****

| **维度**   | **场景**                                            |
| ---------- | --------------------------------------------------- |
| 预算强度   | C1/C2/C3/C4                                         |
| 字段缺失   | pilot随机缺失10/30/50%；state缺失；power转estimated |
| 通信延迟   | 0/30/60/300 s                                       |
| 模型漂移   | 训练站→测试站；早期→后期月份                        |
| 控制池规模 | 小（≤5）、中（6-20）、大（>20）并发会话             |
| 响应异常   | 自然饱和事件、间歇充电、短文件敏感性                |
| 响应模型   | R0/R1/R2                                            |

 

## ***\*10.7 E4 Go/No-Go\****

| **结论** | **最低条件**                                                 |
| -------- | ------------------------------------------------------------ |
| Go       | D1-C相对A2“上一周期actual”和A3滚动分位数，在配对测试中稳定减少未执行功率与预算跟踪残差；交付电量无显著恶化；动作和运行时间可接受；至少两站/多月重复。 |
| 条件Go   | 只在高并发、pilot-rich或动态预算下成立：明确限定场景；D1-P可独立保留为上界保护。 |
| 模块保留 | D1-P有效但重分配无增益：作为普通MPC的会话上界模块。          |
| No-Go    | 简单A2/A3同效；收益依赖未验证响应仿真器；或通过牺牲交付、增加大量动作获得。 |

 

# ***\*11. E5：多源信息可信度与控制回退\****

## ***\*11.1 启动条件\****

E5不是默认独立方向。只有E1-E4证明字段缺失、用户申报偏差或模型失配会显著损害D1控制，而统一保守规则又造成明显损失时，E5才升级为专利候选。

## ***\*11.2 E5.1 信息源可靠性标签\****

| **信息源**           | **在线可信度证据**                                      | **离线校准标签**                     | **回退**                 |
| -------------------- | ------------------------------------------------------- | ------------------------------------ | ------------------------ |
| actual power/current | 采样密度、连续性、物理范围、measured/estimated          | 能量一致性、异常文件                 | 扩大区间/降低上界        |
| pilot                | 存在、稳定、与actual历史一致、阶跃后响应                | 自然阶跃增益/饱和                    | current-only模型         |
| state                | 存在、状态转移合理、与功率一致                          | done/功率轨迹                        | 规则状态机               |
| userInputs           | 是否存在、修改次数、申报时间是否过期、历史用户/站点偏差 | 实际disconnect与kWhDelivered，仅离线 | 站点历史区间，不作硬约束 |
| 预测模型             | 近期滚动误差、区间覆盖、场站适用度                      | 测试期实际功率                       | 简单分位数/保守模式      |

 

## ***\*11.3 E5.2 用户申报审计\****

| **分析**     | **说明**                                             |
| ------------ | ---------------------------------------------------- |
| 缺失率       | 按站点、用户ID可用性、月份统计                       |
| 修改动态     | 同会话userInputs次数、最后一次修改距连接/断开时间    |
| 离场申报误差 | requestedDeparture-actual disconnect，仅离线评价     |
| 电量申报差异 | kWhRequested-kWhDelivered，不称“需求误差”            |
| 历史稳定性   | 同用户有足量历史时；否则使用站点/时段分层            |
| 控制价值     | 作为软优先级是否改善实际断开前交付，而非保证真实需求 |

 

## ***\*11.4 E5.3 可信度到约束的映射\****

| **等级** | **约束生成**                                 | **控制动作** |
| -------- | -------------------------------------------- | ------------ |
| T3高     | 使用D1模型上界和较窄区间；可选申报作为软权重 | 正常分配     |
| T2中     | 区间加安全裕量；降低增配幅度                 | 限制重分配   |
| T1低     | 切换滚动分位数/状态机；忽略不可靠申报        | 保守上界     |
| T0不可用 | 固定安全下界或退出本轮增配                   | 仅维持/保护  |

 

## ***\*11.5 基线与Go门\****

| **基线**     | **说明**                             |
| ------------ | ------------------------------------ |
| 统一缺失填补 | 中位数/前值                          |
| 缺失标记模型 | 缺失作为特征，但无控制等级           |
| 统一保守裕量 | 所有会话同一折减                     |
| 字段分支规则 | 有pilot/无pilot两个固定模式          |
| D2可信度分级 | 连续或分级可信度映射到区间和控制动作 |

 

| **结论** | **条件**                                                     |
| -------- | ------------------------------------------------------------ |
| Go       | D2相对统一保守和字段分支规则，减少过度保守或控制损失，同时不增加高估风险；跨字段模式和至少两站稳定。 |
| 模块保留 | 可信度有校准价值，但控制结果与简单缺失标记同效。             |
| No-Go    | 只是缺失值处理或阈值包装；不能产生独立技术效果。             |

# ***\*14. 统计分析、置信区间与失败案例\****

| **原则** | **具体要求**                                                 |
| -------- | ------------------------------------------------------------ |
| 配对比较 | 同一会话/池/日/预算下比较方法，报告差值而非只报独立均值      |
| 分层统计 | 站点、cluster、station、月份、工作日、时段、并发规模、字段模式、质量等级 |
| 置信区间 | 会话/日级cluster bootstrap，95%CI；避免把分钟点当独立样本    |
| 效应量   | 绝对kW/kWh和相对百分比同时报告；显著性不能替代工程量级       |
| 多重比较 | 主指标预注册；其他指标标为探索性，必要时控制FDR              |
| 最差场景 | 报告p95损失、最差站点/月份/会话，不只总体平均                |
| 稳定性   | 确定性方法复跑一致；随机方法≥3种子，报告种子方差             |
| 失败案例 | 抽取至少20个代表性失败会话，保留原始轨迹、状态、模型输出和控制动作 |

 

**主指标优先级：**D1-R主指标依次为：高估/未执行功率电量 → 站级预算跟踪残差 → 交付影响 → 动作与运行时间。MAE/RMSE为辅助指标。

# ***\*17. 关键风险、停止条件与备选转向\****

| **风险**                | **识别信号**                 | **停止/转向**                                      |
| ----------------------- | ---------------------------- | -------------------------------------------------- |
| pilot差异主要是完成尾段 | 尾段排除后事件率接近0        | D1重分配No-Go；状态识别保留                        |
| 自然正阶跃不足          | 无法验证提高pilot后的响应    | 不主张增量能力；收缩为上界/预算修正                |
| 上一周期actual同效      | A2在E2/E4全面等效            | 复杂模型No-Go；评估仅闭环回收是否有价值            |
| 同池无headroom          | 多数差值时无其他响应会话     | 重分配关闭；上界保护模块保留                       |
| 响应仿真器不可信        | 自然阶跃复现差               | E4不得输出闭环收益，只做观察上界分析               |
| JPL估算支配             | 结论对192.7V或离群过滤敏感   | 主效果以Caltech/Office measured为核心，JPL只作聚合 |
| D2只是缺失包装          | 统一保守/缺失标记同效        | D2降为工程模块                                     |
| D3无负迁移              | 合并模型未恶化最差场景       | D3关闭                                             |
| UCSD不可对齐            | 无可信联合时段或功率平衡     | E7使用透明合成背景或停止，不作为主证据             |
| 基准控制器异常          | 能量/SOC不守恒、简单规则反常 | 暂停全部候选，先修复                               |

 

# ***\*18. E8：最终专利方向决策与证据转换\****

## ***\*18.1 一票否决门\****

· 问题不能由材料和真实数据直接支持，或主要依赖合成异常。

· 独立方案依赖真实SOC、准确需求、准确未来离场或设备隐藏原因等普遍不可得变量。

· 最强简单基线同效或更好。

· 技术效果只体现在预测误差，未进入执行、功率跟踪、交付、PCC或储能指标。

· 效果只在单一月份、单一桩点、极少数离群或未验证响应仿真器中出现。

· 关键步骤无法接入当前EMS/充电桩数据接口，或周期计算成本不可接受。

## ***\*18.2 100分方向评分\****

| **维度**               | **权重** | **评分证据**                       |
| ---------------------- | -------- | ---------------------------------- |

# ***\*附录A：核心公式与指标定义\****

| **指标**         | **定义/说明**                                                |
| ---------------- | ------------------------------------------------------------ |
| 响应比           | r(t)=I_actual(t)/max(I_pilot(t), ε)，仅pilot有效时使用       |
| pilot-actual差值 | g(t)=max(P_pilot(t)-P_actual(t),0)，只称差值，不等同EMS未执行命令 |
| 持续事件         | 有效状态下，比例差和绝对差同时超过阈值并持续T_event          |
| 高估功率电量     | Σ max(P_upper或P_cmd-P_actual,0)·Δt                          |
| 区间覆盖         | 未来实际功率落入[lower,upper]的比例                          |
| 区间得分         | 同时惩罚过宽和未覆盖的标准interval score                     |
| 可回收量         | Σ max(P_cmd-P_exec_upper,0)                                  |
| 可吸收余量       | 由自然正阶跃验证的增量响应模型估计                           |
| 有效可重分配     | min(可回收量, 可吸收余量, 站级剩余预算)                      |
| 预算跟踪残差     | \|P_EV_actual-P_EV_budget\|及时间积分                        |
| 交付影响         | 同一会话相对强基线在实际断开前的累计能量差                   |
| 动作总变差       | Σ\|P_cmd(t)-P_cmd(t-1)\|                                     |
