日期：2026-08-06
范围：V2.1 §8.2 八类技术关系，公开检索初筛（非 FTO，不构成法律意见）。

## 1. 单模块拥挤度

| 模块 | 拥挤度 | 关键近邻 |
|---|---|---|
| 多车辆功率回收/重分配 | **高** | ChargePoint 动态功率模块分配族（US11813959B2 / US10150380B2 / US12157387B2 / US12221010B2，2021–2025；claim 11 明确"释放超分配功率供他桩使用"）；Eaton 自适应负载管理（"将未用功率重分配给能吸收的车"）；Enphase 动态负载均衡；ORNL 模块复用架构 |
| 车辆充电能力/taper 检测 | 中 | 充电限流检测（GM US20240343147）、电池 taper 为公知现象、目标充电电流方法（WO2026/003612） |
| 动态功率管理/按响应更新分配 | 中 | 多端口自适应功率管理（US20250145043A1）、通用动态负载管理 |
| EVSE pilot–实际响应差异识别 | **低** | 多为协议合规/占用检测（US20130346025A1、WO2025/078176），未见"桩侧 pilot 阶跃 vs 实际电流持续偏差 → 会话可执行区间"的高密度布局 |
| 模型适用域/回退、申报可信度 | 低 | 相关但侧重调度/预约（US12165224B2），桩侧观测比对空 |

## 2. 结论

- "重分配/回收"概念本身**高度拥挤**（ChargePoint 族 + 负载管理文献已充分覆盖"释放未用功率给他车"），**不能作为独立创新主张**，只能作为价值/应用主张。
- 相对可区分的空间在：**桩侧纯观测（pilot 阶跃→实际响应差）驱动的会话级"可执行功率区间"生成，配合"不超历史观察支持域"的有界保守回收**。E1/E3 证据恰好在桩侧观测层。
- D1-P/D1-R 完整步骤组合（响应差识别 → 可执行区间 → 同池有界回收 → 基于实际响应更新）在检索到的近邻中未见完整同构组合 → **完整 Go 的必要近邻空间存在**，但主轴必须锚定响应差识别与有界性，不得围绕"重分配"泛化主张。

## 3. 实验含义

- 主轴保持 D1-R：基于充电响应状态识别的可执行功率区间生成。
- E3 的重分配机会作为**价值证据链**而非创新点；创新点落在 E2 的可执行区间生成 + E4 的有界回放验证。
