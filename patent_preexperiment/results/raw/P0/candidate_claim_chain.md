# 候选权利要求链（D1-R 主轴，P0 Lite + 审查结论15 主轴冻结）

> **2026-08-08 审查结论15 主轴冻结**：D1-R 重新定义，主线收窄；同池回收重分配降级为 D1-A 条件增强。
> P0 Lite 阶段产生的近邻区分与证据边界仍然有效，作为本链的既有证据背景保留。

## 主轴定位（审查结论15 冻结版）

**基于桩侧可观测的车辆充电响应状态识别，生成车辆短时数据支持的可执行功率区间，
并依据所述区间对光储充站 EV 功率预算实施支持域内有界修正；在响应证据不足或超出
支持域时切换至保护型功率边界；以实际响应闭环反馈更新下一周期。**

真正的链：

```
响应监测 → 响应状态 → 短时区间 → 支持域判断 → 有界预算修正 → 保护回退 → 实际响应反馈
```

**同池回收重分配 = D1-A 条件增强**（不再作为主轴标题/中心价值主张）。只有 E1-Full
自然正 pilot 阶跃验证 + E2 上调能力估计 + E4 闭环收益全部成立，才把
"回收 → 接收车选择 → 再分配"升级到核心权利要求。

创新锚点：
- 状态是桩侧输入—输出响应关系推断的**控制执行状态**，不是车辆 BMS 内部状态；
- 输出的是**短时执行功率区间**（`[P̲_{t+h}, P̄_{t+h}]`），不是预测点 `\hat P_{t+1}`；
- 域内**有界修正** + 域外**保护回退**，比单纯"模型置信度低所以不用"更可形成技术步骤；
- 预算差先定义为**预算修正量**，再路由，不直接宣称"可回收功率"（规避未验证的 C-004）。

## 独立权利要求（草案要素）

1. 获得 EVSE 侧导引信号（有则用）与实际电流/功率时序；无 pilot 时以
   current-only 观测与回退模式处理；
2. 基于仅含在线可观测量的历史窗口（实际功率/电流、pilot、charging state、
   响应持续时间/连续性、前周期/滚动统计、自然 pilot 变化后的历史响应）识别车辆
   短时**响应状态**（概念上：正常跟随/稳态受限/低吸收/斜坡响应/不确定/支持域外；
   具体命名非必要）；
3. 依据响应状态与历史支持证据生成该会话**短时可执行功率区间** `[P̲_{t+h}, P̄_{t+h}]`
   （1/5/15 min）——数据支持的响应区间，当前不得主张"车辆物理最大可充功率"；
4. 判断当前样本是否落入**已验证支持域**：
   - 域内 → 依据区间对会话 EV 功率预算做**有界修正**（不超历史观察支持域）；
   - 域外 → **不外推**，切换保护型功率边界（历史实际/滚动分位数/保护上界）；
5. 预算修正量按约束路由：返还站级 EV 预算 / 分配给已验证有吸收能力的其他会话
   （D1-A，条件）/ 交还站级优化器（BESS/PV/PCC）——先定义修正量，再判断去向；
6. 以**实际响应**而非申报为准更新会话分配与状态（在线闭环反馈）。

## 从属要素（候选从属点）

- 可执行区间更新频率与控制周期（1/5 分钟）及尾段/初始段排除规则；
- 响应差事件持续性判定（T_event）与最小功率阈值（P_on）；
- 自然 pilot 正阶跃对响应状态的可验证性（E1-Full 生死门）；
- 支持域判定与回退规则（估计功率标记 estimated 时的降级；current-only 功率衰减状态频率回退）；
- 信息可信度 → 不同边界 → 不同回退动作（D2-R 潜在第二专利，E5 验证）。

## 与近邻的区分点（P0 + 审查结论15 补充检索）

- vs **动态分配充电功率**（如 CN112829627A 等已有先例）：本链不是简单的
  "某车实际需求小 → 把剩余分给另一辆车"，而是以"响应状态 → 执行区间 → 支持域 →
  有界修正 → 回退"组合为创新核心；
- vs **近期实际功率驱动 limit 调整**（如 US10464435B2）：本链输出带支持域与保护
  回退的短时执行区间并闭环修正站级预算，而非仅以历史供电功率动态设限；
- vs **pilot 控制**（如 US9290104B2 等）：pilot 仅是输入之一，不主张"调 pilot 控功率"；
- 本链**不依赖 BMS/车侧数据**（无真实 SOC/剩余需求/未来离场），纯 EVSE 观测。

## 待验证后定稿（不提前主张）

- E1-Full：问题强度 + 自然正 pilot 阶跃（D1-A 生死门：阶跃前状态必须能区分
  "会响应/不会响应"，否则收缩为 D1-P 保护型）；
- E2/K2：区间 vs 简单方法（last actual / persistence / rolling median /
  rolling quantile / 简单状态机）信息价值门；高估功率改善而非仅 MAE；
- E3-Full/E4：预算跟踪残差 / 交付影响 / 动作频次；简单 persistence 控制对照；
- E4.1：响应仿真器通过后才允许在权利要求中写"回收收益"；
- E8：正式 claim-oriented prior-art search（中/欧专利库 + 非专利文献），
  不能只做关键词近邻搜索。
