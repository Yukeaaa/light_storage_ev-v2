日期：2026-08-06（含 K1.1 五项纠偏重跑）

## 门结论：**K1 条件 Go（K1-M 主机制 Go + K1-X 边界弱证据）**

评审后由"完整 Go"降级为"条件 Go"。五个纠偏重跑结论：
1. **E1 done-relative**：原 45.9% 主口径含大量近完成/降流段事件（83.5% 在完成前 120 min 内）；核心运行段（距完成 >120 min）事件会话率 **12.1%**、中位差 1.28 kW、6 个月稳定、负对照全稳 → K1-M **Go**。
2. **E3 无泄漏**：修复"当前周期信息"泄漏（全部统计 shift(1) + 扰动硬测试）；无泄漏后 caltech A4 候选率 **34.7% [32.0–36.1]**，A2/A3 仅消除 61.5%/26.4%（≤80%）→ **Go**。
3. **E3 指标拆分**：指标 A（预算差值候选窗口）是 K1 唯一门依据；指标 B（有支持域窗口）未验证、门不采信。
4. **配对比较**：同 eligible mask 配对、分池报告、pool-month 等权、日 cluster bootstrap 95%CI；两证据池（caltech 5.5% / current-only 17.2%）独立过 0.5% 日占比线。
5. **门拆分**：K1-M = caltech 主集机制；K1-X = jpl 边界仅方向一致弱证据（核心率 5.3%），不作等权第二池。

**E0-Full 前置条件（未满足前不得扩大开发）**：
1. 无泄漏候选率（E3 指标 A，caltech A4 ≥1% 且 CI 下界 ≥1%……当前下界 32.0%）在 E0-Full 全量/硬切分样本上复现；
2. done-relative 排除后事件率在 E0-Full 复现（核心段 ≥5%）；
3. 最强简单基线不消除 >80% 候选（当前 61.5%）在 E0-Full 复现；
4. E1-Full 自然 pilot 正阶跃验证增量响应 → 才允许 E4 输出闭环收益结论（E4.1 响应仿真器验证为硬前置）；
5. E2 可执行功率区间生成通过前，不输出"可吸收余量"主张。

## 1. E1-Lite（K1.1 done-relative）：K1-M **Go** / K1-X 弱证据

- 主集 caltech：核心运行段事件会话率 **12.1%**（停止线 5%，超 2.4 倍）；中位功率差 **1.28 kW**（工作功率 36.6%）；核心段差值能量 489.7 kWh；事件持续 p50=10 / p95=98.6 min；6 个月核心率 7.8%–17.3%。
- 负对照（核心段）全稳：时间置换 7.5% ≪ 12.1%；post_done=0；排除短会话 12.2%；单一桩 9.6% / 单一月 23.5%。
- **末段集中特征化**：完成前 120 min 内事件占 83.5%（tail 2,285 + mid 1,517 vs core 750）——响应差异在充电末段集中，属问题特征而非失败；核心运行段独立支撑问题强度。
- K1-X 边界 jpl（2020-06/07）：核心率 5.3%、中位差 1.41 kW（86% 工作功率），方向一致（COVID 窗口，弱证据）。
- 详细：`reports/E1_Lite_gate.md`。

## 2. E3-Lite（K1.1 无泄漏 + 配对）：**Go**

- 泄漏修复后（shift(1)，扰动硬测试通过），caltech A4 候选率 **34.7% [CI 32.0–36.1]**（停止线 1%）；pool-month 等权 26.1%。
- A2/A3 消除 61.5%/26.4%（≤80%）→ 最强简单基线无法消除候选。
- 日候选能量（指标 A=预算差值）：caltech 5.5% / current-only 17.2%（两证据池独立过 0.5% 线）；jpl 边界 1.9%（参考）。
- 指标 B（有支持域窗口）未验证，不作吸收证据；"可回收能力"口径禁用至 E4.1。
- 详细：`reports/E3_Lite_gate.md`。
