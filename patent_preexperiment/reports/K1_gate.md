## 门结论：**K1 条件 Go（K1-M 主机制 Go + K1-X 边界弱证据）**

K1.2 五项纠偏重跑结论（K1.1 的 5 项 P0 全部修复后数值）：
1. **E1 阶段切断**：事件在 core/mid/tail 边界强制切断，各段重跑持续 ≥T_event；核心运行段（距 done >120 min）事件会话率 **11.9%**（K1.1 的 12.1% 基本不变，但核心段持续 p95 由 98.6→66.4 min、差值能量 489.7→350.0 kWh 更纯净）、中位差 1.28 kW、6 个冻结月份逐月 ≥5%、负对照全稳（时间置换 7.2% ≪ 11.9%）→ K1-M **Go**。
2. **E3 跨会话污染修复**：历史统计只在 `(session, run)` 组内 shift(1)/rolling，任何 5min 网格断档即冷启动；无污染后主基线改为 **A2（上一连续周期实际）**，caltech 候选率 **21.3%（周期加权）[日等权 21.8%，CI 20.3–23.5]**，A2/A3 仅消除 55.2%/25.2%（≤80%）→ **Go**。
3. **E3 精确配对**：eligible_mask 在 会话×周期 层求交集；月份按冻结周期过滤；周期加权率/日等权率分开报告；日 cluster bootstrap CI 与日等权点估计同口径；消除比例用比例 bootstrap CI。
4. **E3 指标拆分**：指标 A（预算差值候选窗口）是 K1 唯一门依据；指标 B（有支持域窗口）未验证、门不采信。
5. **门拆分**：K1-M = caltech 主集机制（A2 主口径独立过线）；K1-X = jpl 边界仅方向一致弱证据（核心率 5.1%），不作等权第二池。两证据池 = caltech 4.2% + jpl current-only 3.9% 独立过日占比 0.5% 线。

**E0-Full 前置条件（未满足前不得扩大开发）**：
1. 无泄漏候选率（E3 指标 A，A2 主口径，caltech ≥1% 且 CI 下界 ≥1%……当前下界 20.3%）在 E0-Full 全量/硬切分样本上复现；
2. done-relative 阶段切断后事件率在 E0-Full 复现（核心段 ≥5%）；
3. 最强简单基线不消除 >80% 候选（当前 55.2%）在 E0-Full 复现；
4. E1-Full 自然 pilot 正阶跃验证增量响应 → 才允许 E4 输出闭环收益结论（E4.1 响应仿真器验证为硬前置）；
5. E2 可执行功率区间生成通过前，不输出"可吸收余量"主张。

## 1. E1-Lite（K1.2 阶段切断）：K1-M **Go** / K1-X 弱证据

- 主集 caltech：核心运行段事件会话率 **11.9%**（停止线 5%，超 2.4 倍）；中位功率差 **1.28 kW**（工作功率 36.7%）；核心段差值能量 350.0 kWh；事件持续 p50=10 / p95=66.4 min；6 个冻结月份核心率 7.7%–16.9%，**逐月全部 ≥5%**。
- 负对照（核心段）全稳：时间置换 3 种子 7.2%–7.3% ≪ 11.9%（diff 4.6pp，95%CI [1.7, 2.8]pp）；post_done=0；仅实测/计算功率 11.9%；排除短会话 11.9%；单一桩 9.8% / 单一月 23.5%；38 个桩出现核心事件。
- **末段集中特征化**：done 前 120 min 内段事件占 84.8%（tail 2,569 + mid 1,549 vs core 733）——响应差异在充电末段集中，属问题特征而非失败；核心运行段独立支撑问题强度。
- K1-X 边界 jpl（2020-06/07）：核心率 5.1%、中位差 1.43 kW（87% 工作功率），方向一致（COVID 窗口，弱证据）。
- 详细：`reports/E1_Lite_gate.md`。

## 2. E3-Lite（K1.2 连续时态 + A2 主基线 + 精确配对）：**Go**

- 污染修复后（(session,run) 组内 shift/rolling + 缺桶冷启动，回归测试 9/9 通过），caltech **A2 候选率 21.3%（周期加权）[日等权 21.8%，CI 20.3–23.5]**（停止线 1%）；pool-month 等权 21.3%。
- A2/A3 消除 55.2%/25.2%（≤80%）→ 最强简单基线无法消除候选。
- 日候选能量（指标 A=预算差值，A2 主口径）：caltech 4.2% / current-only 3.9%（两证据池独立过 0.5% 线）；jpl 边界 10.8%（参考）。
- 指标 B（有支持域窗口）未验证，不作吸收证据；"可回收能力"口径禁用至 E4.1。
- 详细：`reports/E3_Lite_gate.md`。
