# 09 权利要求架构冻结：独立权项与从属权项池

> 生成时间（UTC）：2026-09-06
> 性质：PD 轨文档。本文件只冻结**权项结构**（写哪些要素、挂哪些从属），不冻结权项语言；语言级草案在条件 1（CN122203352A claims 复核）完成后展开。
> 上游链：04（目标冻结）→ 07（M1–M6 机制拆解）→ 08（PO-SEARCH-1 强制深查 = PASS WITH CONDITIONS）。
> 纪律：禁收益量化；M3–M6 UNVALIDATED，权项语言只作 enablement 表述；术语红线（§5）全程适用；不扩大 prior-art 检索面（08 §7 收口）。

## 1. 架构总则

- **判据回溯**：独立权项的每个必要要素必须能指认其区别性依据（08 §4 覆盖矩阵 / 05 §3 A 层 crowded 结论）；指认不出的要素不得进独立权项。
- **结构冻结 ≠ 语言冻结**：本阶段产出 = 2 个独立骨架 + 8 项从属池。语言草案允许从属池裁剪/合并，**不允许新增独立权项**——新增独立权项 = 新版本 + 重开检索判定（按 05 决策规则）。
- **先架构后语言**：避免一上来堆十几条权利要求，导致区别链被从属稀释；先把"连接关系"钉死在独立权项骨架里（条件 2 的落点）。

## 2. 独立方法权利要求骨架

信号流 E1→E2→E3→E4→E5→E6→E7，镜像 07 的 M1–M6（M1 只保留必要触发 + M2 + M3 + M4 必要桥接 + M5 + M6）。

| 要素 | 内容要点 | M 环 | 必要性/区别性依据 |
|---|---|---|---|
| E1 | 接收站级功率计划与多类型设备实际执行量 | M1 输入 | 只保留偏差检测必需输入；**无预测/未来量**（在线特征红线：禁 disconnect/最终 kWh/future doneChargingTime/真实 SOC/BMS 限值/PCS 拒绝原因） |
| E2 | 逐设备检测计划-执行偏差 e_i（观察值，阈值触发） | M1 | "最小触发"：仅保留检测与触发所必需的语义；检测算法细节全部下沉说明书/从属 |
| E3 | 对 e_i 做成因分类：通信类/瞬态类/持续类 | M2 | 区别链起点；08 §4：全部强威胁对象均未把偏差分类接到边界更新 |
| E4 | 依据持续类分类结果更新设备方向化可信能力边界 (B_i↓^cap, B_i↑^cap) | M3 | 核心区别特征：方向对状态 + 执行证据驱动；判据红线：不得仅以 SOC/近期执行偏差的简单经验函数作为核心判定依据（RD-2 口径） |
| E5 | 由边界与站级计划计算方向性缺口 ΔP↑/ΔP↓ | M4 | 必要桥接：连接边界知识与跨设备重分配；站级计划降级分支下沉从属 D4 |
| E6 | 异构设备等效调节余量映射 ΔP_eq + 方向兼容过滤 + 确定性排序 | M5 | 核心区别特征：跨设备类型 + 方向兼容；概念层 crowded（DR/negawatt），必须与 E3/E4/E7 成链才成立 |
| E7 | 对承接设备执行结果确认，并维持/恢复边界状态 | M6 | 闭环收口：执行确认式维持/恢复；PCC 二级确认下沉从属 D5 |

撰写形态建议：方法权项以计算机实现步骤（Jepson 式）展开；语言草案中必须显式写出 E3→E4（分类结果驱动边界更新）、E5→E6（缺口驱动映射）、E6→E7（指令驱动承接与确认）、E7→E4（确认结果驱动维持/恢复）四条数据依赖——**这就是条件 2 要求守护的连接关系**。

## 3. 独立系统权利要求骨架（方法镜像）

| 单元 | 对应方法要素 | 功能要点 |
|---|---|---|
| 站级控制器 | E1–E7 | 协调下列单元执行闭环 |
| 设备接口 | E1/E6/E7 | 多类型设备通信：接收实际执行量、下发转移指令 |
| 偏差分类单元 | E3 | 通信/瞬态/持续分类 |
| 边界状态维护单元 | E4 | 维护各设备方向对边界状态 (B↓, B↑) 并执行更新 |
| 等效余量映射/转移单元 | E6 | ΔP_eq 映射、方向兼容过滤、排序与指令生成 |
| 执行确认单元 | E7 | 执行结果确认、维持/恢复触发 |

一致性规则：系统权项不得出现方法骨架中不存在的功能模块（防镜像缺口、便于反规避论证）；单元命名在语言草案阶段统一。

| # | 主题 | 挂靠 | 内容要点 | 检索定位（为何值得从属） |

## 5. 撰写纪律（进入语言草案前的硬约束）

- 术语红线（07 §7 全量沿用）：e_i = 执行偏差观察值；ΔP/ΔP_eq = 设计量；禁"可回收能力/可吸收余量"；禁"命令被拒绝/失败"（用"导引/允许电流与实际响应差异"）；未验证响应仿真器不得作收益依据。
- 禁收益量化：权项与说明书不写"提升/节省 X%"类断言；M3–M6 UNVALIDATED → 只写 enablement（可实施性）表述。
- 条件 1：**已解除（2026-09-07）**——CN122203352A 权利要求 10 条全文复核 = 非 knockout（`10_CN122203352A权利要求级复核_条件1解除.md`），语言级草案定稿解锁；背景技术须按 10 §4 引用位写足三重区别。
- 条件 2：独立权项主体 = 组合链（E3→E4→E6→E7 的连接关系）；"动态能力边界"单点不得作为独立主体（A 层 crowded，08 §4）。
- 在线特征红线：E1 输入白名单之外的未来量不得进入任何权项。
