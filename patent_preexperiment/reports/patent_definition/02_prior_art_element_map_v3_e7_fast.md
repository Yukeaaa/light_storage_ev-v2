## 2. 四个高风险现有技术对照

### 2.1 US10464435B2（ChargePoint）— EV 充电站根据功率限制消息动态响应

> 根据近期实际供电历史响应功率限制消息，可用平均值/最大值等历史统计形成限制。

| 元素 | 是否覆盖 | 说明 |
|---|---|---|
| C（历史 actual）| **是** | 近期实际供电历史 |
| B（charger allowable）| 部分 | 功率限制消息 |
| D（B+C 共同限制上调）| **弱/否** | 主要用历史统计形成限制消息，未见"桩侧允许值+历史**共同**双重约束上调" |
| E（信息不足 → 不上调）| **否** | 未见"缺桩侧允许信息时禁止主动上调"的 fail-closed 逻辑 |
| G（园区需求超出 → 只执行可承担部分）| **否** | 充电站级响应，非园区级需求-能力差协调 |
| H（剩余 → BESS/PCC）| **否** | 无园区储能/电网接口协调 |
| I/J（减少执行缺口+BESS 临时补偿）| **否** | 无系统层技术效果 |

**区别锚**：US10464435B2 是充电桩级历史响应；v3 是**园区级控制链**（A→G→H），
且 D（双重共同约束）+ E（信息不足 fail-closed）组合未见。

## 3. 组合风险分析

### 3.1 D+E+G+H 组合（核心杀伤问题）

| 现有技术 | D | E | G | H | D+E+G+H 全覆盖？ |
|---|---|---|---|---|---|
| US10464435B2 | 弱 | 否 | 否 | 否 | **否** |
| US20220153162A1 | 否 | 否 | 弱 | 否 | **否** |
| CN116316754B | 否 | 否 | 弱 | 是 | **否** |
| CN121886483A | 否 | 否 | 弱 | 是 | **否** |

**结论**：无单一文献覆盖 D+E+G+H。两篇组合（如 CN116316754B 提供 H + US10464435B2 提供 C）
仍缺 E（信息不足 fail-closed）和 D（双重共同约束），且无文献教示"将车辆侧历史响应约束
嵌入园区需求-能力差协调链"。

### 3.2 最大残余风险

1. **审查员组合 US10464435B2 + CN121886483A**：前者给 C（历史响应）+ 后者给 A/H（园区协调）。
   - **反制**：仍缺 D（B+C **共同**双重约束，非单独历史）+ E（信息不足 fail-closed）+
     I/J（执行缺口传播技术效果）。组合需"显而易见性"论证，非简单拼接。
2. **审查员把 D 拆成"已知桩侧上限 + 已知历史上限 → 取更小值"常规组合**。
   - **反制**：Claim 1 不写死公式，保护控制链嵌入；D 的"共同约束"上位表述 +
     E（fail-closed）+ G（需求-能力差执行）组合提供整体创造性。

## 4. v3 可争取的窄空间

基于上述，v3 可争取的窄创造性空间在：
> **D（双重共同约束上调）+ E（信息不足 fail-closed）+ G（园区需求超出只执行可承担部分）
> + H（剩余交 BESS/PCC）+ I/J（执行缺口传播技术效果）** 的组合，嵌入园区光储充控制链。

**不争取**：
- 单独 A（园区需求生成）— CN121886483A 已覆盖
- 单独 H（BESS/PCC 协调）— CN116316754B/CN121886483A 已覆盖
- 单独 C（历史响应限制）— US10464435B2 已覆盖
- 宽泛"光储充联合优化"— 拥挤
