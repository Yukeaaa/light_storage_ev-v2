### 2.1c US20180086213A1 / US10230198B2（Schneider）— ★★★★ 最高风险

> 读取上游 EVSE 的 pilot/maximum offer + EV 实际 current draw + 系统可用容量，
> 动态产生新充电 offer。实施方式：在"系统可分配量"和"上游 EVSE 最大允许值"之间取较小值；
> 若车辆实际消耗低于 EMS 给出的 offer，则进一步降低 offer 至实际消费附近。

| 元素 | 是否覆盖 | 说明 |
|---|---|---|
| B（charger allowable）| **是** | pilot/maximum offer |
| C（历史 actual）| **是** | 实际 current draw；实际消耗低于 offer 时降低 |
| D（B+C 共同限制上调）| **★★ 最危险** | "系统可分配量"与"上游 EVSE 最大允许值"取较小值；actual 低于 offer 时降低 |
| E（信息不足 → 不上调）| **否** | 未见"缺信息时 fail-closed 禁止上调" |
| G（需求超出 → 只执行可承担部分）| **弱** | 系统可分配量限制，但非"园区请求-EV 群能力差" |
| H（剩余 → BESS/PCC）| **否** | 无储能/电网接口 |
| I/J（执行缺口+BESS 临时补偿）| **否** | 无系统层技术效果 |

**★ 这是 v3 创造性最危险的攻击点**：Schneider 已教示"pilot + actual + 取较小值"。
`min(pilot, history)` **绝对不能单独作为发明中心**（审查 §19）。

**反制**：
1. Schneider 的"取较小值"是 offer 生成（桩级），v3 是"群汇总 + 请求限幅"（园区级 G）；
2. Schneider 无 E（信息不足 fail-closed 禁止上调）；
3. Schneider 无"历史实际响应支持水平"作为独立上限（其 actual 是当前消耗，非 Q95 历史统计上界）；
4. v3 的 `min(ΔP_req, Σ_i ΔP_i,allow)` 请求限幅是 Schneider 未教示的园区级协调逻辑。
**但创造性论证必须依赖 D+E+G 组合，不能依赖 D 单独**。

## 3. 组合风险分析

### 3.1 D+E+G 组合（核心杀伤问题；corrective audit 后收窄，不含 H）

> **审查 corrective audit 后**：D3 系统效果 train+val FAIL，BESS/PCC（H）降为弱从属，
> 不作为创造性支撑。核心组合收窄为 **D+E+G**（双重约束 + fail-closed + 请求限幅）。

| 现有技术 | D | E | G | D+E+G 全覆盖？ |
|---|---|---|---|---|
| US10464435B2（ChargePoint）| 弱 | 否 | 否 | **否** |
| **US10230198B2（Schneider）**| **★★ 最危险** | **否** | **弱** | **否（但 D 最接近）** |
| US11376981B2（ACN 族）| 弱 | 否 | 否 | **否** |
| US20220153162A1 | 否 | 否 | 弱 | **否** |
| CN116316754B | 否 | 否 | 弱 | **否** |
| CN121886483A | 否 | 否 | 弱 | **否** |

**结论**：无单一文献覆盖 D+E+G。**Schneider（US10230198B2）是 D 的最危险近邻**
（pilot+actual 取较小值），但仍缺 E（fail-closed）和 G（园区级请求限幅）。

### 3.2 最大残余风险

1. **★★ 审查员用 Schneider（D）+ CN121886483A（A/G 架构）组合攻击**：
   Schneider 教示"pilot+actual 取较小值"（D），CN121886483A 教示"园区协调"（A/G）。
   - **反制**：仍缺 E（信息不足 fail-closed 禁止上调）+ G 的具体形式
     `min(ΔP_req, Σ_i ΔP_i,allow)`（请求限幅，非泛泛"协调"）。
   - Schneider 的 actual 是当前消耗（非 Q95 历史统计上界），v3 的 P_history 是因果化
     历史支持水平（shift(1)+窗口+分位），构成不同的技术特征。
   - **但此组合风险高，创造性论证必须明确 D+E+G 的非显而易见性**。

2. **审查员把 D 拆成"已知桩侧上限 + 已知历史上限 → 取更小值"常规组合**（审查 §17）。
   - **反制**：Claim 1 不写死公式，保护"M2 双重限制 + 群汇总 + 请求限幅"控制逻辑；
     D 的"共同约束"上位表述 + E（fail-closed）+ G（请求限幅）组合提供整体创造性。
   - Schneider 使此风险升级为最高，必须靠 E+G 区别。
