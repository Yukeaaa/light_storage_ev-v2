# 07_核心发明机制拆解_执行偏差确认的动态能力边界修正与跨设备功率转移

> 冻结时间（UTC）：2026-09-06
> 性质：PD 轨（`06_治理修订_…` §3）核心产出——把冻结的核心专利目标收窄为一个可从工程控制逻辑自洽成立的连接机制，并拆解为可画成专利附图的技术单元。**本文件是机制设计，不是权利要求**；所有"效果"表述均为可实施性级别（"使得能够…"），禁止收益量化。权利要求起草前 PO-SEARCH-1 深查清单（§8）强制。

## 1. 收窄后的发明核心

> **一种基于设备执行偏差确认的动态能力边界修正及跨设备功率转移机制。**

保护重心不是"估计可用能力"（拥挤区），而是以下连接结构：

```text
站级计划 P*
  ↓ 向设备 i 下发目标 P*_i
设备实际执行 P_i
  ↓ 执行偏差 e_i = P*_i − P_i（带方向）
偏差分类（瞬态 / 通信 / 持续能力不足）
  ↓ 仅"持续能力不足"进入修正，且只修正偏差对应方向
方向化可信能力边界修正
  （正向不足 → 收缩上向边界 B_i↑；负向不足 → 抬高下向边界 B_i↓）
  ↓ 产生方向化可转移需求 ΔP↑ / ΔP↓
异构设备站级等效调节余量映射
  → 方向兼容过滤 → 定向转移
  ↓ 再次观察实际执行
确认 / 恢复 / 继续收缩（闭环）
```

三个设计公理（本机制的骨架，也是与一般 EMS 的分界）：

1. **设备能力是方向化的状态变量，不是常数**：站内为每设备维护**成对**的可信能力边界（上向 B_i↑ / 下向 B_i↓，等价于区间 [P_i,min^cap, P_i,max^cap]），由执行证据与设备状态在线、**按方向分别**修正；
2. **偏差先分类、后动作**：不是任何偏差都触发重调度——瞬态/通信类偏差不进入边界修正（防误收缩）；
3. **转移是定向的、确认式的**：承接设备与转移量由确定性规则选择，转移结果必须经执行观察确认后才回写边界置信度。

## 2. 技术单元拆解（M1–M6）

每个单元按统一七要素描述：输入字段 / 内部状态 / 判定条件 / 输出字段 / 与下一单元的数据关系 / 异常分支 / 恢复条件。

### M1 执行偏差检测

| 要素 | 内容 |
|---|---|
| 输入字段 | 站级计划向设备 i 的目标 P*_i；设备实际执行 P_i（PCS/逆变器/充电模块遥测）；时戳与对齐信息；设备额定/当前运行点 |
| 内部状态 | 滚动偏差序列 e_i(τ)；滑动窗口统计（幅值、方向、持续时间） |
| 判定条件 | \|e_i\| > δ_det（检测阈值，随设备额定缩放）。M5BAT 为 δ_det 的工程量级设计提供实测参考：该数据中单元 schedule–actual 残差 MAE 约为额定功率的 2.0–3.6%，但存在明显重尾，因此 δ_det 不直接取自该 MAE，具体阈值仍需目标设备数据标定。另含时间对齐有效性检查 |
| 输出字段 | 偏差事件（设备 id、时刻、幅值、方向：不足/超出）、偏差序列句柄 |
| → M2 | 偏差事件 + 序列 |
| 异常分支 | 遥测缺失/时戳错乱 → 挂起判定并记数据质量事件，**不产生边界动作** |
| 恢复条件 | 遥测恢复，重新进入检测 |

### M2 偏差持续性/原因判定

| 要素 | 内容 |
|---|---|
| 输入字段 | M1 事件与序列；设备状态字段（status/alarm/derating 标志、保护状态、温度/SOC 等可得者）；设备近期指令历史与确认（ACK）信息；通信质量指标 |
| 内部状态 | 偏差事件计时器（持续时长）；分类状态机 {transient, comm, persistent_shortfall}（可扩展 external_conflict） |
| 判定条件 | transient：T_transient 内自恢复（斜坡未完成/启动阶段）；comm：遥测抖动、时戳跳变、命令无 ACK；persistent_shortfall：偏差持续 > T_persist 且方向一致，且设备状态无反向解释（或 derating/告警与偏差同向印证）。**分类优先级冻结：comm > transient > persistent**（防误收缩） |
| 输出字段 | 分类结果 + 证据计数（连续命中次数） |
| → M3 | 仅 persistent_shortfall 进入边界修正，并携带偏差方向（决定修正哪个方向的边界） |
| 异常分支 | 分类振荡（transient↔persistent 反复）→ 迟滞处理：恢复阈值 ≠ 触发阈值 |
| 恢复条件 | 偏差消失或状态字段解除 |

### M3 方向化可信能力边界更新

| 要素 | 内容 |
|---|---|
| 输入字段 | M2 分类结果（含偏差方向）；当前计划边界 B_i^0（额定/限值/计划限，双向）；持续偏差幅值序列；设备状态 |
| 内部状态 | **成对可信边界 (B_i↓^cap, B_i↑^cap)**（等价于区间 [P_i,min^cap, P_i,max^cap]）；各方向独立的边界置信度（证据计数）与收缩时间戳 |
| 判定条件 | **只修正偏差对应方向**：正向目标无法达到（出力/放电不足）→ 收缩上向边界 B_i↑^cap 至观测持续不足水平；负向目标无法达到（充电不足）→ 抬高下向边界 B_i↓^cap（即充电能力绝对值收缩）。收缩量取**观测持续不足水平**（保守化：不用单点极值）；未受扰动方向的边界保持不变 |
| 输出字段 | 更新后的 (B_i↓^cap, B_i↑^cap)（作为站内分配的硬约束）+ 带方向的边界事件日志 |
| → M4 | 方向化边界差产生 ΔP↑ / ΔP↓ 需求 |
| 异常分支 | 同方向"过交付"（正向过交付 / 负向过充）→ **不收缩该方向**，记为该方向能力上/下界证据（放宽需独立确认条件；本机制默认只收不放的保守原则，放宽为显式例外路径） |
| 恢复条件 | 由 M6 判定（确认式恢复，按方向独立恢复） |

设备类型语义（双向边界的物理必要性）：PV = 0 ≤ P ≤ P_max（调节空间在下方）；BESS = P_min ≤ P ≤ P_max（充/放双边界独立存在）；EV 充电 = 0 ≤ P_charge ≤ P_max（通常承担减载/恢复，非发电承接）；V2G = 回到双边界。统一符号约定（正=放电）下，充电能力表现为负方向边界，标量"上边界"在负方向语义不成立——这是采用成对方向边界的物理根据。

### M4 方向化功率缺口计算

| 要素 | 内容 |
|---|---|
| 输入字段 | 站级计划 P*；各设备成对边界 (B^cap↓, B^cap↑) 与计划边界 B^0；负荷/需求上下文 |
| 内部状态 | 最近一次缺口值（带方向） |
| 判定条件 | 站级计划与方向化可行域的比较：**ΔP↑** = 上向缺口（站级出力目标 − 收缩后可行最大出力）；**ΔP↓** = 下向缺口（站级吸收/充电目标 − 收缩后可行最大吸收量）。缺口方向 = 计划落出方向化可行域的方向 |
| 输出字段 | 方向化可转移需求 ΔP↑ / ΔP↓（含时间窗） |
| → M5 | 方向化缺口 + 候选集合上下文 |
| 异常分支 | 缺口超出站级可承受范围（如变压器余量不足）→ **站级计划降级**并记录缺口事件——这是边界收缩向站级传导的关键分支 |
| 恢复条件 | 对应方向边界恢复后缺口消失 |

### M5 异构资源等效余量映射与定向转移

| 要素 | 内容 |
|---|---|
| 输入字段 | 方向化缺口 ΔP↑/ΔP↓；候选设备集合（其他 PV/BESS/EV 等）各自的**方向化可信边界余量**、本地动作类型、状态、当前执行、可得的状态量（温度/SOC 等，仅作排序特征） |
| 内部状态 | 站级等效调节余量表（按方向）；候选排序表 |
| 判定条件 | **第一步 方向兼容性过滤**：候选的本地动作先映射为站级等效功率贡献 ΔP_eq——设备动作不同，但对 PCC 的站级功率增量方向可等价（例：需补上向 100 kW 时，BESS 增加放电、PV 减少弃光/增加出力、EV 减少充电负荷，均为等效上向贡献；"让 EV 增加充电 100 kW"不兼容）。**第二步 余量排序**：在方向兼容集合内按**确定性规则**（如 ΔP_eq 可信余量/额定 + 状态告警惩罚）排序，非学习；转移量上限 = 候选等效余量与爬坡约束的较小者 |
| 输出字段 | 承接设备 + 方向化定向目标修正值（写为"目标修正"，术语纪律：不使用"命令被拒绝/失败"表述） |
| → M6 | 指令下发，进入执行观察 |
| 异常分支 | 方向兼容集合为空或等效余量不足 → 缺口保持并记录（供站级计划降级/需求侧动作决策） |
| 恢复条件 | 新候选出现或对应方向边界恢复 |

本单元的关键中间量——**设备本地动作 → 站级等效调节余量 ΔP_eq 的映射**——使机制从"设备边界 → 找另一个设备补"升级为"方向化可信边界 → 站级等效调节余量 → 按缺口方向筛选异构资源 → 定向改变不同类型设备的本地目标 → 用设备/PCC 执行共同确认"。此连接关系列入 §6 优先检索焦点。

### M6 执行反馈与边界恢复

| 要素 | 内容 |
|---|---|
| 输入字段 | 转移后各设备实际执行；M1 持续运行产生的新偏差序列 |
| 内部状态 | 确认计数器；恢复计时器 |
| 判定条件 | 确认：承接设备实际执行与转移目标偏差 < δ_confirm → 转移成立，边界修正维持；恢复：被收缩设备在其收缩边界之上持续稳定执行 ≥ T_recover（或状态解除 + 执行确认）→ 边界按保守步长分级恢复（防振荡） |
| 输出字段 | 边界恢复事件；确认/失败记录（回写 M3 置信度） |
| → M3/M4 | 闭环回到边界状态与缺口计算 |
| 异常分支 | 承接设备亦出现 persistent_shortfall → **级联**：该设备进入 M2/M3，缺口重算——机制本体就是"边界确认在闭环中迭代" |
| 恢复条件 | 如上 |

## 4. 与被淘汰方向的分界

- **不以简单经验状态函数为收缩核心依据**：RD-2 在该数据与冻结协议下证明 SOC 20% bin + recent-response 简单经验函数无稳定增量解释力（B3 劣于 B0）。据此设计约束为：**不得仅以 SOC/近期执行偏差的简单经验函数作为能力边界收缩的核心判定依据**；其可作为辅助状态或排序信息，核心收缩证据必须来自持续执行不足及可核验设备状态/限值（PCS/BMS limit、derating/status、饱和、保护、接受值 vs 实际值）。
- **不是重调度器**：M4/M5 不做全站再优化，只做方向化缺口计算 + 等效余量映射与定向转移；计划器 P* 的来源不属于本发明范围（避免撞 MPC/EMS 拥挤区）。
- **不是保护逻辑**：M2/M3 作用于"能力可信度"，不替代保护装置；保护/告警字段是 M2 的**输入证据**。

## 6. 检索焦点锐化（并回 PO-SEARCH-1 深查清单）

机制拆解使强制深查更有靶子，重点检索：

1. M2 类：执行偏差分类/原因判定（tracking shortfall classification、curtailment detection、communication-loss discrimination）；
2. M3 类：**方向化**能力边界状态变量维护（directional capability boundary、adaptive capability limit state machine、derating recovery logic）；
3. M5 类：异构资源**站级等效调节余量映射**（heterogeneous equivalent regulation margin、direction-compatible resource filtering）与定向（非比例/非市场）转移选择规则；
4. M6 类：确认式恢复/防振荡分级恢复（execution-confirmed boundary update）；
5. 组合：M2+M3+M5 的连接关系，以及"方向化边界 + 异构等效余量映射 + 执行确认式更新"整链是否被单篇覆盖（对应 PO-SEARCH-1 C 层）。

## 7. 术语纪律（本文件内生效）

- "执行偏差 e_i"= 目标与实际执行之差（观察值）；"可转移需求 ΔP"= 由边界收缩推导的设计量——两者均不得表述为"可回收能力/可吸收余量"。
- 成对边界 (B_i↓^cap, B_i↑^cap) 在获得真实执行验证前是**设计变量**，不得作为已证能力引用。
- 禁止收益量化表述；本文档全部效果语句为可实施性语句。
