# 07_核心发明机制拆解_执行偏差确认的动态能力边界修正与跨设备功率转移

> 冻结时间（UTC）：2026-09-06
> 性质：PD 轨（`06_治理修订_…` §3）核心产出——把冻结的核心专利目标收窄为一个可从工程控制逻辑自洽成立的连接机制，并拆解为可画成专利附图的技术单元。**本文件是机制设计，不是权利要求**；所有"效果"表述均为可实施性级别（"使得能够…"），禁止收益量化。权利要求起草前 PO-SEARCH-1 深查清单（§8）强制。

## 1. 收窄后的发明核心

> **一种基于设备执行偏差确认的动态能力边界修正及跨设备功率转移机制。**

保护重心不是"估计可用能力"（拥挤区），而是以下连接结构：

```text
站级计划 P*
  ↓ 向设备 i 下发目标 P*_i
设备实际执行 P_i
  ↓ 执行偏差 e_i = P*_i − P_i
偏差分类（瞬态 / 通信 / 持续能力不足）
  ↓ 仅"持续能力不足"进入修正
收缩设备 i 的可信可用边界 B_i
  ↓ 产生可转移需求 ΔP
候选设备选择与定向转移 ΔP
  ↓ 再次观察实际执行
确认 / 恢复 / 继续收缩（闭环）
```

三个设计公理（本机制的骨架，也是与一般 EMS 的分界）：

1. **设备能力是状态变量，不是常数**：站内维护每设备的"可信可用边界"B_i，由执行证据与设备状态在线修正；
2. **偏差先分类、后动作**：不是任何偏差都触发重调度——瞬态/通信类偏差不进入边界修正（防误收缩）；
3. **转移是定向的、确认式的**：承接设备与转移量由确定性规则选择，转移结果必须经执行观察确认后才回写边界置信度。

## 2. 技术单元拆解（M1–M6）

每个单元按统一七要素描述：输入字段 / 内部状态 / 判定条件 / 输出字段 / 与下一单元的数据关系 / 异常分支 / 恢复条件。

### M1 执行偏差检测

| 要素 | 内容 |
|---|---|
| 输入字段 | 站级计划向设备 i 的目标 P*_i；设备实际执行 P_i（PCS/逆变器/充电模块遥测）；时戳与对齐信息；设备额定/当前运行点 |
| 内部状态 | 滚动偏差序列 e_i(τ)；滑动窗口统计（幅值、方向、持续时间） |
| 判定条件 | \|e_i\| > δ_det（检测阈值，随设备额定缩放，工程量级可由 M5BAT 实测偏差分布支撑：持续偏差 2–3.6% 额定属正常执行散布，δ_det 应显著高于该底噪）；时间对齐有效性检查 |
| 输出字段 | 偏差事件（设备 id、时刻、幅值、方向：不足/超出）、偏差序列句柄 |
| → M2 | 偏差事件 + 序列 |
| 异常分支 | 遥测缺失/时戳错乱 → 挂起判定并记数据质量事件，**不产生边界动作** |
| 恢复条件 | 遥测恢复，重新进入检测 |

### M2 偏差持续性/原因判定

| 要素 | 内容 |
|---|---|
| 输入字段 | M1 事件与序列；设备状态字段（status/alarm/derating 标志、保护状态、温度/SOC 等可得者）；设备近期指令历史与确认（ACK）信息；通信质量指标 |
| 内部状态 | 偏差事件计时器（持续时长）；分类状态机 {transient, comm, persistent_shortfall}（可扩展 external_conflict） |
| 判定条件 | transient：T_transient 内自恢复（斜坡未完成/启动阶段）；comm：遥测抖动、时戳跳变、命令无 ACK；persistent_shortfall：偏差持续 > T_persist 且方向一致，且设备状态无反向解释（或 derating/告警与偏差同向印证）。**分类优先级冻结：comm > transient > persistent**（防误收缩） |
| 输出字段 | 分类结果 + 证据计数（连续命中次数） |
| → M3 | 仅 persistent_shortfall 进入边界修正 |
| 异常分支 | 分类振荡（transient↔persistent 反复）→ 迟滞处理：恢复阈值 ≠ 触发阈值 |
| 恢复条件 | 偏差消失或状态字段解除 |

### M3 设备可信能力边界更新

| 要素 | 内容 |
|---|---|
| 输入字段 | M2 分类结果；当前计划边界 B_i^0（额定/限值/计划限）；持续偏差幅值序列；设备状态 |
| 内部状态 | 可信边界 B_i^cap（收缩后）；边界置信度（证据计数）；收缩时间戳 |
| 判定条件 | 收缩量 ΔB_i 取**观测持续不足水平**（保守化：不用单点极值）；B_i^cap ≤ 观测可持续执行水平 |
| 输出字段 | 更新后的 B_i^cap（作为站内分配的硬约束）+ 边界事件日志 |
| → M4 | B_i^0 − B_i^cap 产生可转移需求 |
| 异常分支 | 偏差方向为"超出"（过交付）→ **不收缩**，记为能力上界证据（放宽需独立确认条件，本机制默认只收不放的保守原则，放宽为显式例外路径） |
| 恢复条件 | 由 M6 判定（确认式恢复） |

### M4 功率缺口计算

| 要素 | 内容 |
|---|---|
| 输入字段 | 站级计划 P*；各设备 B^cap 与 B^0；负荷/需求上下文 |
| 内部状态 | 最近一次缺口值 |
| 判定条件 | ΔP = 站级目标 − 收缩后可行最大满足量（方向与窗口一并有定义） |
| 输出字段 | 可转移需求 ΔP（含方向、时间窗） |
| → M5 | ΔP + 候选集合上下文 |
| 异常分支 | ΔP 超出站级可承受范围（如变压器余量不足）→ **站级计划降级**并记录缺口事件——这是边界收缩向站级传导的关键分支 |
| 恢复条件 | 边界恢复后缺口消失 |

### M5 跨设备承接资源选择与定向转移

| 要素 | 内容 |
|---|---|
| 输入字段 | ΔP；候选设备集合（其他 PV/PCS/EV/其余设备）各自的可信边界余量、状态、当前执行、可得的状态量（温度/SOC 等，仅作排序特征） |
| 内部状态 | 候选排序表 |
| 判定条件 | 过滤：可信余量 ≥ 可承接量、状态可用、无反向约束；排序：**确定性规则**（如可信余量/额定 + 状态告警惩罚），非学习；转移量上限 = 候选余量与爬坡约束的较小者 |
| 输出字段 | 承接设备 + 定向目标修正值（写为"目标修正"，术语纪律：不使用"命令被拒绝/失败"表述） |
| → M6 | 指令下发，进入执行观察 |
| 异常分支 | 无合格候选 → 缺口保持并记录（供站级计划降级/需求侧动作决策） |
| 恢复条件 | 新候选出现或边界恢复 |

### M6 执行反馈与边界恢复

| 要素 | 内容 |
|---|---|
| 输入字段 | 转移后各设备实际执行；M1 持续运行产生的新偏差序列 |
| 内部状态 | 确认计数器；恢复计时器 |
| 判定条件 | 确认：承接设备实际执行与转移目标偏差 < δ_confirm → 转移成立，边界修正维持；恢复：被收缩设备在其收缩边界之上持续稳定执行 ≥ T_recover（或状态解除 + 执行确认）→ 边界按保守步长分级恢复（防振荡） |
| 输出字段 | 边界恢复事件；确认/失败记录（回写 M3 置信度） |
| → M3/M4 | 闭环回到边界状态与缺口计算 |
| 异常分支 | 承接设备亦出现 persistent_shortfall → **级联**：该设备进入 M2/M3，缺口重算——机制本体就是"边界确认在闭环中迭代" |
| 恢复条件 | 如上 |

## 4. 与被淘汰方向的分界

- **不是 SOC 函数**：RD-2 硬门证据（B3 劣于 B0）直接冻结为设计约束——B_i^cap 的修正依据是执行偏差序列 + 设备状态字段（PCS/BMS limit、derating/status、饱和、保护、接受值 vs 实际值），SOC/温度仅允许作为 M5 排序特征，不得作为边界收缩的判定依据。
- **不是重调度器**：M4/M5 不做全站再优化，只做缺口计算 + 定向定向转移；计划器 P* 的来源不属于本发明范围（避免撞 MPC/EMS 拥挤区）。
- **不是保护逻辑**：M2/M3 作用于"能力可信度"，不替代保护装置；保护/告警字段是 M2 的**输入证据**。

## 6. 检索焦点锐化（并回 PO-SEARCH-1 深查清单）

机制拆解使强制深查更有靶子，重点检索：

1. M2 类：执行偏差分类/原因判定（tracking shortfall classification、curtailment detection、communication-loss discrimination）；
2. M3 类：设备能力可信度/边界状态变量维护（adaptive capability limit state machine、derating recovery logic）；
3. M5 类：定向（非比例/非市场）转移选择规则；
4. M6 类：确认式恢复/防振荡分级恢复；
5. 组合：M2+M3+M5 的连接关系是否被单篇覆盖（对应 PO-SEARCH-1 C 层）。

## 7. 术语纪律（本文件内生效）

- "执行偏差 e_i"= 目标与实际执行之差（观察值）；"可转移需求 ΔP"= 由边界收缩推导的设计量——两者均不得表述为"可回收能力/可吸收余量"。
- B_i^cap 在获得真实执行验证前是**设计变量**，不得作为已证能力引用。
- 禁止收益量化表述；本文档全部效果语句为可实施性语句。
