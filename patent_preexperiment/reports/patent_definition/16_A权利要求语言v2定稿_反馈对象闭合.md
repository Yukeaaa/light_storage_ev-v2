### 2.1 【e】对象归属注记（本次核心修订）

```text
【修正前（归属不明，字面可错读）】
  【c】更新 A 的状态 → 【d】用 B/C/D 的状态选 B → 向 B 下发修正量
  【e】根据"实际执行结果"更新"所述方向化可用能力状态"
                                      ↑ 谁的？可被读成 A 的     ✗

【修正后（一一对应）】
  【c】更新 A 的持久能力知识 → 【d】按 B/C/D 各自当前状态选 B/C
  → 向 B/C 下发功率修正量 → B/C 执行
  【e】用 B/C 各自的实际执行结果 → 回写 B/C 各自的方向化可用能力状态  ✓
```

**写作要点（三个限定词各司其职）**：

- "**所述承接资源**执行相应功率修正量后的实际执行结果" = **反馈来源**限定为承接资源（而非产生偏差的资源 A）；
- "**根据各承接资源**的所述实际执行结果" = 反馈**逐承接资源对应**（多资源场景下逐资源一一对应）；"**各**"承接了权 7 的**级联承接**形态（承接资源可能被重新确定，故承接资源可能不止一个，反馈对象相应为多个）；
- "**对应**承接资源的方向化可用能力状态" = 每个反馈结果只回写**它自己所属资源**的状态，不交叉回写。

### 2.2 五段链对象闭合（修正后）

```text
A 执行偏差
  → A 归因判定
  → 更新 A 的持久能力知识
  → 得到待补偿站级功率缺口

  → B/C 执行功率修正
  → 用 B/C 各自的实际执行结果
  → 回写 B/C 各自的方向化可用能力状态
```

**与 F6 的边界（再次确认）**：本段回写的仍是**设备持续能力知识**（能力边界 / 可信度），**不是**本次控制事务的 ACK / FAILED / UNCERTAIN / ROLLBACK 状态——A-M6 与 F6 的"更新对象"区别（AGENTS.md PD 轨 §3）在本段得到最终的语言层落实。

**权 2（设备类别实施形式）**
……其特征在于，所述多个可控资源包括光伏设备、储能设备、充电设备和车网互动设备中的至少两种；针对各可控资源分别建立所述方向化可用能力状态，并根据各可控资源所属类别采用对应的能力边界表达方式。

**权 3（三类偏差的显式划分与优先级）**
……其特征在于，所述判定信息包括与通信有效性、控制响应阶段以及执行偏差持续性相关的信息；所述有效性与能力归因判断包括将所述执行偏差划分为通信无效对应的偏差、暂态响应对应的偏差以及持续可用能力受限对应的偏差，且判定优先级为：通信无效对应的偏差优先于暂态响应对应的偏差和持续可用能力受限对应的偏差，暂态响应对应的偏差优先于持续可用能力受限对应的偏差；当判定为通信无效对应的偏差时，在本轮待补偿站级功率缺口的承接资源选择中，不再将该可控资源选作承接资源；当判定为暂态响应对应的偏差时，暂缓更新所述方向化可用能力状态。

**权 4（双迟滞）**
……其特征在于，所述确认采用迟滞方式：由非持续可用能力受限进入持续可用能力受限所依据的第一判定条件，严于其反向退回所依据的第二判定条件；和/或，所述能力边界的恢复采用恢复迟滞，须在恢复迟滞窗口内经所述实际执行结果连续确认后方执行恢复。

**权 5（双方向独立更新与独立可信度）**
……其特征在于，所述方向化可用能力状态包括上向能力边界与下向能力边界，二者相互独立地更新和维持；按所述执行偏差的方向仅更新其中一个方向的能力边界及其可信度，另一方向的能力边界及其可信度保持不变。

**权 6（确定性排序）**
……其特征在于，所述选择至少一个承接资源包括：在方向兼容的所述其他可控资源中，按照预设的确定性排序规则排序，并依序选取承接资源。

**权 7（级联承接失败）**
……其特征在于，当承接资源在功率修正后的实际执行结果不满足确认条件时，在当前功率修正事务中，将该承接资源从后续承接选择中排除，按照所述方向兼容性判断与所述可承接贡献重新确定承接资源，以承接剩余的所述待补偿站级功率缺口；在重新确定出承接资源之前，维持该承接资源经实际执行结果修正后的能力边界。

**权 8（无可承接或仍有剩余缺口 → 调整功率控制要求）**
……其特征在于，当经所述方向兼容性判断后不存在能够承接所述待补偿站级功率缺口的其他可控资源，或者经重新确定承接资源后仍存在剩余待补偿站级功率缺口时，根据所述剩余待补偿站级功率缺口调整所述多个可控资源的功率控制要求，以减小当前要求的调节幅度，并记录所述调整事件以及剩余待补偿站级功率缺口的方向与大小。

**权 9（分级恢复）**
……其特征在于，所述能力边界的恢复分级执行：每一级恢复后获取该级对应的实际执行结果，经确认后方进入下一级恢复；当任一级的实际执行结果不满足确认条件时，暂停恢复并将所述能力边界回退至该级恢复前的值。

**权 10（预设站级功率参考点的优选实施 + 关口二级确认）**
……其特征在于，所述预设站级功率参考点为并网点或关口；所述方法还包括：获取所述并网点或关口的关口实测功率，以所述关口实测功率对所述功率修正的执行效果进行二级确认；当所述关口实测功率的变化量与所述功率修正的预期变化量之间的偏差超出二级确认容许范围时，触发对参与承接的可控资源的方向化可用能力状态进行复核。

**权 11（功率控制要求的实施形式）**
……其特征在于，所述功率控制要求为直接针对各可控资源形成的目标值或约束值，或者由站级目标功率进一步分解得到；所述站级目标功率由站级需量限制、变压器容量约束、并网点限制、上级调度要求、孤网功率平衡要求和优化调度结果中的至少一种确定。
