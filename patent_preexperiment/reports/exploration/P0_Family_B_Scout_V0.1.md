## 0. 本轮唯一要回答的问题

> 同一 PCS / BESS / EVSE 的 `S_rated / I_rated`，
> 在有功服务与无功 / 谐波 / 不平衡治理之间发生容量竞争时，
> 是否存在**超出常规 `P²+Q²≤S²`、三相 OPF/MPC** 的结构性技术矛盾？

**结论：不存在。**

```text
P0-Family B = DOWNGRADED / NO CURRENT RESIDUAL TECHNICAL GAP
```

理由不是"别人申请过"这一条，而是**三重叠加**：

1. **行业已是标准强制项**：IEEE 1547-2018 把 volt-var / volt-watt / frequency-watt 列为强制功能，
   `P` 与 `Q` 谁优先被做成 **UL 1741 SB 认证项**（证书里直接写 `priority modes: [ ] active power [X] reactive power`）
   —— 即"有功 / 无功竞争"是一个**已被标准化的配置选择**，不是一个待解决的结构问题。
2. **商业产品已同时提供全部四项服务**：例如 CoEpo 125 kW PCS 明确列出"有功/无功四象限调节 +
   三相功率不平衡治理 + 低次谐波治理"。
3. **该对象已被**逐项**写入中国专利申请的权利要求**（见 §4.1，**权项级已核**）：
   电能质量指标分解 → 四类需求（有功任务 / 无功补偿 / 谐波补偿视在功率 / 不平衡补偿视在功率）
   → 基于多属性效用理论的**动态权重**（含 SOC 与有功任务需求）
   → **基于权重的变流器容量约束分配** → 指令集 → 多功能补偿电流合成 + PWM。

唯一看起来可能有残余的入口（**热状态跨时间尺度耦合**）也已核实被占据（见 §4.3）：
结温约束与谐波折中的**已授权**专利、以及"按半导体**温度历史**调整电流限值"的**授权**专利。

## 2. 行业真实存在？——**成立，且比 Family A 更硬**

| 事实 | 来源等级 |
|---|---|
| IEEE 1547-2018 把 Volt-Var、Volt-Watt、Frequency-Watt 列为强制；旧版（1547-2003）无 volt-var、功率因数固定 1.0 | 标准/综述页（二手，但为公开标准事实） |
| **无功能力要求：Category B 在额定出力下 `Q ≥ 44%` of rated kVA** | 同上 |
| 工程后果被明确写为"**硬件过尺寸（Hardware Over-Sizing）的代价**"：为在正午同时输出最大有功与大量无功，IGBT 须物理上加大约 10% → 直接抬高资本成本 | 行业实务页（二手） |
| 调试指引明确要求确认："**若启用 Volt/VAR 优先，在有功削减与逆变器电流限制下是否允许放弃有功以达成无功目标**" | 同上 |
| 电压调节与频率支持之间有**优先级规则**（"往往电压优先于频率，但可配置"） | 同上 |

**读法**：`S_rated / I_rated` 在多服务间竞争**是真实的物理与成本问题**，
而且它已经被标准与认证程序"制度化"了 —— 这恰恰意味着**它不是一个开放的结构问题**。

## 3. 商业系统已经做到什么？——**四项一体已是货架产品**

- **CoEpo-125kW PCS**（商用产品页）：明确列出
  ① 有功/无功四象限调节；② 可解决三相功率不平衡；③ 具备治理低次谐波功能；
  并标注"针对用户现场**有功无功平衡、谐波电流畸变、负载三相不平衡调节**提供一站式综合解决方案"。
- **智能逆变器 / DER 市场**：volt-var、volt-watt、freq-watt、limit-active-power 已是并网必备功能，
  由 UL 1741 SB 逐项测试（Anti-Islanding / Ride-Through / Specified Power Factor / Volt-Var /
  Frequency-Watt / Volt-Watt / Limit Active Power）。

**结论**：`S_rated/I_rated` 的四类需求共享**已经是量产能力**，不是待发明对象。

## 4. 现有技术压力（按证据等级列出）

### 4.1 ⭐ CN121507903A —— **本 Family 的正对撞件（权项级已核）**

- **标题**：基于电能质量评估的储能变流器补偿控制方法及系统
- **申请人**：格尔木时代新能源发电有限公司 + 北京华能新锐控制技术有限公司
- **申请日**：2025-10-31　**公开日**：2026-02-10　**权项数**：10（权 10 为系统权）
- **法律状态**：**Pending（申请中，未授权）** → A 公开文本，权利范围可能变动

**权 1 的技术链（逐项）**：

```text
① 对 PCC 三相瞬时电压 + 关键负载三相瞬时电流做电能质量指标分解
   → 度量集合 = {PCC 电压偏差率, 负载电流总谐波畸变率, PCC 电压不平衡度}
② 多维需求计算（输入含 EMS 有功功率指令）
   → 需求集合 = {有功任务需求功率, 无功补偿需求功率,
                 谐波补偿需求视在功率, 不平衡补偿需求视在功率}
③ 基于多属性效用理论的动态权重生成（输入含**电池荷电状态**与有功任务需求功率）
   → 动态权重集合 = {有功权重, 无功权重, 谐波权重, 不平衡权重}
④ **基于动态权重集合，对需求集合做"储能变流器容量约束分配"**
   → 指令集合 = {最终有功指令, 最终基波无功指令,
                 最终谐波补偿电流指令, 最终不平衡补偿电流指令}
⑤ 多功能补偿电流合成 + PWM 生成 → IGBT 驱动信号
```

**权 9** 进一步给出容量分配的判定结构：
`对需求集合与储能变流器额定视在功率做综合需求聚合与**过载判定** → 过载为真时按动态权重做**视在功率容量分配**（基波任务 / 谐波补偿 / 不平衡补偿）→ 指令解构与安全校核`。

**摘要原文（其对"从固定优先级到动态自适应"的自我定位）**：

> "……最终，依据该动态权重体系对储能变流器的**有限容量进行最优分配**。通过该方法，可实现补偿策略
> **从固定的优先级模式向动态自适应模式的转变**，确保在储能变流器容量受限时，优先处理当前最紧急的
> 电能质量问题。"

**为什么这是正对撞**：Family B 想主张的"同一变流器容量在有功与三类治理任务之间竞争 / 分配"，
其**对象、状态量的选取、触发（过载判定）、分配方式（按权重）与控制后果（四类指令）**
在权 1 + 权 9 中已成链。**并且它明确取代了"固定优先级模式"** ——
这同时封掉了"用优先级解决 P/Q 竞争"和"用动态权重解决 P/Q 竞争"两条路。

### 4.3 「热状态耦合」这条唯一残余入口 —— **也已被占据**

Family B 唯一看起来能超出静态 `P²+Q²≤S²` 的方向是：`I_rated` 是**热限制**、
谐波电流引起附加损耗 → 抬高器件温度 → 反过来降低后续有功可用能力，
即"跨时间尺度的热-电耦合状态"。核实结果：

| 文献 | 内容 | 等级 |
|---|---|---|
| **CN121939785B**（**已授权**） | "电网变流器的热控制方法：**平衡低谐波与结温限制**" —— 建立热网络模型、给出结温-开关频率关系与 THD-开关频率关系，在合资格开关频率范围内用热增益函数/损耗函数选最优点 | 说明书级 |
| **"Method for operating a power electronic converter"**（授权件） | 估计半导体温度 → **"is increased or decreased in function of the *history* of temperatures of semiconductors"**、并计入"converter 的 **history**"→ 迭代调整**电流限值** | 说明书级 |
| **US10742110B2**（GE，IGBT reliability） | 随器件温度升高**降低/停止**开关；反向在低出力时段用开关损耗/无功环流维持温度 | 说明书级 |
| **CN121435889A**（IGBT 散热分析，2025-11-03 申请） | 热阻网络 + Cauer 热阻抗 + 有限元求解温度分布场，闭环生成散热优化策略 | 摘要级 |
| **学术（Microelectronics Reliability, 2014）** | "Junction temperature management of IGBT module in power electronic converters" —— 提出**广义双环控制器（温度环 + 电功率环）**，明确"converter 的**功率处理能力取决于功率模块的热应力**" | 论文摘要/正文片段 |

**读法**：① "结温 vs 谐波/THD 折中" 已授权；
② "**按温度历史调整电流限值**"（含历史状态）已授权；
③ "温度环 + 电功率环"（含补偿控制器）2014 年论文即已提出。
→ **"热状态 → 可用容量"这一入口不新，"含历史的电流限值"这一状态形式也不新。**

### 4.4 V1 已确立的相邻禁区（沿用）

- **US10873188B2**（V1 已权项级核）：动态承载能力已按 `location × time interval × DER type`，
  且从属权含**三相潮流**与 **per-phase V / I / P / Q / power factor** →
  「把 V/Q/三相潮流考虑进承载能力」不能作主题。

## 6. 判定

```text
P0-Family B（#6，多维电气约束下的真实站级可承载能力·变流器容量竞争）
= DOWNGRADED
= NO CURRENT RESIDUAL TECHNICAL GAP
= reopen 仅凭下列新证据之一：
   ① 存在超出「额定 S + 过载判定 + 权重分配」的容量语义
      （例如容量本身是与拓扑/相别/时间连续性绑定的非标量对象）；
   ② 出现"多台异构变流器之间治理任务的分配"无法由 OPF/MPC 表达的结构缺口；
   ③ 有新的强制标准/市场机制，使现行"优先级模式 + 容量约束分配"不再合规。
```

**Family B 一并收线。** 按本轮方法与 Family A 同样的口径：
不是"这个方向不能做"，而是**当前建模假设下没有剩余技术机制值得继续投入**。

> **不做的事**：不为 Family B 开启第二层攻击、不找数据、不做仿真、不注册候选。
