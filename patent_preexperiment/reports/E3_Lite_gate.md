# E3-Lite 门报告：同逻辑池重分配机会早期审计（K1.1 纠偏重跑：无泄漏 + 配对比较）

实验编号：E3-Lite（V2.1 §7；K1 冻结；K1.1 纠偏：全部历史统计 shift(1) 无当前周期泄漏）
日期：2026-08-06（K1.1 纠偏重跑）
预注册：`configs/k1_preregister.yaml`（K1_preregister_v1 + k1_1_corrections）
门判定：**Go（无泄漏后候选窗口仍高频；两证据池独立过日占比线；最强简单基线不消 >80%）**

## 1. 结论摘要（K1.1 纠偏后）

- **泄漏修复**：原先"当前控制周期信息"进入预算统计的问题已修复——全部历史统计先聚合 5 min 周期再 `shift(1)`，决策时刻只可见已结束周期；泄漏不变性由扰动硬测试锁定（`tests/test_k11_regression.py`，10/10 全绿）。
- 主集 caltech：35,086 个有效周期（同 eligible mask 配对）中，最强基线 **A4 = min(前一周期 pilot, 滚动 0.9 分位) 候选率 34.7% [95%CI 32.0–36.1]**（停止线 1%，超 34 倍）；pool-month 等权 26.1%。
- 最强简单基线不能消除候选：A2（上一周期实际）消除 61.5%、A3（滚动分位）消除 26.4%（停止线 ≤80%）。消除率 95%CI（日 cluster 配对 bootstrap）均显著 <1。
- 日候选能量占比（指标 A=预算差值，无吸收假设）：caltech 中位 **5.5%**、jpl current-only 中位 **17.2%**、jpl 边界 1.9%——两证据池（caltech + current-only）独立过 0.5% 线。
- 机会分布于 9 个月，非单月/离群驱动（单日占比 ≤1.2%）。
- **指标拆分子项**：`candidate_redistribution_window`（指标 A，K1 唯一门依据，仅预算差值）与 `supported_ref_energy_kwh`（指标 B，历史 headroom 参考上界，**未验证、门不采信**，须 E1-Full 自然 pilot 阶跃验证后才允许作吸收证据）。

## 2. 方法与口径（K1.1 纠偏）

- 池 = site+garage 逻辑池（P1 证据等级）。池标签：`caltech.California_Garage_01`（主集）、`jpl.Arroyo_Garage_01.current_only`（回退池）、`jpl.Arroyo_Garage_01.boundary_2020`（外部边界）。
- 控制周期 = 5 min；有效控制周期 = 池内 ≥2 活跃充电会话；全部历史统计 `shift(1)` 滞后一期。
- 候选修正窗口（指标 A）= ∃ 会话预算差值 ≥0.5 kW，且同池 ≥2 活跃会话；候选能量 = 总预算差值（kW·min→kWh），**无吸收假设**。
- 预算代理：A0 池均分 pilot / A1 会话 pilot / A2 上一周期实际 / A3 滚动 0.9 分位 / A4 min(pilot, 滚动分位)。pilot 类代理仅对 pilot 覆盖 ≥0.5 的周期计算。
- **配对比较**：同一比较组内所有代理都可计算的完全相同周期（available_mask）；分池报告，不跨池混合分母；日 cluster bootstrap 95%CI；pool-month 等权。
- 每池最强基线：caltech 用 A4；jpl current-only 无 pilot 用 A3；jpl 边界用 A4（有 pilot）。

## 4. 停止线判定

| 停止线 | 阈值 | 观测 | 判定 |
|---|---|---|---|
| 无泄漏候选率 ≥1%（caltech A4 配对） | 1% | 34.7% [32.0–36.1] | ✓ |
| 两证据池日占比 ≥0.5%（池独立过线） | 0.5% | caltech 5.5% / current-only 17.2% | ✓ |
| 最强简单基线不消 >80%（caltech 口径） | ≤80% | A2 61.5% / A3 26.4% | ✓ |
| 非单一月/离群 | — | 9 个月，单日 ≤1.2% | ✓ |
| 泄漏自检（扰动硬测试） | 不变 | 通过 | ✓ |

**结论：E3 Go** —— 无泄漏口径下并发候选修正窗口仍高频（34.7%），两证据池独立满足日占比，简单基线无法消除候选，指标 A 作为 K1 唯一门依据成立。指标 B（有支持域的修正窗口）**未验证，不作吸收证据**。

## 5. 术语与边界

- 全部为"预算差值 / 并发候选修正窗口"，未称"可回收能力"。
- 指标 A 不假设另一会话可吸收——仅"存在 ≥2 活跃会话 + 预算差值 ≥0.5 kW"的修正候选窗口。
- 指标 B（supported_ref_energy_kwh）为历史 headroom 参考上界，须 E1-Full 自然 pilot 正阶跃验证增量响应后才允许作吸收证据。
- jpl current-only 的 A3 候选率高于 A2 且 `elimination_A3_vs_A2` 为负（-0.535）——即 rolling 分位在 current-only 池**增加**候选而非消除；因此 jpl 池不引用消除率门，只承担日占比独立过线（17.2%）。
