# E3-Lite 门报告：同逻辑池重分配机会早期审计（K1.2 纠偏重跑：连续时态历史 + 精确配对 + A2 主门口径）

实验编号：E3-Lite（V2.1 §7；K1 冻结；K1.2 纠偏：每会话连续 5min 网格、(session,run) 内 shift/rolling、缺桶冷启动、A2 主基线、会话×周期精确配对、冻结 cycle_month 过滤）
日期：2026-08-07（K1.2 纠偏重跑；K1.2.1 术语统一：冻结月份字段统一为 cycle_month，无数值变化）
预注册：`configs/k1_preregister.yaml`（K1_preregister_v1 + k1_1_corrections + k1_2_corrections）
门判定：**Go（A2 主口径下候选窗口仍高频；两证据池独立过日占比线；最强简单基线不消 >80%）**

## 1. 结论摘要（K1.2 纠偏后；K1.2.1 仅术语统一）

- **跨会话污染修复**：历史统计只允许在 `(session, run)` 组内做 shift/rolling；**任何 5min 网格断档即冷启动**（等效严格">5min 缺口"规则）；当前活跃仅作评价标签、不进任何统计 → 会话 B 不可能借用会话 A 的未来/历史信息。
- **主基线改为 A2（上一连续周期实际功率）**——候选量最低的可执行简单基线；两证据池（caltech / jpl current-only）**均冻结为 A2 口径**（不再用 A4/A3 各自最优口径）。
- 主集 caltech：49,593 个有效周期（会话×周期精确配对交集）中，**A2 候选率 21.3%（周期加权）[日等权 21.8%，95%CI 20.3–23.5]**（停止线 1%，超 20 倍）；pool-month 等权 21.3%。
- 最强简单基线不能消除候选：A2 消除 55.2%、A3 消除 25.2%（停止线 ≤80%）。消除比例（比例 bootstrap，日 cluster 配对）95%CI 均显著 <1：A2 [52.5, 56.4]、A3 [22.3, 27.1]。
- 日候选能量占比（指标 A=预算差值，无吸收假设）：caltech 中位 **4.2%**、jpl current-only 中位 **3.9%**——两证据池独立过 0.5% 线；jpl 边界 10.8%（参考，A4 口径）。
- 机会分布于冻结 6 个月，非单月/离群驱动（单日占比 ≤1.2%）；`n_months_with_opp=6`、`leak_selfcheck=PASS`。
- **指标拆分子项**：`candidate_redistribution_window`（指标 A，K1 唯一门依据，仅预算差值）与 `supported_ref_energy_kwh`（指标 B，历史 headroom 参考上界，**未验证、门不采信**，须 E1-Full 自然 pilot 阶跃验证后才允许作吸收证据）。

## 2. 方法与口径（K1.2 纠偏）

- 池 = site+garage 逻辑池（P1 证据等级）。池标签：`caltech.California_Garage_01`（主集）、`jpl.Arroyo_Garage_01.current_only`（回退池）、`jpl.Arroyo_Garage_01.boundary_2020`（外部边界）。
- 控制周期 = 5 min 连续网格；有效控制周期 = 池内 ≥2 活跃充电会话；全部历史统计在 `(session, run)` 组内 shift(1)/rolling，决策时刻只可见已结束周期。
- 候选修正窗口（指标 A）= ∃ 会话预算差值 ≥0.5 kW，且同池 ≥2 活跃会话；候选能量 = 总预算差值（kW·min→kWh），**无吸收假设**。
- 预算代理：A0 池均分 pilot / A1 会话 pilot / A2 上一连续周期实际 / A3 滚动 0.9 分位 / A4 min(上一周期 pilot, 滚动分位)。pilot 类代理仅对 pilot 覆盖 ≥0.5 的周期计算。
- **精确配对**：`eligible_mask` 在 会话×周期 层求各代理可计算交集；月份按冻结周期月份过滤；周期加权率与日等权率分开报告；日 cluster bootstrap 95%CI 与日等权点估计同口径；消除比例用比例 bootstrap CI。
- 每池主基线：caltech/jpl current-only 用 **A2**；jpl 边界用 A4（有 pilot，作参考）。A4/A3 仅作研究对象，不再承担任何池的门判定。

## 4. 停止线判定

| 停止线 | 阈值 | 观测 | 判定 |
|---|---|---|---|
| 无泄漏候选率 ≥1%（A2 主口径，CI 下界） | 1% | caltech 20.3% / current-only 33.0% | ✓ |
| 两证据池日占比 ≥0.5%（池独立过线） | 0.5% | caltech 4.2% / current-only 3.9% | ✓ |
| 最强简单基线不消 >80%（caltech 口径） | ≤80% | A2 55.2% / A3 25.2% | ✓ |
| 非单一月/离群 | — | 6 个月，单日 ≤1.2% | ✓ |
| 泄漏自检（跨会话/冷启动/精确配对回归） | 不变 | 通过（`tests/test_k12_regression.py` 9/9） | ✓ |

**结论：E3 Go** —— A2 主口径下并发候选修正窗口仍高频（周期加权 21.3%，CI 下界 20.3% ≫ 1%），两证据池独立满足日占比（4.2%/3.9%），最强简单基线无法消除候选，指标 A 作为 K1 唯一门依据成立。指标 B（有支持域的修正窗口）**未验证，不作吸收证据**。

## 5. 术语与边界

- 全部为"预算差值 / 并发候选修正窗口"，未称"可回收能力"。
- 指标 A 不假设另一会话可吸收——仅"存在 ≥2 活跃会话 + 预算差值 ≥0.5 kW"的修正候选窗口。
- 指标 B（supported_ref_energy_kwh）为历史 headroom 参考上界，须 E1-Full 自然 pilot 正阶跃验证增量响应后才允许作吸收证据。
- 边界池（jpl 2020-06/07）作方向一致参考，不作门判定；其 A4 口径 49.2% 高于 K1.1 的 27.5%——因连续网格/精确配对口径下分母由跨会话污染转正确配对所致。
