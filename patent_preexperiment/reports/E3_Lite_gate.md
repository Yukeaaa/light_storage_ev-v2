# E3-Lite 门报告：同逻辑池重分配机会早期审计

实验编号：E3-Lite（V2.1 §7；K1 冻结）
日期：2026-08-06
预注册：`configs/k1_preregister.yaml`
门判定：**Go（强基线后机会仍高频，两池日能量占比达标，无集中）**

## 1. 结论摘要

- 2 个逻辑池（P1 证据等级：site+garage）共 **47,743 个有效控制周期**（5 分钟、≥2 活跃充电会话）。
- 最强预算基线 A4（min(pilot, 滚动 0.9 分位)）下 **17.7%** 有效周期仍有修正机会（停止线 1%，超 17 倍）。
- 上一周期实际功率（A2，消除 70%）与滚动分位（A3，消除 11%）**未消除 >80% 机会**。
- 日潜在修正能量中位数：caltech **3.62%**、jpl **3.21%** 的当日 EV 能量（停止线 0.5%，双池均达标）。
- 机会分布于 9 个月，最高单日占比 1.8%，非单一月/离群驱动。
- 术语纪律：本报告全部为"预算差值/反事实机会"，未称"可回收能力"（回收能力需 E4 闭环验证）。

## 2. 方法与口径（V2.1 §7.3）

- 池 = site+garage（P1 逻辑控制池，ACN 公开数据上限）。
- 控制周期 = 5 分钟；有效控制周期 = 池内 ≥2 活跃充电会话（actual ≥ P_on）。
- 保守修正机会：∃ 会话低于其预算代理 ≥0.5 kW，且 ∃ 另一活跃会话历史实际上界高于其当前代理（吸收能力 ≥0.5 kW）；调整不超出历史观察支持域（滚动 60 分钟 max）。
- 机会能量 = min(总 slack, 总可吸收头寸)（反事实上限，保守）。
- 预算代理：A0 平均分配 / A1 当前 pilot 比例 / A2 上一周期实际 / A3 滚动 0.9 分位 / A4 min(pilot, 滚动分位)。
- 每池最强可用基线：caltech 用 A4；jpl 无 pilot 用 A3（保守，pilot-less 口径）。

## 3. 结果

### 3.1 机会率（各代理，47,743 有效周期）

| 代理 | 机会率 | 说明 |
|---|---|---|
| A0 平均分配 | 35.6% | 弱基线 |
| A1 当前 pilot | 30.2% | |
| A2 上一周期实际 | 10.7% | 强基线，消除 70% |
| A3 滚动 0.9 分位 | 31.7% | 消除 11% |
| **A4 min(pilot, 滚动分位)** | **17.7%** | **最强基线（主口径）** |

### 3.2 能量（6 个月，主样本）

| 池 | 最强基线 | 机会能量合计 | 日修正能量中位 | 占当日 EV 能量中位 |
|---|---|---|---|---|
| caltech.CG1 | A4 | 1,928.0 kWh | ~11.5 kWh/日 | **3.62%** |
| jpl.Arroyo | A3（pilot-less） | 4,508.1 kWh | ~20 kWh/日 | **3.21%** |

注：caltech A4 机会能量（1,928 kWh）≈ E1 差值能量（2,378 kWh）的 81%——重分配视角下大部分响应差落在"另一会话可吸收"的并发窗口内。

### 3.3 分层与集中度

- 9 个月出现机会（2018-11, 2019-03/04/05/08/10 主月份 + 边界跨月）。
- 单日机会能量最高占 1.8%；单池占 70%（caltech 高 pilot 覆盖池），双池均有独立证据。
- 最活跃月份（2018-11）机会周期 1,610，最弱主月份（2019-10）1,288，无异常劣化。

## 4. 停止线判定（V2.1 §7.5）

| 停止线 | 阈值 | 观测 | 判定 |
|---|---|---|---|
| 强基线后机会率 ≥1% 有效周期 | 1% | 17.7%（A4） | ✓ |
| ≥2 逻辑池日修正能量中位 ≥0.5% EV 能量 | 0.5% | caltech 3.62% / jpl 3.21% | ✓ |
| A2/A3 不能消除 >80% 机会 | ≤80% | 消除 70% / 11% | ✓ |
| 非单一月/离群 | — | 9 个月，单日 ≤1.8% | ✓ |

**结论：E3 重分配机会 Go** —— 响应差发生时同池普遍存在其他活跃会话，强简单基线后仍高频存在可修正的预算差值，且能量量级（双池 3–4% 日 EV 能量）达到投入线。

## 5. 术语与边界

- 本报告结论仅支持"逻辑控制池的反事实机会"（P1），不声称设备级共享预算（P2）或现场可回收（P3）。
- jpl 无 pilot：该池全部结论基于 pilot-less 保守口径（A3），不依赖导引信号。
- 机会能量为反事实上限：实际回收受 E4 回放与现场约束（BMS/变流器）限制，需 E4.1 验证响应仿真器后才能输出闭环收益结论。
