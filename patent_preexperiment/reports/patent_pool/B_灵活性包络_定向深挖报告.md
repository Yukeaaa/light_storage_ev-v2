# B 候选定向深挖报告：灵活性包络

**版本**：V1（2026-09-08）
**性质**：PD 轨 cheap-deepening，B1–B5 链条的文献元素扫描
**依据**：B_v0.1_扫描尺子 + 7 篇目标文献

---

## 1. B 候选链条回顾（B-v0.1）

```
B1 单资源方向化可调能力 (up/down, 不是标量)
        ↓
B2 时间尺度 / 持续时长 / 能量耦合
        ↓
B3 异构资源映射到统一站级参考 (PCC)
        ↓
B4 站级聚合 + PCC/变压器公共约束裁剪
        ↓
B5 承诺占用 → 剩余灵活性更新
```

**核心保护对象**：随方向、时间尺度和持续时长变化的站级可交付灵活性边界。

**与 A 边界**：B 假设"设备当前状态已知"，不追问执行偏差归因。B 更新可承诺灵活性，A 更新能力知识。

## 2. 七篇目标文献 B1–B5 元素扫描

### 2.1 lit_id 9（靖志勇 2026）— 最强 B 近邻

**文献**：面向实际场景的光储充一体化系统控制架构优化设计，自动化应用 67(5), 2026

**B1 方向化可调能力：Neighbor（邻域）**
- 公式 `ΔP(t) = α1·P_bess,dis + α2·P_V2G,dis + α3·P_load,shed` 中，各项都是"向下调节"（降低 PCC 上网功率或减少购网功率）
- 方向限定在削峰方向（down），未建模反向（up）能力
- `α` 是静态参数（"可调度裕度"），不随执行反馈调整

**B2 时间尺度/持续时长：无**
- 虽然架构是"分层多时间尺度"（日前/日内/实时），但时间尺度用于调度频率分层，不是灵活性持续时长建模
- 未讨论"100 kW 能维持多久"

**B3 异构方向映射：A-node（有）**
- 异构资源（BESS 放电、V2G 放电、负荷削减）统一归入同一 `ΔP` 补偿任务
- 方向映射隐含：三类资源的动作在 PCC 参考系下都是"减少购网功率"，已对齐
- 但缺少"光伏限发 vs 储能充放电 vs EV 调节"的双向对齐

**B4 公共约束裁剪：A-node（有）**
- 明确以 PCC 功率限制（`P_limit`）作为触发和裁剪条件
- 削峰场景：电网指令给 `P_limit`，系统计算 `ΔP = P_grid,actual - P_limit`

**B5 承诺后剩余：无**
- 无"已承诺/剩余"概念，调度是一次性分配

**判定**：B3+B4 有触及，B1 邻域，B2/B5 全缺失。

### 2.3 lit_id 38（CN121440802A）— B1+B3 统一度量衡

**文献**：基于智能调度的光储充配合优化方法及系统

**B1 方向化可调能力：Neighbor（邻域）**
- "统一度量衡下的可调度能力量化"：充电设备（电池状态 + 柔性充电时间窗口 + 功率范围）、储能设备（剩余充放电能力 + 循环寿命成本）、光伏设备（预测出力曲线）
- 三个"可调度能力"分别量化，但未明确 up/down 方向分离
- "充电时间窗口"隐含时间灵活性，但不是持续时长 × 功率的包络建模

**B2 时间尺度/持续时长：Neighbor（邻域）**
- "柔性充电时间窗口"触及时间维度，但没有"在某个时间尺度内、以某功率水平维持多久的能量约束"的完整建模

**B3 异构方向映射：Neighbor（邻域）**
- "统一度量衡"是概念性的——三种资源的度量方式不同（充电看时间窗口、储能看剩余能力、光伏看出力曲线），只是都放入"调度基线库"
- 没有明确的"在 PCC 参考系下符号对齐"

**B4 公共约束裁剪：无**
- 未看到 PCC/变压器等公共约束裁剪聚合结果

**B5 承诺后剩余：无**
- 调度基线库是"预注册"概念，不是执行后的剩余更新

**判定**：B1/B2/B3 均为邻域级别。"统一度量衡"是概念，不是实施细节。距离 B 链仍有断裂。

### 关键发现

**B1 方向化**：全库无 A-node。所有文献的方向建模都是"削峰/降低功率"单向。未见 up/down 方向对。

**B2 持续时长-能量耦合**：全库无 A-node。lit_id 38 的"柔性充电时间窗口"和 lit_id 30 的"自然日规划"是邻域触及，但都不具备持续时长 × 功率 × 能量的完整耦合。

- **无单篇覆盖 ≥3 个 B-node**

## 4. Cheap-knockout 判定

对照 B_v0.1 冻结判据：

| 判据 | 结果 |
|------|------|
| B1→B2→B3→B4→B5 全链覆盖 | **未发生**（最长连续 2 环） |
| B1/B4 crowded，B2/B3/B5 断裂 | **符合**（B4 有 2 篇 A-node，B1 全邻域，B2/B5 全缺失） |
| 只剩"多资源可调功率求和" | **不**（B2/B5 是明确的创新空间） |
| 多时间尺度包络 + 异构方向映射 + 承诺后残余 | **B2 + B5 空白 = 强 PASS 条件** |

**综合判定：B candidate = PASS**

## 5. B 候选改进方向建议

基于扫描结果，B 的专利价值集中在三个断裂点：

1. **B2 持续时长-能量耦合**：现有文献只给出"现在能调多少"，不回答"能维持多久、在什么时间尺度上有效"。这是 B 链与"普通可调容量"拉开距离的核心。

2. **B5 承诺占用 → 剩余包络**：全库空白。任何"承诺部分从总包络中扣除"的机制都是强差异点。

3. **B1+B3 组合**：up/down 方向对 + 异构方向在 PCC 参考系的符号对齐——现有文献只做单向（削峰），不做反向。

**不建议**：把 B 写成"多资源可调功率求和 + 约束优化"——这在 lit_id 9/12 中已经做过。
