## 1. 引证画像：lit45 的技术实质

| 项 | 内容 |
|---|---|
| lit_id | 45 |
| 文献 | 任汝飞等，《信息能源系统的边缘节点可信评估及控制策略》，《全球能源互联网》3(6)，2020（东北大学） |
| 子库 / 证据层级 | 可信 / 全文级（`converted_fulltext`） |
| 台账口径 | 相关度 B；对 A 五步链判定"无覆盖"；标注"'可信'同词异义" |
| 矩阵口径（gap_hook） | "信息侧信任评估止于通信安全，**未与功率控制资格/能力连接——信息可信→功率可信缺桥**" |

### 1.1 lit45 的机制链（据 C 深挖报告 §2.5）

```text
零信任前提（默认一切数据不可信）
   ↓
可信度评估：二次性能指标 J(q) → 触发器 H(q(t)) = J(q) − J(q)*
            H < 0 → 判定该节点不可信
   ↓
可信权重控制器：c_ij(k+1) = c_ij(k) − ω·μ（连续衰减）
            低于阈值 c_ij → 彻底切除
   ↓
事件触发边缘控制：按信任度调整**信息流的动作权重**
```

### 1.2 关键结构性特征（决定后面每一条反打）

1. **作用对象是信息流**：c_ij 是网络邻接权重，调低它 = 降低该节点信息对控制决策的**影响程度**。
2. **状态空间连续**：可信度是 [0,1] 连续量，不存在离散等级。
3. **单向**：只有衰减 → 切除方向，**无恢复**。
4. **输出消费方是信息融合环节**，不是调度器或命令下发环节。
5. **问题域是信息安全**（防数据混淆 / 防攻击），不是设备控制可用性。

## 2. 权 1 逐限定项反打

| 权 1 限定 | lit45 | 反打重点 |
|---|---|---|
| **[a]** 获取运行状态信息 + 异常指示信息 | **部分有** | 单点不争 |
| **[b]** 持续维护 ≥3 个离散控制参与资格等级 | **未见公开** | 连续可信权重 ≠ 离散控制资格 |
| **[c]** 等级 → 允许控制动作范围 | **未见公开** | 权重改变的是信息影响程度，不产生控制动作集合 |
| **[d]** 资源准入 + 控制动作下发约束 | **未见公开** | 作用对象是信息流，不是 EMS 可控资源与设备控制动作 |
| **[e]** 同一资格状态的恢复 + 权限重新开放 | **未见公开** | lit45 只有衰减 / 切除，没有资格恢复闭环 |

### 2.1 【a】获取运行状态信息 + 异常指示信息 —— 部分有，**单点不争**

**审查员可能主张**：lit45 的零信任框架持续监测节点状态并据此评估可信度，已构成对设备运行状态信息的获取。

**判定**：**接受该主张，不在 [a] 上争。**

**理由**：本草案已把 [a] 定位为**技术输入锚点**而非创造性来源（Claim Draft §1 写作注记）。与 lit45 在"获取状态信息"这一层纠缠无胜算，也不需要——权 1 的创造性主链在 `[b]→[c]→[d]→[e]`。

**落点**：说明书背景技术中把 lit45 归为"已获取设备状态但未用于确定控制参与资格"的现有技术，不做区别论证。

### 2.2 【b】≥3 个离散控制参与资格等级 —— **未见公开**

**审查员可能主张**：lit45 的可信度存在高/低分档与切除阈值，实质是多级资格。

**反打**：

1. **状态空间性质不同**：lit45 的 c_ij 是连续权重，可由阈值人为切档，但**档位不是机制的固有状态**。本申请的"至少三个离散等级"是**定义资格本身的离散状态空间**，等级之间的迁移是资格状态迁移，而非对连续量取阈值。
2. **等级承载不同语义**：本申请的等级直接绑定"允许完整 / 允许受限 / 不允许"的动作权限语义（见【c】）；lit45 的权重高低只表示"信息可信程度"，不承载动作权限语义。
3. **数量下限的意义**：本申请以"至少三个等级"排除二元开关——这正是 lit45 与普通 EMS 的共同形态。若 lit45 被读作两级（可信 / 切除），则它**恰好落在被本限定排除的形态内**。

**落点**：权 1【b】"具有至少三个等级的离散等级"；说明书显式区分"连续可信权重的阈值分档"与"离散资格等级状态空间"。

### 2.3 【c】等级 → 允许控制动作范围 —— **未见公开**

**审查员可能主张**：lit45 调低权重即限制了该节点的作用，等价于限制其控制动作。

**反打**：

1. **作用对象不同**：lit45 限制的是**信息流参与控制决策的权重**（该节点的量测/数据对融合结果影响多少）；本申请限制的是**该设备被允许执行的控制动作集合**。
2. **不产生动作集合**：连续权重衰减**不产生**"允许哪些控制类型、允许哪个控制方向、控制幅度上限是多少"这一组集合语义。权重再低，也不会表达出"允许放电但禁止充电"或"排除某类控制动作"。
3. **中间受限态非空**：本申请【c】要求较低等级的允许控制动作范围**相对于较高等级受进一步限制但可以非空**；lit45 是单调衰减，不存在"受限但可参与"的离散中间态。

**落点**：权 1【c】"限制包括控制类型、控制方向和控制幅度中的至少一种"；退守位 ①（权 3 / D2）把该限定进一步具体化。

### 2.4 【d】资源准入 + 控制动作下发约束 —— **未见公开**

**审查员可能主张**：lit45 的切除机制已经从系统中排除了不可信节点，构成资源准入控制。

**反打**：

1. **被排除的对象不同**：lit45 切除的是**节点在信息网络中的参与度**；本申请【d】确定的是**设备是否被纳入参与调度的可控资源集合**——这是 EMS 调度资源池的成员资格，不是通信/信息网络的参与资格。
2. **两个不同的控制后果**：本申请【d】同时产生"是否纳入可控资源集合"（集合级）与"限制能够下发的控制动作"（动作级）两个后果；lit45 的权重作用于信息融合环节，**既不决定设备能否被下发控制动作，也不决定其是否算作调度资源**。
3. **输出消费方不同**：lit45 的输出进入信息融合；【d】的输出进入**调度器 / 分配器**的候选资源范围。

**落点**：权 1【d】；退守位 ③（权 5 / D7）把集合级后果写成"全集 / 受限子集 / 移出"三态。

### 2.5 【e】同一资格状态的恢复 + 权限重新开放 —— **未见公开**

**审查员可能主张**：通信网络自愈或信任恢复后可重新纳入，等价于资格恢复。

**反打**：

1. **lit45 机制内无恢复方向**：其控制器只实现衰减（c − ω·μ）与切除，**不含由低等级升至等级的判据**。
2. **恢复对象不同**：本申请【e】恢复的是**同一控制参与资格体系内的等级提升**，并据此**重新确定允许控制动作范围与资源准入条件**——即权限的重新开放。lit45 即使信任回升，也只是信息权重的数值变化，不产生"权限重新开放"这一控制语义。
3. **"恢复"不是保护复归**：本申请的恢复由**资格判据**驱动且与动作范围/资源准入联动；它不是设备内部保护动作的自动复归。

**落点**：权 1【e】；退守位 ②（权 4 / D5）以连续确认/阈值的非对称化，进一步与"保护复归"拉开距离。

## 3. 组合论证防御（本轮真正的风险）

当前单一引证未见 [b]–[e] 完整公开，权 1 **未被该单篇文献直接击穿**；但**创造性仍需面对组合论证**——这才是本轮真正的风险：

> lit45 已经有动态可信等级与切除，普通 EMS 又已知故障设备剔除与恢复，因此把可信度用于资源池准入是否只是常规应用？

必须正面拆掉这一论证。四条防线：

### 防线 1：结合启示缺失——跨域改造并非显而易见

| | lit45 | 普通 EMS 故障剔除 |
|---|---|---|
| 技术领域 | 信息安全（零信任、防数据混淆/攻击） | 设备保护（防设备损坏） |
| 作用对象 | 信息流权重（邻接矩阵） | 设备在池/不在池 |
| 状态空间 | 连续 [0,1] | 二元 |
| 输出消费方 | 信息融合 | 资源调用 |
| 恢复 | 无 | 保护复归 |

把 lit45 的"信息安全可信度"改造为本申请的"控制参与资格"，需要**同时**改变四件事：作用对象（信息流 → 控制动作 + 资源集合）、状态空间（连续 → 离散）、恢复方向（无 → 有）、输出消费方（信息融合 → 调度器）。组合论证要成立，须给出明确的**结合启示来源**；两文献分属信息安全与设备保护两个技术领域、解决不同技术问题，不存在自然的结合动机。

### 防线 2：【c】+【d】的双重控制后果是 lit45 结构上做不到的

这是最强的防线，也是 Claim Draft §4 的设计目的：

```text
                    ┌─→ 【c】允许控制动作范围（动作级）
控制参与资格 ───────┤      完整 / 受限非空 / 空
                    └─→ 【d】是否纳入可控资源集合（集合级）
```

- lit45 的权重即使衰减到阈值以下被"切除"，被切除的仍是**信息通道的参与度**，不是"设备被允许执行的控制动作集合"，也不是"设备在调度资源池中的成员资格"。
- 因此即便审查员把 lit45 的"切除"直接读作本申请的第三等级，**【c】的中间受限等级非空动作范围**仍然是 lit45 无法表达的——lit45 是单调衰减，不存在"允许单向动作、禁止反向动作"这类离散集合语义。
- 结论：这不是"把连续权重换成开关"，而是引入了 lit45 不具备的两个控制语义维度。

### 防线 3：【e】的恢复闭环与二元复归不是同一手段

普通 EMS 的"故障剔除—恢复"是**二元**的（在池 / 不在池），触发源是设备保护动作复归。本申请【e】是**同一资格体系内的等级提升**，且同时重新确定动作范围与资源准入条件。二者在状态空间（离散多级 vs 二元）、触发源（资格判据 vs 保护复归）、后果（权限重新开放 vs 重新入池）三个维度上都不同。

### 防线 4：把防御下沉到从属梯（退守位）

即使权 1 在组合论证下被削弱，退守位 ①②③ 提供第二层防线，使 C 不至于一次失守（见 §4）。

### 3.1 组合论证防御小结

| 审查员论点 | 防御 | 依赖的权项 |
|---|---|---|
| lit45 可信等级 ≈ 资格等级 | 连续权重 ≠ 离散资格状态空间 | 权 1【b】 |
| 权重降低 ≈ 限制控制 | 信息影响程度 ≠ 控制动作集合 | 权 1【c】+ 权 3 |
| 切除 ≈ 资源准入控制 | 信息网络参与度 ≠ 调度资源成员资格 | 权 1【d】+ 权 5 |
| 自愈 ≈ 资格恢复 | 数值回升 ≠ 权限重新开放 | 权 1【e】+ 权 4 |
| 两篇结合 = 常规应用 | 跨域四要素同时改写 + 结合启示缺失 | 权 1【c】【d】【e】 |

## 4. 从属梯四类退守位的针对性防御

按 Claim Draft v1.1 §2 的排序，权 3/4/5（D2/D5/D7）为三类核心退守位，权 8（D6）经 v1.1 重写后成为第四类（恢复向）退守位，各自对抗一种特定攻击。

### 退守位 ① —— 权 3（D2）中间受限等级的具体动作限制

**对抗攻击**：把本申请的资格分级读作"二元故障剔除的细分"，即"能用/不能用"换个说法。

> **交叉引用更正（2026-09-10，随 Claim Draft v1.2）**：本句原写"本申请的**四级资格**"，对应 Claim Draft v1 的 D1。v1.2 已将资格骨架改为**三级 + 第三等级内两个子状态**（仅观测 / 完全阻止），故此处表述同步更正为"资格分级"。**实质含义不变**——两个子状态仍为空控制动作范围，本退守位对抗"二元剔除"的论证不因此改变。本次仅更正交叉引用，**未重做压力测试**（权 1 未变动）。

**防御要点**：权 3 明确第二等级的动作范围**非空且多维受限**（仅允许单一控制方向 / 排除特定控制类型 / 控制幅度上限更低）。**二元剔除在结构上无法表达"允许放电但禁止充电"**——这是本退守位的核心。

### 退守位 ② —— 权 4（D5）恢复迟滞与连续确认

**对抗攻击**：把本申请的恢复读作"普通保护装置的故障复归"。

**防御要点**：权 4 的恢复判据为"预设持续时间内连续满足 / 连续多个采样周期满足 / 恢复阈值区别于降级阈值"中的至少一种，且其后果是**等级提升 + 动作范围与资源准入条件重算**。与保护复归（设备内部条件满足即复归、无权限重算语义）在触发源、粒度、后果三方面均不同。

### 退守位 ③ —— 权 5（D7）资源集合动态加入 / 移出

**对抗攻击**："C 只做动作权限，不涉及调度资源池"——从而把 C 降格为动作过滤逻辑。

**防御要点**：权 5 把等级显式映射到**可控资源集合的三态**（全集 / 受限子集 / 移出），使集合级控制后果成为白纸黑字的从属限定。这同时把 lit45 的"信息网络参与度"与本申请的"调度资源成员资格"彻底分开。

### 退守位 ④（v1.1 新增）—— 权 8（D6）渐进恢复顺序

**对抗攻击**：主张"低等级恢复时直接跳回完整权限"即可，无需分层试探。

**防御要点**：权 8 保护的是**恢复过程中的"先试探、后升级"顺序**——初步恢复条件成立时**维持第二等级**、仅开放单一控制方向（落在权 3 已允许的受限动作范围内）；执行确认后才升至第一等级并开放完整动作范围。它既不是"恢复"本身（权 1【e】已覆盖），也不是"动作受限"本身（权 3 已覆盖），而是**二者之间的过渡顺序**。

> **另一重价值**：v1.1 重写后，权 8 不再与权 1 的"第一等级 = 允许完整控制动作"定义冲突，因此**在答审中可安全启用**。v1 原稿在此处存在内部语义矛盾，即便写出也实际上不可用——这正是本次 P1-2 阻塞的实质。

权 3（动作限制）· 权 4（恢复迟滞）· 权 5（资源集合三态）
