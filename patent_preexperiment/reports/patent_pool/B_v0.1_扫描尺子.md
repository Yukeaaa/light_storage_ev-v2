# B 候选扫描尺子 V0.1

**版本**：V0.1（2026-09-08）
**性质**：PD 轨 cheap-deepening 预注册，只冻结链条结构，不写公式/算法/权利要求
**依据**：13 号方法论转变 + B 候选与 A 候选的边界定义

---

## 1. 一句话冻结

> **将光伏、储能及充电资源的方向化局部可调能力，结合时间尺度、持续时长及能量约束映射至统一站级功率参考点，经公共电气约束裁剪形成站级可承诺灵活性包络，并根据已接受的调节承诺更新剩余灵活性包络。**

---

## 2. B1–B5 链条定义

### B1：单资源方向化可调能力

**对象**：每个设备/资源类型，在当前位置，向上/向下各能调多少。

**要求**：至少区分 up/down 两个方向（标量可调容量不计为 B1）。

**典型示例**：
- BESS：向上放电能力 ≠ 向下充电能力
- EV：降低充电功率 vs 增加充电功率 vs 延后任务
- PV：向下限发能力（单向）

**与 A 边界**：B1 假设"设备当前状态已知"，不追问"为什么设备实际没做到"。A 更新能力知识，B 基于已知状态计算可承诺量。

### B2：时间尺度 / 持续时长 / 能量耦合（关键节点）

**对象**：可调能力随能维持多久、在多长时间内有效而变。

**要求**：至少表达以下维度的组合：
- 方向 × 功率 × 持续时长 × 时间尺度 × 能量预算

**典型问题**：
- "储能现在还能放 100 kW"≠ "能维持多久？"
- "EV 能少充 200 kW"≠ "未来 30 分钟都能少充吗？"
- 必须考虑剩余需求电量、离站时间、最迟完成时间

**与普通可调容量的区别**：标量或瞬时可调容量不具备 B2。

### B3：异构资源映射到统一站级参考

**对象**：不同资源类型的方向语义统一到站级功率参考点（PCC / 变压器）。

**要求**：PV 限发、BESS 充放电、EV 充电速率变化的方向映射关系。

**典型问题**：
- PV "向下" = 限发 → PCC 净注入减少
- BESS "向上" = 放电 → PCC 净注入增加
- EV "向下" = 降充电 → PCC 净负荷减少 → 净注入增加
- 三者在 PCC 参考系的符号对齐是聚合前提

**与简单求和的区别**：`P_flex = Σ P_i` 不计为 B3。

### B4：站级聚合 + 公共约束裁剪

**对象**：理论聚合包络经公共电气约束裁剪后形成站级可交付包络。

**要求**：至少一种公共约束（变压器容量、PCC 进/出限制、反送限制、母线/支路约束）。

**术语约定**：用"可交付/可承诺"而非"可用"——表达"全站在公共耦合约束下真正能对外承诺"。

### B5：承诺占用 → 剩余灵活性更新

**对象**：接受调节任务后从包络中占用对应方向、持续时间和能量预算，得到残余包络。

**要求**：已承诺部分从总包络中扣除，剩余包络可被后续任务使用。

**与 A 边界**：B5 更新"尚未被承诺占用的可交付灵活性"，不是"执行偏差修正能力状态"。不做执行反馈。

---

## 3. 扫描矩阵定义

文献对 B1–B5 每个节点的判定：

| 判定 | 含义 |
|------|------|
| A-node（有） | 明确披露该节点的核心机制 |
| Neighbor（邻域） | 触及但不等于该节点（如"可调容量"≠ B1 方向化） |
| 无 | 未触及 |

**邻域与 A-node 分离**：
- "可调容量/可调功率"→ B1 邻域（标量，非方向化）
- "多时段调度"→ B2 邻域（有时间维度但不一定有持续时长/能量耦合的灵活性边界）
- "聚合"→ B3 邻域（简单聚合，无方向映射）
- "约束优化"→ B4 邻域（有约束但不一定是公共约束裁剪聚合包络）
- "滚动优化"→ B5 邻域（有更新但不是承诺占用模型）

---

## 4. Cheap-knockout 判据

| 组合 | 判定 |
|------|------|
| B1→B2→B3→B4→B5 全链覆盖 | **高风险，B 需重新设计** |
| B1/B4 crowded，B2/B3/B5 断裂 | **PASS，继续** |
| 只剩"多资源可调功率求和" | **HOLD** |
| 多时间尺度包络 + 异构方向映射 + 承诺后残余 | **强 PASS** |

---

## 5. 不属于 B 的东西

- **执行偏差归因** → A 链
- **控制参与资格判定** → C 链
- **调度目标函数设计**（如成本最小化、需量管理） → 背景技术
- **预测模型**（PV 出力预测、负荷预测） → 前提假设，不是 B 的核心
- **市场出清/报价策略** → 超出范围，除非与灵活性包络直接相关
