# C 候选独立权架构反审

**版本**：V1（2026-09-09）
**性质**：PD 轨权利要求语言级反审；不扩 prior-art、不做新实验、不重新设计 C
**依据**：C 深挖报告、C OpenCEM Cheap Validation 报告、横向评审 V1（含五项修订）、A 12 号反审（格式参考）
**目标**：把 C 从"故障设备是否可控"的泛化概念，压成"持续资格状态 → 动作权限映射 → EMS 资源池门控 → 同一资格状态恢复"的技术链

## 第一部分：三栏表——C1-C5 逐项审查

| 子特征 | 归类 | 判定理由 |
|---|---|---|
| C1-1 获取设备运行状态（在运/停机/检修等） | **必要特征** | 控制资格的最基本判定输入，不写入则权项缺少技术锚点 |
| C1-2 获取告警/保护触发信息 | **必要特征** | 是区分"不能控"与"不宜控"的条件源，必须保留但须泛化表述 |
| C1-3 获取通信或数据有效性 | **应降从属** | 通信失效是异常指示的一种工程实现，独立权中上位表述已覆盖 |
| C1-4 获取控制通道状态 | **应降从属** | 同上，属于异常指示的子类，D 项细化 |
| C1-5 具体字段名（outstatus/sysalarmflag/der* 等） | **禁止写入独立权** | OpenCEM 专有字段，写入即限缩为单一平台 |
| C2-1 形成离散等级的控制参与资格 | **必要特征** | 离散等级是与 lit45 连续权重的根本区别 |
| C2-2 四状态名（FULL/LIMITED/BLOCKED/OBSERVE） | **禁止写入独立权** | 写死四状态=限定实施例，竞争对手用三或五级即绕开 |
| C2-3 资格随条件变化持续更新 | **必要特征** | 动态性是区别于静态配置的核心 |
| C2-4 更新触发机制（事件驱动/周期扫描） | **应降从属** | 实现细节，独立权只要求"持续更新" |
| C3-1 资格→允许控制类别的映射 | **必要特征** | 区别于"检测故障→剔除"的关键：不只是在/不在，而是能做什么 |
| C3-2 资格→允许控制方向的映射 | **应降从属** | 方向限定是退守位，"动作范围"已做上位覆盖 |
| C3-3 资格→允许动作范围的映射 | **必要特征** | 与 C3-1 共同构成"权限集合"概念 |
| C3-4 映射关系的具体表格或函数 | **禁止写入独立权** | 实施例细节 |
| C4-1 资格门控可控资源池 | **必要特征** | C 的系统级作用点，缺失则退化为单机告警 |
| C4-2 资格门控具体控制动作的下发 | **必要特征** | 与 C4-1 共同构成"双重门控"，区别 A 候选能力边界 |
| C4-3 资源池动态加入/剔除机制 | **应降从属** | 实现细节，独立权中"门控"已覆盖 |
| C5-1 恢复判据 | **必要特征** | 无恢复则 C 链不完整，且与 lit45 的核心区别在此 |
| C5-2 恢复后重新开放控制范围 | **必要特征** | 与 C5-1 配对，构成闭环 |
| C5-3 恢复条件与降级条件的非对称性 | **应降从属** | 迟滞有价值但不必入独立权 |
| C5-4 恢复后的试探性控制或分级恢复 | **应降从属** | 工程实现细节 |

## 第二部分：五种退化逐一防御

### 退化 1：退化成"检测故障→不参与→恢复后参与"

**退化语言：**
> 当检测到设备故障时，将其从可控资源池中剔除；故障消除后重新加入。

**为什么失败：** 任何 EMS 的基础故障隔离逻辑。Novelty 为零。

**正确语言：**
> 所述控制参与资格具有至少三个离散等级，每一等级对应不同的允许控制动作集合，资格等级变化时目标设备按等级进入资源池的不同子集，而非仅在"参与"与"不参与"之间切换。

### 退化 2：四状态名写死

**退化语言：**
> 所述控制参与资格包括完全参与、受限参与、完全阻止和仅观测四种状态。

**为什么失败：** 竞争对手用三状态或五状态、或改名即可绕过。

**正确语言：**
> 所述控制参与资格为离散等级，至少包括：允许完整控制动作的第一等级、允许受限控制动作的第二等级、以及不允许控制动作的第三等级。

### 退化 3：OpenCEM 字段写入权项

**退化语言：**
> 根据设备的 outstatus 字段和 sysalarmflag 字段判定控制参与资格。

**为什么失败：** 限缩为单一平台。IEC 61850、Modbus 等不落入。

**正确语言：**
> 获取目标设备的运行状态信息和异常指示信息，所述异常指示信息用于表征所述目标设备当前不适合执行全部或部分控制动作。

### 退化 4：LIMITED ≈ 降低功率

**退化语言：**
> 所述受限等级表示降低设备的控制功率。

**为什么失败：** "降低功率"是 A 候选的语义空间。C 与 A 重叠。

**正确语言：**
> 所述第二等级对应的允许控制动作集合是所述第一等级对应的允许控制动作集合的真子集，其差异包括控制方向、控制类型、控制幅度上限中的至少一种。

### 退化 5：C5 ≈ 故障解除后恢复

**退化语言：**
> 当故障消除时，恢复设备的控制参与资格。

**为什么失败：** 所有保护装置标配。lit45 虽无恢复，但大量过流/过温保护复归可引用。

**正确语言：**
> 当所述异常指示信息满足恢复判据时，将所述控制参与资格从较低等级提升至较高等级，并根据提升后的等级重新确定所述允许控制动作集合，所述恢复判据与所述控制参与资格降级的触发条件不相同。

## 第三部分：C 独立权骨架草案

### 方法独立权（权 1）

> 一种能源管理系统中设备控制参与资格的控制方法，包括：
>
> **【a】** 获取目标设备的运行状态信息和异常指示信息，所述异常指示信息用于表征所述目标设备当前不适合执行全部或部分控制动作；
>
> **【b】** 根据所述运行状态信息和异常指示信息，确定所述目标设备的控制参与资格，所述控制参与资格为具有至少三个等级的离散等级，至少包括允许完整控制动作的第一等级、允许受限控制动作的第二等级、以及不允许控制动作的第三等级，所述控制参与资格随所述运行状态信息和异常指示信息的变化而持续更新；
>
> **【c】** 将每一等级映射为对应的允许控制动作集合，其中所述第二等级对应的允许控制动作集合是所述第一等级对应的允许控制动作集合的真子集，所述允许控制动作集合的差异包括控制方向、控制类型、控制幅度上限中的至少一种；
>
> **【d】** 根据当前控制参与资格，门控所述目标设备进入可控资源集合的条件以及允许向所述目标设备下发的控制动作范围，使得所述控制参与资格作为控制约束直接作用于调度决策；
>
> **【e】** 当所述异常指示信息满足恢复判据时，将所述控制参与资格从较低等级提升至较高等级，并根据提升后的等级重新确定所述允许控制动作集合，所述恢复判据与所述控制参与资格降级的触发条件不相同。

### 系统独立权（权 10）

> 一种能源管理系统，包括处理器和存储器，所述存储器存储有计算机程序，所述处理器执行所述程序时实现如权 1 所述方法的步骤，系统包括：
>
> 资格采集单元，用于获取目标设备的运行状态信息和异常指示信息；
>
> 资格判定单元，用于根据所述运行状态信息和异常指示信息确定具有至少三个离散等级的控制参与资格并持续更新；
>
> 权限映射单元，用于将每一等级映射为对应的允许控制动作集合；
>
> 资源池门控单元，用于根据当前控制参与资格门控目标设备进入可控资源集合的条件及允许下发的控制动作范围；
>
> 恢复判定单元，用于在异常指示信息满足恢复判据时将控制参与资格提升至较高等级并重新确定允许控制动作集合。

### 各段写作注记

| 段 | 注记 |
|---|---|
| 【a】 | "异常指示信息"是上位词——覆盖告警、保护标志、通信超时指示、数据质量标记。不用"故障"，因为检修/停机不是故障但同样影响资格 |
| 【b】 | "至少三个等级"排除二元开关。"持续更新"排除静态配置。不用"状态机"一词，避免被解读为特定实现 |
| 【c】 | "真子集"是数学精确表述，排除 LIMITED ≈ FULL。列举"方向/类型/幅度上限"三类差异为从属留出递降空间 |
| 【d】 | 核心句的工程化表述。"作为控制约束直接作用于调度决策"防止被解读为"生成告警供人工判断" |
| 【e】 | "恢复判据与降级触发条件不相同"强制非对称性——保护复归是同一阈值反向穿越，C5 的非对称恢复是独立设计 |

### 与 lit45 区别映射

| 维度 | lit45 | C 候选 | 效果 |
|---|---|---|---|
| 领域 | 信息安全域 | 电力控制执行域 | 领域跨越 |
| 状态空间 | 连续权重 c_ij ∈ [0,1] | 离散等级（≥3） | 离散等级支持明确的权限集合映射 |
| 作用对象 | 信息流权重 | 功率控制资源池门控 + 控制动作范围 | 从"信不信消息"到"让不让设备参与调度、能调什么" |
| 恢复 | 无 | 有，非对称恢复判据 | 暂态异常→恢复→重新可用的真实需求 |
| 权限表达 | 单一维度（权重降低） | 多维度（方向/类型/幅度的组合子集） | LIMITED 下可部分参与，lit45 做不到 |

## 第四部分：从属梯 D1-D8

**D1 离散等级定义**
> 所述至少三个等级包括四个等级：完全参与等级、受限参与等级、完全阻止等级和仅观测等级，所述仅观测等级允许获取设备运行数据但不允许下发任何控制动作。

**D2 方向/动作/功率范围映射**
> 所述受限参与等级对应的允许控制动作集合包括以下至少一种限定：仅允许单一控制方向的动作、排除特定类型的控制动作、控制幅度上限低于第一等级对应的控制幅度上限。

**D3 具体条件组合**
> 所述异常指示信息包括设备告警标志、保护动作标志、通信异常指示、数据质量标记中的至少一种；所述运行状态信息包括设备在运状态、停机状态、检修状态中的至少一种。

**D4 降级优先级**
> 当多项异常指示信息同时存在时，按照预设的优先级规则确定控制参与等级，所述优先级规则使得保护动作标志优先于告警标志，通信异常指示优先于数据质量标记。

**D5 恢复迟滞**
> 所述恢复判据包括：异常指示信息消除后持续超过预设恢复确认时长的条件，所述恢复确认时长大于控制参与资格降级的触发时间窗口。

**D6 保守方向限定**
> 当控制参与资格从第二等级提升至第一等级时，首先允许单一控制方向的动作，在确认控制执行无异常后再允许完整控制动作集合。

**D7 资源池动态加入/剔除**
> 所述门控包括：当控制参与资格为第一等级时将目标设备加入可控资源集合的全集，当为第二等级时加入受限子集，当为第三等级时从可控资源集合中剔除。

**D8 OpenCEM 实施例**
> 应用于微电网能量管理系统，所述异常指示信息从设备的输出状态字段和告警标志字段提取，所述运行状态信息从设备的有功功率输出状态推导。

## 第五部分：Open items

1. **【c】"真子集"表述**：审查员若认为数学化，备选"范围小于第一等级对应的允许控制动作集合"
2. **【d】术语隔离**：暂用"可控资源集合"而非 A 的"可控资源池"，若最终合入同一说明书需统一
3. **【e】"不相同"是否过强**：实际工程中"通信超时→恢复→资格恢复"是同一条件反向。备选：改为"恢复判据可以与降级触发条件相同或不同，当相同时还包括额外的恢复确认条件"
4. **C 与 A 关系**：当前按独立发明起草。若 C 作为 A 的从属模块合入，需改写——按"不重新设计 C"约束，暂保持独立
5. **【b】"至少三个等级"的最低限**：第三等级的零动作集合与第二等级的非空真子集在数学上可区分，但审查员可能要求明确"第三等级对应的允许控制动作集合为空集"
6. **"门控"一词**：电力领域已有使用（电压门控等），备选"控制……的准入条件"或"基于……筛选"
7. **OpenCEM 统计数据**：D8 建议仅保留字段映射，统计数据移至说明书
8. **C 与 07 号 M 环映射**：C 覆盖 M2 的"控制通道/告警/保护"分支，不覆盖 M3/M6——按约束不扩展
