## 1. 技术领域

本申请涉及能源管理技术领域，具体涉及一种能源管理系统中设备控制参与资格的控制方法及系统。

本申请可应用于工商业园区、微电网、分布式能源站等场景下的站级功率调度，用于确定各类可控设备在给定时刻是否被允许参与控制、被允许执行何种控制动作，以及在设备状态变化后如何更新上述判定。

---

## 2. 背景技术

在能源管理系统中，站级控制器通常需要将功率调节任务分配给多个可控设备，例如储能设备、光伏设备、充电设备等。为了完成分配，控制器首先要确定哪些设备当前可以被控制。

在一些现有设备控制方案中，设备被划分为"可控制"与"不可控制"两种情形：当设备运行正常时将其纳入可控范围，当设备出现故障或保护动作时将其从可控范围中移除，待故障消除后再重新纳入。一种处理方式是依据设备自身的保护逻辑或保护装置的复归信号完成上述纳入与移除。

上述方式在处理处于中间运行状态的设备时，可能难以给出恰当的控制策略。例如，设备出现了非严重的告警但尚可继续运行，或者设备处于停机、检修等非故障状态；此时若仍按完全参与处理，可能使设备处于不宜承受的控制动作之下；若直接按不可控制处理，则设备在较长时间内完全无法贡献调节能力，而实际上其仍可能承担部分受限的控制动作。因此，设备参与控制的程度在部分实际场景中并非只有"参与"与"不参与"两种取值。

另一种已知的处理方式来自信息可信评估领域。该类方案可根据信息节点的可信程度调整其信息交互的权重，对可信程度下降的节点降低其信息对控制过程的影响程度，并在可信程度低于某一水平时切除该节点的参与。该类处理关注的是**信息是否可信、以及信息对控制过程的影响程度**。对于能源管理系统而言，还存在另一类技术问题：如何根据**设备当前的运行状态与异常状态**，确定该设备**是否被允许参与实际控制、以及被允许执行何种控制动作**。上述两类问题所处理的对象与所产生的作用并不相同。

此外，已有一些分层或多时间尺度的自治架构方案，其在不同层级之间隐含地设置了不同的控制权限。该类方案侧重于架构划分与任务分层，对于"由设备状态观测到控制参与资格的判定"、"由资格到可执行控制范围的映射"，以及"异常解除后资格的恢复"等环节，通常未给出具体的判定与门控方式。

综上，在一些现有方案中，可能存在以下情形：设备参与控制的程度以二元方式处理；从设备状态观测到控制参与资格、再到可执行控制范围与资源纳入的判定链条不完整；对于处在中间运行状态的设备缺少相应的处理层次；以及设备状态恢复后，资格如何重新开放缺少相应的判定依据。

## 3. 发明目的与要解决的技术问题

本申请要解决的技术问题包括：

（1）对于出现非严重异常或处于非标准运行模式的设备，如何使其仍能**受限地**参与控制，而非在完全参与与完全排除之间二选一；

（2）如何建立从设备的运行状态信息与异常指示信息，到该设备控制参与资格的判定，并使该资格随观测信息的变化而持续更新；

（3）如何将控制参与资格映射为可执行的门控，使得该资格既约束**允许下发的控制动作范围**，又决定该设备**是否被纳入参与调度的可控资源集合**；

（4）在设备状态恢复后，如何依据恢复判据更新其控制参与资格，并据此重新开放相应的控制动作范围与资源纳入条件，同时避免因停止观测而使恢复判据失去判定依据。

本申请的目的在于提供一种能源管理系统中设备控制参与资格的控制方法及系统，通过由运行状态信息与异常指示信息确定**具有至少三个等级的离散控制参与资格**、由该资格确定**允许控制动作范围与可控资源集合的纳入条件**、以及依据**恢复判据**更新该资格，来解决上述技术问题。

## 4. 核心技术方案

### 4.1 方法方案

在一个实施方式中，所述控制方法包括：

**【a】** 获取目标设备的运行状态信息和异常指示信息，所述异常指示信息用于表征所述目标设备当前不适合执行全部或部分控制动作。

其中，所述运行状态信息用于表征所述目标设备当前所处的运行状态，例如在运状态、停机状态、检修状态等；所述异常指示信息用于表征所述目标设备当前存在的不适合执行全部或部分控制动作的情形，例如设备告警标志、保护动作标志、通信异常指示、数据质量标记等。上述信息可以来自设备本地的上报数据，也可以经由边缘控制器或站级采集装置获得。

**【b】** 根据所述运行状态信息和异常指示信息，确定所述目标设备的控制参与资格。所述控制参与资格为具有至少三个等级的离散等级，至少包括允许完整控制动作的第一等级、允许受限控制动作的第二等级、以及不允许控制动作的第三等级；所述控制参与资格随所述运行状态信息和异常指示信息的变化而持续更新。

在一个实施方式中，所述控制参与资格随每次获得新的运行状态信息或异常指示信息而重新确定，从而使该资格随设备实际状态的变化而持续更新，而不是作为一次性的静态配置。

**【c】** 将每一等级映射为对应的允许控制动作范围。其中，较低等级对应的允许控制动作范围相对于较高等级受到进一步限制，所述限制包括控制类型、控制方向和控制幅度中的至少一种；所述第三等级对应的允许控制动作范围为空。

**【d】** 根据当前控制参与资格，确定目标设备是否被纳入参与调度的可控资源集合，并限制能够向所述目标设备下发的控制动作，使调度器仅从与当前控制参与资格相匹配的控制动作范围内生成或选择控制动作。

在一个实施方式中，控制参与资格同时用于确定两方面的控制后果：一方面确定所述目标设备被允许执行的控制动作范围，另一方面确定所述目标设备是否被纳入参与调度的可控资源集合，以及被纳入何种资源集合。

**【e】** 当满足与当前控制参与资格对应的恢复判据时，将所述控制参与资格从较低等级更新为较高等级，并根据更新后的控制参与资格重新确定所述目标设备的允许控制动作范围和/或所述目标设备参与可控资源集合的条件。

在一个实施方式中，所述恢复判据依据所述运行状态信息与异常指示信息是否恢复至满足预设条件的程度来确定；在资格更新后，相应扩大所述目标设备被允许执行的控制动作范围，或使其纳入参与调度的可控资源集合中范围更大的子集。

### 4.2 系统方案

在一个实施方式中，所述能源管理系统包括：资格采集单元、资格判定单元、权限映射单元、资源集合门控单元和恢复判定单元。

- **资格采集单元**，用于获取目标设备的运行状态信息和异常指示信息；
- **资格判定单元**，用于根据所述运行状态信息和异常指示信息确定所述目标设备的控制参与资格，所述控制参与资格为具有至少三个等级的离散等级并持续更新；
- **权限映射单元**，用于将每一等级映射为对应的允许控制动作范围；
- **资源集合门控单元**，用于根据当前控制参与资格确定目标设备是否被纳入参与调度的可控资源集合，并限制能够向所述目标设备下发的控制动作范围；
- **恢复判定单元**，用于在所述异常指示信息满足与当前控制参与资格对应的恢复判据时，将所述控制参与资格从较低等级更新为较高等级，并重新确定所述目标设备的允许控制动作范围和/或所述目标设备参与可控资源集合的条件。

上述各单元可以由站级控制器中的软件模块实现，也可以由边缘控制器、或能源管理系统中具有相应计算能力的装置实现。各单元在物理上可以位于同一装置内，也可以分布在不同的装置中并通过通信链路协同工作。

### 4.3 有益效果

在一个实施方式中，通过上述方案，可使设备在出现非严重异常或处于非标准运行模式时，仍按受限制的控制动作范围参与控制，而不必在完全参与与完全排除之间二选一。

在一个实施方式中，通过将控制参与资格同时用于确定允许控制动作范围与资源集合纳入条件，控制器对所纳入设备的控制动作受到相应约束，从而使下发的控制动作与该设备当前的运行与异常状态相适应。

在一个实施方式中，通过设置恢复判据并在第三等级的构成中保留对设备运行状态与异常指示信息的获取，使设备状态恢复后资格能够被重新确定，相应控制动作范围与资源纳入条件能够被重新开放，而不依赖外部的人工复位操作。

## 5. 术语定义

本申请中，除另有说明外，下列用语的含义如下：

**运行状态信息**：指目标设备当前所处的运行状态的信息，包括但不限于在运状态、停机状态、检修状态。所述运行状态信息用于表征设备是否处于具备运行条件的状态。

**异常指示信息**：指用于表征目标设备当前不适合执行全部或部分控制动作的信息，包括但不限于设备告警标志、保护动作标志、通信异常指示、数据质量标记中的至少一种。所述异常指示信息不限于"故障"一种情形，设备处于检修、停机等非故障状态时，同样可以通过运行状态信息反映其对控制参与的影响。

**控制参与资格**：指目标设备被允许参与控制的程度，其取值为具有至少三个等级的离散等级。

**离散等级**：指第一等级、第二等级、第三等级。其中第一等级对应允许完整控制动作，第二等级对应允许受限控制动作，第三等级对应不允许控制动作。

**允许控制动作范围**：指某一等级下允许向目标设备下发的控制动作的集合。所述集合可以由控制类型、控制方向、控制幅度等维度中的一个或多个维度界定。允许控制动作范围为空，表示不允许向该设备下发控制动作。

**控制动作与遥测采集**：控制动作指由调度器生成并下发至设备、用于改变设备运行状态的指令；遥测采集指对设备运行数据的获取。二者不是同一概念：不参与控制动作，不等于不获取该设备的运行数据。

**可控资源集合**：指参与调度的可控资源的总体。在一个实施方式中，所述可控资源集合划分为完整控制资源子集与受限控制资源子集。

**完整控制资源子集**：指控制参与资格为第一等级的目标设备所纳入的资源子集。

**受限控制资源子集**：指控制参与资格为第二等级的目标设备所纳入的资源子集。

**恢复判据**：指使控制参与资格由较低等级更新为较高等级所需满足的条件。

## 6. 控制参与资格的三级构成与第三等级的子状态

在一个实施方式中，控制参与资格包括第一等级、第二等级与第三等级，其中第三等级包括仅观测子状态与完全阻止子状态。各等级的构成及其对应的控制后果如下：

| 等级 | 含义 | 允许控制动作范围 | 资源集合纳入 | 对设备运行数据的获取 |
|---|---|---|---|---|
| 第一等级 | 完整参与 | 完整的控制动作集合 | 纳入完整控制资源子集 | 常规遥测 |
| 第二等级 | 受限参与 | 受限且非空的控制动作集合 | 纳入受限控制资源子集 | 常规遥测 |
| 第三等级·仅观测子状态 | 不参与控制 | 空 | 不纳入上述任一子集 | 将目标设备保留为监测对象，其运行数据参与状态监测 |
| 第三等级·完全阻止子状态 | 不允许控制动作 | 空 | 不纳入上述任一子集 | 仍获取用于资格恢复判定的运行状态信息与异常指示信息；其运行数据不作为调度控制决策的输入 |

在一个实施方式中，第三等级的两个子状态的区别在于**非控制动作维度**：二者均不允许下发控制动作，其区别在于是否将目标设备保留为监测对象、以及所获取的运行数据用于何种用途。仅观测子状态下，设备的运行数据参与状态监测；完全阻止子状态下，设备的运行数据不作为调度控制决策的输入，但仍被获取用于判定其资格是否具备恢复条件。

在一个实施方式中，将第三等级的两个子状态设置为第三等级内部的子状态，而非与第一等级、第二等级并列的独立等级，其原因在于：上述两个子状态在允许控制动作范围这一维度上均为空，二者之间不构成"较低等级相对于较高等级的进一步限制"这一关系；而第一等级、第二等级、第三等级之间则依次构成上述限制关系。

在一个实施方式中，设备的具体运行状态可以表现为四种：完整参与、受限参与、仅观测、完全阻止。其中完整参与对应第一等级，受限参与对应第二等级，仅观测与完全阻止对应第三等级的两个子状态。

## 7. 等级到允许控制动作范围的映射

在一个实施方式中，等级到允许控制动作范围的映射由控制类型、控制方向和控制幅度中的至少一个维度界定。

所述控制类型维度用于限定允许或排除特定类型的控制动作。例如，允许有功功率调节而排除需要快速功率爬坡的控制动作。

所述控制方向维度用于限定允许的控制方向。例如，仅允许单一控制方向的动作，包括仅允许放电而不允许充电，或仅允许降低取用功率而不允许增加取用功率。

所述控制幅度维度用于限定控制动作的幅度上限。例如，令第二等级对应的控制幅度上限低于第一等级对应的控制幅度上限。

在一个实施方式中，第二等级对应的允许控制动作范围相对于第一等级受到上述至少一种限制，且该范围为非空集合；第三等级对应的允许控制动作范围为空集合。

在一个实施方式中，映射关系可以以预设表格的形式存储，也可以由预设的判断规则在运行时确定。

## 8. 可控资源集合的纳入

在一个实施方式中，所述可控资源集合包括完整控制资源子集与受限控制资源子集。当控制参与资格为第一等级时，将目标设备纳入完整控制资源子集；当控制参与资格为第二等级时，将目标设备纳入受限控制资源子集；当控制参与资格为第三等级时，不将目标设备纳入上述任一控制资源子集。

在一个实施方式中，**不将目标设备纳入控制资源子集，不等于不获取该设备的运行数据**。对于第三等级的目标设备，其仍可作为监测对象保留，或在完全阻止子状态下保留用于资格恢复判定的观测通道。由此，设备在不符合参与控制条件期间，其状态变化仍可被获取，从而具备判定恢复条件的信息来源。

在一个实施方式中，所述完整控制资源子集与受限控制资源子集可以分别对应调度器中不同的资源列表；调度器在生成控制动作时，仅从受限控制资源子集对应设备所被允许的控制动作范围内生成或选择控制动作。

在一个实施方式中，目标设备进入或退出上述资源子集不需要人工干预，而是随着其控制参与资格的更新自动进行。

## 9. 恢复判据与渐进恢复

### 9.1 恢复判据

在一个实施方式中，所述恢复判据包括以下至少一种：

- 在预设持续时间内连续满足恢复条件；
- 连续多个采样周期满足恢复条件；
- 恢复所依据的阈值区别于资格降级所依据的阈值。

在一个实施方式中，采用区分于降级阈值的恢复阈值，可以使等级状态在阈值附近不因观测数据的微小波动而反复变化。

### 9.2 恢复的控制后果

在一个实施方式中，当满足与当前控制参与资格对应的恢复判据时，将控制参与资格由较低等级更新为较高等级，并据此重新确定目标设备的允许控制动作范围，和/或重新确定该目标设备参与可控资源集合的条件。即，恢复不仅表现为该设备重新被纳入资源集合，还表现为该设备被允许执行的控制动作范围相应扩大。

### 9.3 渐进恢复

在一个实施方式中，资格由第二等级向第一等级更新时，采用渐进的更新顺序：

当满足将控制参与资格由第二等级向第一等级提升的初步恢复条件时，维持所述控制参与资格为第二等级，并仅允许单一控制方向的动作；在所述动作的控制执行满足预设确认条件后，将所述控制参与资格更新为第一等级，并开放第一等级对应的完整控制动作范围。

上述顺序中，试探性开放的控制动作范围位于第二等级本已允许的受限控制动作范围之内，因此与控制参与资格各等级的上述定义相符。

在一个实施方式中，若所述动作的控制执行未满足所述预设确认条件，则维持所述控制参与资格为第二等级，或将其回退至较低等级；在回退情形下，设备对运行状态信息与异常指示信息的获取不被中断。

## 10. 实施例 1：独立实施方式

本实施例给出在单个站点内实施本申请方案的实例。

**站点构成**：站级控制器，以及与站级控制器通信连接的若干可控设备，包括储能设备、光伏设备与充电设备中的至少一种。

**数据流**：各可控设备将运行状态信息与异常指示信息上报至站级控制器；站级控制器据此确定各设备的控制参与资格；再依据所述资格确定各设备被允许的控制动作范围以及是否纳入可控资源集合；调度器在所确定的控制动作范围内生成或选择控制动作并下发。

**判定示例**：设站点内有三台可控设备。

- 设备 A 处于在运状态且无异常指示，其控制参与资格确定为第一等级，纳入完整控制资源子集，允许执行完整的控制动作集合；
- 设备 B 存在一般告警指示，其控制参与资格确定为第二等级，纳入受限控制资源子集；其允许控制动作范围被限定为仅允许单一控制方向的动作；
- 设备 C 存在通信异常指示，其控制参与资格确定为第三等级；在该子状态下，设备 C 不纳入上述任一控制资源子集，但其运行状态信息与异常指示信息仍被获取，用于判定其是否具备恢复条件。

**说明**：本实施例中，控制参与资格的判定输入为设备运行状态信息与异常指示信息，不依赖其他类型的信息。因此本实施例可在不引入其他功能单元的条件下实施。

## 11. 实施例 2：多种异常指示信息组合下的资格确定

本实施例给出当多种异常指示信息同时存在时，确定控制参与资格的实例。

**异常指示信息的来源**：包括设备告警标志、保护动作标志、通信异常指示、数据质量标记中的至少一种；运行状态信息包括在运状态、停机状态、检修状态中的至少一种。

**判定的先后次序**：在一个实施方式中，当多项异常指示信息同时存在时，按照预设的优先级规则确定控制参与资格。所述优先级规则中，保护动作标志优先于告警标志，通信异常指示优先于数据质量标记。

**判定示例**：

| 序号 | 运行状态信息 | 异常指示信息 | 确定的资格 |
|---|---|---|---|
| 1 | 在运 | 无异常 | 第一等级 |
| 2 | 在运 | 存在一般告警标志 | 第二等级 |
| 3 | 在运 | 存在保护动作标志 | 第三等级·完全阻止子状态 |
| 4 | 在运 | 通信异常指示与数据质量标记同时存在 | 第三等级（按通信异常指示优先确定） |
| 5 | 停机 | 无异常 | 第三等级·仅观测子状态 |
| 6 | 检修 | 无异常 | 第三等级·仅观测子状态 |
| 7 | 在运 | 一般告警标志与数据质量标记同时存在 | 第二等级（按已生效的告警标志确定） |

**说明**：序号 4 与序号 7 示出优先级规则的作用；当多项指示信息指向不同的资格时，依上述次序确定最终资格，使判定结果不随信息到达顺序而改变。

## 12. 实施例 3：恢复过程与渐进恢复

本实施例给出设备状态恢复后资格更新的实例。

**场景**：某设备此前因通信异常指示被确定为第三等级，其不纳入任一控制资源子集，但站级控制器仍持续获取其运行状态信息与异常指示信息。

**阶段一：恢复条件出现**。该设备的通信异常指示消失，且后续连续多个采样周期未再出现异常指示。此时满足恢复判据中的"连续多个采样周期满足恢复条件"。

**阶段二：等级更新与权限重新开放**。将该设备的控制参与资格由第三等级更新为第二等级，将其纳入受限控制资源子集，并确定其允许控制动作范围为"仅允许单一控制方向的动作"。

**阶段三：渐进恢复**。在满足由第二等级向第一等级提升的初步恢复条件时，维持该设备为第二等级，并仅允许单一控制方向的动作；在所述动作的控制执行满足预设确认条件后，将该设备更新为第一等级，并开放完整控制动作集合。

**阶段四：恢复失败的处置**。若在阶段二或阶段三中，该设备再次出现异常指示信息，或所述动作的控制执行未满足预设确认条件，则维持当前等级或回退至较低等级；在此过程中，对运行状态信息与异常指示信息的获取不被中断。

**时序示例**：

```text
时刻  观测                      资格                资源集合
t0    通信异常指示出现          第三等级·完全阻止   不纳入
t1    通信异常指示持续          第三等级·完全阻止   不纳入
t2    异常消失，第 1 个周期     第三等级·完全阻止   不纳入（恢复判据未满足）
t3    异常消失，连续 N 个周期   第二等级            纳入受限子集
t4    初步恢复条件满足          第二等级            纳入受限子集（仅单一方向）
t5    该方向动作执行确认通过    第一等级            纳入完整子集
```

在一个实施方式中，上述 N 以及所述的确认条件可由使用者预先设定。

## 13. 实施例 4：基于公开运行数据的设备控制参与资格确定实例

本实施例以一公开获取的分布式能源运行数据集为对象，给出本申请方案的一种工程实现形式。

**站点与数据**：该站点包含两台容量级别为数千瓦至十千瓦级的混合型功率变换设备，以及相应的站级采集与控制器。可获取的观测信息包括：

- 设备输出状态信息，其取值为多个离散取值，分别对应该设备的不同输出工况；
- 告警标志信息，其以多个标志位的组合形式表示，不同组合对应不同的告警情形；
- 与该设备充放电过程相关的状态信息。

**资格确定规则**：在一个实施方式中，按照以下规则由上述观测信息确定控制参与资格：

```text
输入：设备输出状态 O，告警标志位向量 A = (a1, a2, ..., an)

若 A 中存在表示保护动作或严重告警的位为有效：
        确定资格为第三等级；
        进而：若 O 表示设备处于停机工况，或 A 中仅存在非严重告警位，
              则确定子状态为仅观测子状态；
              否则确定子状态为完全阻止子状态；
否则若 A 中存在表示一般告警的位为有效：
        确定资格为第二等级，允许控制动作范围限定为单一控制方向；
否则若 O 表示设备处于停机工况：
        确定资格为第三等级·仅观测子状态；
否则：
        确定资格为第一等级，纳入完整控制资源子集。
```

**状态转换示例**：在该数据集所覆盖的运行期间，可观察到上述资格在等级之间发生多次双向转换，包括由第一等级向第三等级的转换、以及由第三等级向第一等级或第二等级的恢复转换；相应地，设备在完整控制资源子集、受限控制资源子集与均不纳入三种情形之间发生成员变化。

**伪代码示例**：

```text
function determine_qualification(O, A):
    if has_protection_or_severe_alarm(A):
        if O == STOPPED or only_non_severe_alarm(A):
            return THIRD_LEVEL, OBSERVE_ONLY
        else:
            return THIRD_LEVEL, FULLY_BLOCKED
    if has_general_alarm(A):
        return SECOND_LEVEL          # 允许动作范围：仅单一控制方向
    if O == STOPPED:
        return THIRD_LEVEL, OBSERVE_ONLY
    return FIRST_LEVEL
```

**门控示例**：确定资格后，依第 8 节所述将设备纳入相应资源子集，并按第 7 节所述确定其允许控制动作范围。当设备处于第三等级时，其不被纳入任一控制资源子集，但其输出状态信息与告警标志信息仍被获取，用于判定恢复条件。

**关于标志位语义的说明**：上述标志位的具体含义可依相应设备的通信协议文档确定。在采用本方案时，所述映射规则可以依据协议文档预先设定；在没有协议文档的情形下，也可以依据实际观测数据中标志位取值与设备工况的对应关系确定所述映射规则。本实施例在此不对特定标志位的含义作出限定。

**说明**：本实施例用于说明本申请方案在具有上述观测信息条件下的可实施形式，不构成对观测信息来源、设备型号或标志位定义的限定。
