## 0. 执行摘要

> **F candidate = PASS（继续；核心进一步收窄到 F4→F5→F6）。**

本轮 7 篇高相关专利中：

- **F1/F2 已明显 crowded**：自然语言/事件理解、任务分解、模型/工具调用、MCP/插件式外部资源调用均已有公开；
- **F3 已有实质近邻**：至少 CN122047017A、CN120746348A 已把确定性优化/路径搜索结果转成调度/处置方案并进入现场执行；
- **F4 仅有强 Neighbor，未见严格 F-node**：存在“安全校验智能体”“Z3/CVXPY 物理规则校验”“仿真/数字孪生预演”，但均缺少“独立于 LLM/Agent、对候选控制动作实施强制硬物理约束校验”的完整控制语义；
- **F5 精确节点 = 0**：未见“物理校验结果”与“控制授权策略”分离，形成 AUTO / HUMAN-APPROVAL / REJECT 等授权门后才允许 EMS/设备执行；
- **F6 精确节点 = 0**：有执行后评估、模型再训练、一般错误重试，但未见面向真实控制的“执行确认失败→拒绝/回退/降级/人工接管”的在线安全退出机制；
- **最长连续 F-node 覆盖仅 2 环：F2→F3（CN122047017A）**；不存在 F2→F3→F4→F5→F6 连续覆盖。

因此命中 F-v0.1 cheap-knockout 的 PASS 条件：

```text
F1/F2 crowded
+ F3 已有近邻
+ F4→F5 断裂
+ F5→F6 断裂
= PASS
```

但 F 不是“宽松 PASS”。本轮发现一个明确的**组合攻击面**：

```text
CN122047017A  提供 F2→F3（LLM 动态选/调优化模型→可执行调度指令）
        +
CN121168599A  提供 F4 强邻域（Z3/CVXPY + Modelica/数字孪生验证）
        +
CN120746348A  提供 F4/F5 强邻域（安全校验智能体→控制执行智能体）
```

所以 F 后续不能再以“Agent 调工具 + 安全校验”作为独立权核心；真正需要压住的是：

> **强制的独立物理校验器 → 与校验分离的控制授权门 → 仅授权动作进入 EMS → 执行确认失败触发回退/降级/人工接管。**

## 1. F-v0.1 扫描尺子

```text
F1 运行事件 → 结构化控制意图
        ↓
F2 受约束的确定性工具选择与调用
        ↓
F3 基于工具结果形成结构化候选动作
        ↓
F4 独立物理安全与运行约束校验
        ↓
F5 控制授权门 → EMS/设备执行
        ↓
F6 执行确认 → 拒绝/回退/降级/人工接管
```

### 1.1 节点口径

- **F1**：不是“大模型生成建议”。输出至少应可被后续计算/执行环节消费，例如目标、对象、时间范围、动作类型、风险/优先级等结构化字段。
- **F2**：工具应来自预设集合/注册表/白名单，并至少有接口规范、参数模式、适用条件或权限约束；普通 Function Calling / API 调用 / MCP 接入只算 Neighbor。
- **F3**：候选控制动作应由确定性工具结果形成，LLM 负责理解/编排而非自由生成设备设定值。
- **F4**：校验器应与 LLM/Agent 决策主体分离，对候选控制动作实施硬物理/运行约束检查；Agent 自评、另一个 LLM critic、一般评分/排序、仅做仿真展示均只算 Neighbor。
- **F5**：“校验通过”不自动等于“允许执行”。应根据风险等级、设备/用户权限、动作类型等形成独立授权决策，例如 AUTO / HUMAN / REJECT，再进入 EMS/设备指令链。
- **F6**：真实执行后检查 ACK/实测状态/超时/异常；失败时应有撤销、回退、降级、保守策略或人工接管。执行后报表、效果评分、RLHF 再训练均只算 Neighbor。

### 1.2 邻域纪律

以下单点不得自动计为 F-node：

- LLM + RAG；
- LLM + 多 Agent；
- LLM + API / MCP / Function Calling；
- LLM + 优化算法；
- Agent 互相评审；
- 数字孪生/仿真预演；
- 自动生成调度建议；
- 执行结果用于再训练。

## 3. 逐篇 F1–F6 深挖

### 3.1 lit_id 104 — CN122047017A：LLM 动态调用启发式优化模型（最强单篇近邻）

**关键披露**：预构建包含多种优化偏好的启发式优化模型库；模型带功能标签、性能特征、适用工况约束和接口规范；领域 LLM 根据配电网情景和调度需求筛选、评估并调用适配模型；候选模型经仿真/多维性能指标评估后确定最优策略，再转成可执行调度指令下发现场；执行后的量化效果、方案和全过程决策轨迹用于强化学习。

**逐环判定**：

- **F1 = Neighbor**：理解任务/运行约束/优化偏好并形成语义查询，但未明确形成完整结构化控制意图对象。
- **F2 = A-node**：本轮最明确的 F2；存在预构建模型库、元数据标签、适用工况约束、接口规范，LLM 负责筛选并调用候选启发式优化模型。
- **F3 = A-node**：候选模型经评估确定最优策略，并转成可执行调度指令序列。
- **F4 = Neighbor**：有仿真和最低节点电压/最大设备负载率等运行评价，但用途仍是候选模型/策略评估与排序，不是独立硬物理 verifier。
- **F5 = Neighbor**：最优策略直接转调度指令下发，没有与 F4 分离的授权策略门。
- **F6 = Neighbor**：有执行后量化评估/轨迹回灌，但未见本次控制失败的撤销/回退/降级/人工接管。

**结论**：**连续 F-node = F2→F3（2 环）**。“LLM 动态调用优化算法”已不能作为 F 的创造性核心。

### 3.2 lit_id 75 — CN120746348A：大模型 + 多智能体电网故障处置

**关键披露**：故障信息经语义解析后，大模型生成处置策略并拆为可执行子任务序列；风险分析、机组调整、负荷转移、协调、安全校验、控制执行六类智能体协作；机组调整使用优化模型，负荷转移使用拓扑/容量路径搜索；协调 Agent 汇总方案；安全校验 Agent 通过后送控制执行 Agent，下发真实设备；执行后做多维效果评估。

**逐环判定**：

- **F1 = A-node**：处置策略拆成可执行子任务序列并明确 I/O 与顺序，已超出自然语言建议。
- **F2 = Neighbor**：固定 Agent 内部使用优化/搜索，不是 LLM 从受约束工具白名单中按 schema/权限动态调用。
- **F3 = A-node**：优化/搜索结果组合成结构化故障处置方案。
- **F4 = Neighbor（强）**：有名义独立的安全校验 Agent，但未限定为独立确定性硬物理校验器。
- **F5 = Neighbor（强）**：校验通过后直接送执行 Agent，形成条件门，但没有“物理可行性”和“控制授权”两个分离状态对象。
- **F6 = Neighbor**：执行后有量化评估，但没有失败回退/降级/人工接管。

**结论**：F4/F5 最危险邻域。后续不能仅写“安全校验 Agent，通过后下发”。

### 3.3 lit_id 71 — CN121168599A：光储用例生成 + Z3/CVXPY + 虚实融合验证

**关键披露**：自然语言需求转 JSON 可执行约束；调用 Z3/CVXPY 检查参数是否满足知识图谱物理规则，违反则自动修正并重新生成；进一步经规则引擎、Modelica 动态仿真、数字孪生平台验证；无效用例反馈大模型，新约束更新知识图谱。

**逐环判定**：

## 5. Crowded / Gap 重新划线

### 5.1 已 crowded，不再作为独立发明点

1. LLM/RAG 理解电力运行文本或告警；
2. 多 Agent 分工协作；
3. LLM 动态选择/调用优化算法；
4. MCP/插件式 API/工具库接入；
5. 优化/路径搜索结果转成调度方案；
6. 通过仿真、数字孪生或另一个 Agent 做方案评价；
7. 执行结果用于效果评估或后续模型再训练。

### 5.2 仍值得保护的连接

#### Gap-F4：候选控制动作 → 强制独立物理校验

```text
Agent/工具形成候选动作
→ 独立确定性 verifier
→ 设备/PCC/变压器/SOC/能量/服务约束
→ machine-readable physical_verdict
→ 未通过则禁止进入授权链
```

#### Gap-F5：物理可行 ≠ 自动允许执行

```text
physical_verdict = PASS
→ 风险等级 + 动作类型 + 设备控制资格 + 操作者/Agent权限
→ authorization_state = AUTO / HUMAN / REJECT
```

**F5 是当前最重要的 connector。** lit75 的“安全校验通过→执行 Agent”没有把“可行性”和“授权策略”分成两个状态对象。

#### Gap-F6：真实控制失败的安全退出

```text
已授权命令下发
→ ACK/设备实测/超时
→ execution_state = SUCCESS / FAILED / UNCERTAIN
→ FAILED/UNCERTAIN：撤销、回退、降级、人工接管
```

lit104/75/89 的执行后评估/学习都不能替代这一节点。

## 6. 最危险组合攻击

### 6.1 CN122047017A + CN120746348A

前者提供 F2→F3；后者提供“安全校验 Agent→控制执行 Agent”的 F4/F5 强邻域。可能被组合成“工具调用后增加安全检查再执行”的显而易见攻击。

- F5 必须独立于 F4；

### 6.3 CN122346481A + CN120746348A

MCP/工具库编排 + 安全校验/执行 Agent 也能构成泛化组合攻击，因此“MCP + 安全 Agent”不能作为唯一差异。

## 8. 权利要求设计启示

## 9. 与 C/H 的边界

- **C**：某设备当前有没有资格被控制、允许什么动作；其 `control_qualification` 可以成为 F4/F5 的输入。

- **H**：长期 provenance/replay，负责输入证据、工具版本、verdict、授权记录、命令和执行结果的可验证留痕。
