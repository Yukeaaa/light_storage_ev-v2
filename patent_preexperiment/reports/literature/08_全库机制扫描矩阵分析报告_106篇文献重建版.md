## Part II：A 候选 — 五步链（邻域/覆盖分离）

### 2.1 判定标准：A-node 与 neighbor 分离

**A-node（计入覆盖统计）**：
- S1 偏差证据：功率控制要求 vs 实际执行的偏差检测
- S2 能力归因：执行偏差的能力归因

- S4 跨资源承接：功率差额→某资源不足→另一资源承接
- S5 能力状态反馈：执行结果回写能力边界（维持/收缩/恢复）

**Neighbor（不计入覆盖统计，仅标注）**：
- 计划反馈邻域：执行结果回写下一时段计划输入，但不形成能力边界维持/恢复
- 标量能力邻域：SOC/SOH/温度等经验函数的标量降额，非方向化状态机
- 健康归因邻域：SHAP/不一致性解释，非执行偏差归因

**邻域不进入 A 链覆盖统计、不参与相邻连续环节判定。**

## 附录 C：build_matrix.py 断言说明

V2.1 `build_matrix.py` 在执行时强制验证：

1. `len(ledger_usable_ids) == 106`——台账可用 ID 必须为 106
2. `lit_id <= 108`——每条扫描记录 lit_id 不得超过 108
3. `actual_ids == expected_ids`——扫描集必须等于台账可用集
4. `len(matrix) == 106`——输出 CSV 必须恰好 106 行
5. **`lit_id` 重复 → FATAL**（V2.1 新增，不再使用 warning + last wins）
6. **ledger 交叉校验**（V2.1 新增）：扫描记录的 `pub_no` 必须与 ledger 中该 `lit_id` 的 `pub_no` 一致

任一断言失败则脚本终止，不生成矩阵。
