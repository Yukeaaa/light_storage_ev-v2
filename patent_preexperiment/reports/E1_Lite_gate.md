# E1-Lite 门报告：基于充电响应状态识别的功率区间生成——问题强度（K1.2 纠偏重跑）

实验编号：E1-Lite（V2.1 §6；阈值网格权威口径 V2.0 §4.3）
日期：2026-08-07（K1.2 纠偏重跑：done 相对阶段切断 + 全会话分钟 done 赋值）
预注册：`configs/k1_preregister.yaml`（K1_preregister_v1 + k1_1_corrections + k1_2_corrections）
门判定：**K1-M（caltech 主集机制）= Go**；**K1-X（jpl 边界）= 方向一致弱证据**

## 1. 结论摘要（K1.2 纠偏后）

- 评审两项 P0 修复生效：
  1. **事件在阶段边界强制切断**：长事件跨 core/mid/tail 边界时按段重跑、各段独立满足 T_event，不再把整条长事件计为一个 core 事件 → 核心段事件率仍 **11.9%**（原 12.1%），但**核心段持续 p95 由 98.6 → 66.4 min**、核心段差值能量 489.7 → 350.0 kWh（切断后 core 段只含真正>120min 的运行段，不再混入近完成段分钟）。
  2. **推断 done 对全会话分钟统一赋值**：done 锚点按会话计 5,961 中 api 5,956（99.9%）/ inferred 3 / missing 2，非之前"仅用于排伪"的逐行推断。
- caltech 主集：2,941 个有核心运行窗口的会话中 349 个出现核心事件（733 段事件），**事件会话率 11.9%**（停止线 5%，超 2.4 倍）；中位功率差 **1.28 kW**（≈ 工作功率 36.7%）。
- 阶段切断后近完成集中度更清晰：done 前 120 min 内段事件占比 84.8%（tail 2,569 + mid 1,549 vs core 733）。
- 6 个冻结正常月份核心率 7.7%–16.9%，**逐月全部 ≥5%**（停止线"≥6 个正常月份过线"满足）。
- 负对照（核心段口径）全稳：时间置换 3 种子均值 7.2% ≪ 11.9%（diff 4.6pp，bootstrap 95%CI [1.7, 2.8]pp 下界>0）；post_done=0；仅实测/计算功率子集 11.9%（一致）；排除短会话 11.9%；单桩 9.8%、单月 23.5% 无集中；38 个桩出现核心事件。
- K1-X 边界 jpl（2020-06/07）：513 个核心窗口会话，核心率 **5.1%**、中位差 1.43 kW（≈ 工作功率 87%），方向与主集一致（仅弱证据）。

**语义修正**：done 前 120 分钟内事件占比高不是失败，而是问题特征化——响应差异在充电**末段集中**。这与"可执行功率区间生成"主轴的关系是：末段降流差异是可识别信号，但其"有界修正"价值需 E2 验证；核心运行段事件（11.9%）独立支撑问题强度。

## 3. 阈值与 done-relative 定义（冻结，V2.0 §4.3 权威）

- P_on=0.5 kW；δ_r=0.25；δ_p=0.5 kW；T_event=5 min；初始排除=5 min；尾段排除=10 min；pilot 工作阈值=1.0 A。
- done 锚点：`doneChargingTime`（API，按会话计 5,956/5,961=99.9%）；缺失时离线推断（<0.3 kW 持续 20 min 且不再恢复，全会话分钟统一赋值）。`done_anchor_coverage_by_session`: api 5,956 / inferred 3 / missing 2。
- 阶段划分：core_run_segment（距 done >120 min）｜ pre_done_mid（30–120 min）｜ pre_done_tail（0–30 min）｜ post_done（<0，应为 0）｜ done_missing。
- **K1.2 切断规则**：事件在 core/mid/tail 边界强制切断，各段独立重跑持续 ≥T_event；同一会话可产生多段事件（733 段 / 349 会话）。
- V2.1 §6.4 与 V2.0 §4.3 的 δ_r/δ_p/尾段网格不一致，以 V2.0 为准（已记录待协调项）。

## 7. current-only 保护回退

JPL current-only 400 会话抽样：低功率状态频率 47.5%，77.3% 会话存在低功率段（排除初始 5 分钟与尾段 10 分钟）→ 无 pilot 条件下仍存在大比例"连接但低功率"状态，回退路径可行。

## 8. 停止线判定（K1-M 主集）

| 停止线 | 阈值 | 观测 | 判定 |
|---|---|---|---|
| ≥6 正常月份有核心窗口 | 6 | 6 | ✓ |
| ≥500 合格会话 | 500 | 5,961 | ✓ |
| 核心段事件会话率 ≥5% | 5% | 11.9% | ✓ |
| 中位功率差 ≥0.5kW 或 ≥10% 工作功率 | — | 1.28 kW / 36.7% | ✓ |
| 单一桩/月贡献 ≤50% | 50% | 9.8% / 23.5% | ✓ |
| 负对照后保留主量级 | — | 置换 7.2% ≪ 11.9%；post_done=0 | ✓ |

**结论：K1-M = Go** —— 阶段切断后核心运行段响应差异事件率 11.9%、量级 1.28 kW、6 个月逐月稳定、负对照稳健、末段集中已按特征化而非失败处理。
**K1-X = 方向一致弱证据**（边界核心率 5.1% 达标，但 COVID 低量期不作独立判定）。
