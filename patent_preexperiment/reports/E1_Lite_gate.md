# E1-Lite 门报告：基于充电响应状态识别的功率区间生成——问题强度（K1.1 纠偏重跑）

实验编号：E1-Lite（V2.1 §6；阈值网格权威口径 V2.0 §4.3）
日期：2026-08-06（K1.1 纠偏重跑：主口径改为 doneChargingTime 相对阶段）
预注册：`configs/k1_preregister.yaml`（K1_preregister_v1 + k1_1_corrections）
门判定：**K1-M（caltech 主集机制）= Go**；**K1-X（jpl 边界）= 方向一致弱证据**

## 1. 结论摘要（K1.1 纠偏后）

- 评审质疑成立：原 45.9% 事件率的主口径把"距完成 ≤120 分钟"的近完成/降流段（pre_done_mid + pre_done_tail）计入主证据，其中 **83.5% 的事件落在完成前 120 分钟内**（tail 2,285 + mid 1,517 vs core 750）——原结论大部分由 taper/接近完成段的功率下降构成。
- 纠偏后主口径改为**核心运行段（core_run_segment：距完成 >120 min 且充电中）**：
  - caltech 主集：2,939 个有核心运行窗口的会话中 357 个出现事件，**事件会话率 12.1%**（停止线 5%），仍超 2.4 倍；
  - 中位功率差 **1.28 kW**（≈ 工作功率 36.6%），核心段差值能量 **489.7 kWh**，事件持续 p50=10 / p95=98.6 min；
  - 6 个正常月份核心率 7.8%–17.3%，全部超停止线。
- 负对照（核心段口径）全稳：时间置换 7.5% < 12.1%；post_done=0（排除停车占位伪影）；排除短会话 12.2%（稳健）；单一桩 9.6%、单一月 23.5% 无集中；38 个桩出现核心事件。
- K1-X 边界 jpl（2020-06/07）：513 个核心窗口会话，核心事件率 **5.3%**、中位差 1.41 kW（≈ 工作功率 86%），方向与主集一致（仅弱证据）。

**语义修正**：done 前 120 分钟内事件占比高不是失败，而是问题特征化——响应差异在充电**末段集中**。这与"可执行功率区间生成"主轴的关系是：末段降流差异是可识别信号，但其"有界修正"价值需 E2 验证；核心运行段事件（12.1%）独立支撑问题强度。

## 3. 阈值与 done-relative 定义（冻结，V2.0 §4.3 权威）

- P_on=0.5 kW；δ_r=0.25；δ_p=0.5 kW；T_event=5 min；初始排除=5 min；尾段排除=10 min；pilot 工作阈值=1.0 A。
- done 锚点：`doneChargingTime`（API，主集 99.97% 覆盖）；缺失时离线推断（<0.3 kW 持续 20 min 且不再恢复，仅用于排伪，不影响推断锚点会话的判定主体）。`done_anchor_coverage`: api 2,254,390 / inferred 499 / missing 685 行。
- 阶段划分：core_run_segment（距 done >120 min）｜ pre_done_mid（30–120 min）｜ pre_done_tail（0–30 min）｜ post_done（<0，应为 0）｜ done_missing。
- V2.1 §6.4 与 V2.0 §4.3 的 δ_r/δ_p/尾段网格不一致，以 V2.0 为准（已记录待协调项）。

## 7. current-only 保护回退

JPL current-only 400 会话抽样：低功率状态频率 47.5%，77.3% 会话存在低功率段（排除初始 5 分钟与尾段 10 分钟）→ 无 pilot 条件下仍存在大比例"连接但低功率"状态，回退路径可行。

## 8. 停止线判定（K1-M 主集）

| 停止线 | 阈值 | 观测 | 判定 |
|---|---|---|---|
| ≥6 正常月份有核心窗口 | 6 | 6 | ✓ |
| ≥500 合格会话 | 500 | 5,961 | ✓ |
| 核心段事件会话率 ≥5% | 5% | 12.1% | ✓ |
| 中位功率差 ≥0.5kW 或 ≥10% 工作功率 | — | 1.28 kW / 36.6% | ✓ |
| 单一桩/月贡献 ≤50% | 50% | 9.6% / 23.5% | ✓ |
| 负对照后保留主量级 | — | 置换 7.5% ≪ 12.1%；post_done=0 | ✓ |

**结论：K1-M = Go** —— 核心运行段响应差异事件率 12.1%、量级 1.28 kW、6 个月稳定、负对照稳健、末段集中已按特征化而非失败处理。
**K1-X = 方向一致弱证据**（边界核心率 5.3% 达标，但 COVID 低量期不作独立判定）。

## 9. 失败案例与局限

- 20 个最大核心事件 + 20 个长充电无事件会话：`results/raw/E1L/e1_lite_fail_cases.csv`。
- 局限：caltech 单池承载 K1-M 主结论；核心段与末段的事件解释差异需 E2 可执行区间验证；差值能量未扣"可执行区间"边界；JPL 能量离群过滤推迟至 E0-Full；V2.1/V2.0 阈值网格差异待协调。
