## 4. 科学证据链现状

### 4.1 R1-E1：问题强度存在，但 test 不足以支撑宽泛机制

E1 正式结果：

| split | 结论 | 关键事实 |
|---|---|---|
| train | PASS | 9,426 会话；core rate 11.35%；median gap 1.272 kW；置换 CI 下界 >0；非单桩/月 |
| validation | PASS | 3,896 会话；core rate 14.07%；median gap 1.284 kW；置换 CI 下界 >0；非单桩/月 |
| test | FORMAL FAIL | 155 会话；core denom 40；core rate 7.5% 达线；但置换 CI [-5.00, 12.50]pp，单桩 90.9%，单月 100% |

解释边界：

- train/validation 足以证明“现象在历史主域真实存在”；
- test 不能证明“跨时间/跨站稳健泛化”；
- 失败不是实现问题，fidelity check 已锁定 K1 冻结值逐位复现；
- 不能把 test 小样本事后标记为不可评估。

### 4.2 R1-E3：候选预算差值存在，但 Caltech test 主门失败

E3 正式结果：

| 轨道 | train | validation | test |
|---|---:|---:|---:|
| Caltech A2 CI 下界 | 0.2018 | 0.1680 | 0.0052 |
| Caltech 日候选能量中位 | 0.0413 | 0.0378 | 0.0 |
| Caltech A2 elimination | 0.5407 | 0.5190 | 0.7701 |
| Caltech all_pass | True | True | False |
| JPL current-only all_pass | True | True | True |

正式判定为 `FORMAL_FAIL_MAIN`，原因是 Caltech test 主门失败，JPL 不能救主门。

关键含义：

- “并发候选修正窗口”在训练/验证中充足，但 hard-test 域明显塌缩；
- Caltech test 的日候选能量中位为 0，不只是样本小；
- A2 在 test 上消除 77%，逼近 80% 复杂模型止损线；
- 因此 broad active D1-R 不应恢复。

### 4.3 R1 扩展审计 A1-A4

A1-A4 的主要发现：

- Caltech temporal-test main 10,528 会话收缩到 L1_strict_matched test 155，会话保留率 1.47%；
- E1 test 11 个 core events 全在 2020-06，且 10/11 在单桩 `2-39-79-382`；
- E3 Caltech test opportunity energy 79.5% 集中在 2020-11；
- E1 和 E3 在 test 的主导月份不同，但共享部分站点且有 1 个 shared session；
- Caltech test 中 S1∩S2=0，E1 response failure 与 E3 budget opportunity 在 test 域不重叠；
- A4 生成 10 个 A5 eligible candidates，主要集中在 `median_elapsed` 与 recent actual history/variance 类变量。

这些结果更支持“域依赖 + 支持域识别 + 保护回退”的路线，而不是恢复宽泛主动重分配。
